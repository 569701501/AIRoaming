INTENDED USE
Create one clean reusable visual reference for a group that is treated as one stable visual subject in a comic/manhua production.

GROUP IDENTITY LOCK

- Keep the group anonymous unless the supplied facts name an individual. Do not invent new named characters or separate character identities.

COMPOSITION

OUTPUT CONTRACT
