你正在执行 storyboard-shot-generate 的第二阶段：把已经合格的分镜骨架整理成可直接进入候选图工作台的单帧画面说明。

这不是重新创作分镜。只能润色现有 Shot 的四项静态候选图说明：

- `visualDescription`：覆盖原 `comic.panelDescription`。
- `action`：覆盖原 `coreAction`。
- `composition`：覆盖原 `comic.composition`。
- `promptDraft`：覆盖原 `promptDraft`。

冻结规则：

1. 输出镜头数量、顺序和 `order` 必须与输入完全一致，不得增加、删除、合并、拆分或换序。
2. 不得改变 beat、场景、入画角色、剧情事实、决定性瞬间、道具状态、情绪、景别、机位、对白、caption、画格节奏或 motion。
3. 只能把输入中已经存在的事实写得自然、具体、可见；不得补写角色卡和场景卡没有提供的外貌、服饰、建筑、天气、光线或道具细节。
4. 一镜只写同一地点、同一时刻、同一机位下的一个决定性瞬间。不要写“先、随后、然后、片刻后、切到、转到”等连续过程。
5. 不写声音、气味、心理、背景知识或时长；仅在输入已有可见来源和结果时写可见状态。
6. 不要求画面生成文字、数字、字幕、对白框、气泡、拟声词、标识或水印；`dialogueContextOnly` 只帮助理解表演，不得复制进四项输出。
7. 每个已绑定且不是纯声音的角色都要用角色名点明，并写清位置、动作对象、承受关系或视线方向。多人镜头不得只写“他们”“众人互动”。
8. 两个及以上人类个体同镜时，`visualDescription` 必须显式写出与绑定角色一致的总人数（如“两人”“三人”）；非人角色使用符合其形态的量词；群体角色必须在 `visualDescription` 中同时写出原群体名和人数、范围或队形。只有群体身份但没有精确人数时，在群体名前使用“一群”“一队”等中性范围，例如“一群商队众人”；只写群体名不算人数或范围，不得虚构精确人数。
9. `visualDescription` 用自然中文先交代地点与全部主体，再锁定姿态、表情、临时道具和可见环境关系；建议 50～180 字。
10. `action` 用自然中文写清动作发出者、对象、接触点和受力/视线关系；建议 30～100 字。
11. `composition` 只写前中后景、左右位置、遮挡、视觉中心、阅读动线和留白；不写运镜、秒数或连续动作；建议 30～100 字。
12. `promptDraft` 是面向后续静态候选图的自然摘要，包含主体、决定性瞬间、环境、可见光线/氛围和构图重点；不写模型名、艺术家名、参数或负面提示词；建议 50～180 字。
13. 文风应像人类分镜师给画师的清楚说明：完整句、主客体明确、信息有层次，不堆砌逗号分隔的标签。

只返回一个 JSON 代码块。顶层只能有 `shots`；每项只能有 `order`、`visualDescription`、`action`、`composition`、`promptDraft`，不得输出解释、诊断、警告或其他字段。
