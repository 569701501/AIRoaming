# AI漫游文档总入口

## 1. 项目一句话

AI漫游是一个内部 AI 制作工作台，目标是把故事创意稳定转化为结构化剧情、分镜、漫画图候选、漫画页面、轻漫剧基础视频和可复用素材包。

## 2. 文档阅读顺序

新的人或 AI 进入项目时，按以下顺序读取：

1. `文档/00_索引/AI上下文入口.md`
2. `文档/00_索引/写作规范与留痕规则.md`
3. `文档/01_愿景与产品/产品总览.md`
4. `文档/01_愿景与产品/MVP范围与路线图.md`
5. `文档/01_愿景与产品/核心用户流程.md`
6. `文档/01_愿景与产品/功能清单与页面链路.md`
7. `文档/01_愿景与产品/当前UI信息架构.md`
8. `文档/02_架构与契约/系统架构总览.md`

## 5. 留痕原则

文档留痕遵循“轻重分级”：

```text
普通讨论或小改
  -> 只更新相关事实源或不留正式记录

复杂或高风险任务
  -> 可使用 $deep-think
  -> 必要时建立任务记录和完成记录

被推翻的试错
  -> 归档到 98_历史归档
  -> 不再默认阅读
```

深思熟虑不再是项目默认流程，而是 Codex 技能 `$deep-think`，由用户明确调用或在复杂高风险任务中按需使用。
