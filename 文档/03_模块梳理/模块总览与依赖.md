## 1. 模块划分原则

- 模块按用户工作流和数据边界拆分。
- 每个模块都有明确输入、输出和持久化对象。
- AI 生成能力通过任务模块统一进入，不散落在业务模块里。
- 素材管理是底座模块，所有生成结果都要回到素材体系。

## 4. 模块边界

### 4.1 项目管理

负责：

- 创建项目。
- 删除项目，并清理项目记录、本地 workspace 项目目录、该项目生成任务和项目级对话运行态缓存。
- 维护项目状态。
- 维护默认风格和导出目标。
- 聚合项目级统计。
- 在数据库持久化接入前，从本地 workspace 恢复项目索引，保证服务重启后项目库仍可进入已有项目。

不负责：

- 直接生成分镜或图片。
- 直接操作物理素材文件。
- 直接管理章节内剧本正文和章节状态。

### 4.2 章节管理

负责：

- 创建项目默认章节。
- 展示和维护章节列表。
- 维护当前活跃章节。
- 保存当前章节剧本草稿。
- 在用户点击“完成本章，进入下一章”时，写入章节剧本版本并推进章节状态。
- 创建或切换到下一章。
- 协调章节级 workspace 路径。

不负责：

- 直接生成结构化剧情、分镜或图片。
- 把章节标题当作唯一排序依据。
- 保存项目级角色、世界观、通用场景和共享素材。
- 让前端直接写本地物理路径。

当前实现状态：

| 内容 | 状态 | 代码入口 |
| --- | --- | --- |
| 创建项目默认章节 | 已实现 | `apps/server/src/projects/projects.service.ts` |
| `story/story_draft.source.txt` 旧兼容 | 已移除 | 新项目不再创建、读取或写入旧 `story/` 目录 |
| 工作台快照当前章节 | 已实现 | `WorkbenchSnapshot.chapters/currentChapter`；编辑器和对话上下文优先消费当前章节 |
| 章节列表 API | 已实现 | `GET /api/projects/{projectId}/chapters` |
| 保存章节草稿 / 完成本章 | 已实现 | `PATCH /api/projects/{projectId}/chapters/{chapterId}/draft`、`POST /api/projects/{projectId}/chapters/{chapterId}/complete` |

### 4.2.1 项目工作流

负责：

- 定义项目内 7 步主流程。
- 根据当前章节状态推导下一步 `currentStepKey`。
- 维护每个步骤的 `done/active/waiting/blocked` 状态。
- 向前端流程栏、后续对话框提示和生成任务入口提供统一状态。
- 将当前 workflow 快照写入 `workspace/projects/{projectId}/workflow.json`。

不负责：

- 替代 `Chapter.status` 或章节内产物状态。
- 自动创建生成任务。
- 自动把 AI 对话结果写入右侧文档。

当前实现状态：

| 内容 | 状态 | 代码入口 |
| --- | --- | --- |
| 共享 workflow 步骤定义 | 已实现 | `packages/shared/src/domain.ts` |
| `WorkbenchSnapshot.workflow` | 已实现 | `packages/shared/src/dto.ts`, `apps/server/src/projects/projects.service.ts` |
| `workflow.json` 落盘 | 已实现 | `apps/server/src/projects/projects.service.ts` |
| 流程栏按 workflow 状态点击 | 已实现 | `apps/web/src/components/workbench/WorkbenchStageRail.vue` |

### 4.3 故事与剧情结构

负责：

- 保存和读取当前章节剧本。
- 调用 `story_parse` 任务。
- 保存当前章节结构化剧情。
- 管理当前章节故事版本。
- 在剧情结构步骤按章节展示结构状态，并控制未完成剧本章节不能生成结构。
- 在用户确认剧情结构后，将当前章节推进为 `structured` 并允许进入分镜。

不负责：

- 生成最终图片。
- 决定漫画页面布局。
- 把待确认预览当作正式结构输入给分镜。

### 4.4 角色与场景模板

负责：

- 保存角色外观、性格、参考图、提示词片段。
- 保存项目级角色身份、层级、文字描述、图片生成描述 / prompt、预览图和定稿图。
- 角色名是项目内身份标识，普通角色图片生成弹窗不能修改角色名；生图弹窗只编辑用于 AI 生图的形象描述 / prompt。
- 承接剧情结构和分镜阶段发现的待处理新角色；普通用户路径以看图、改生图描述、重新生成、应用当前图和删除当前图片版本为主。
- 加入角色库、合并到已有角色、标记临时或忽略属于底层归类或高级/异常处理能力，不作为普通图卡默认主操作。
- 保存场景地点、氛围、参考图。
- 为分镜和图片生成提供约束。

不负责：

- 保证高级模型层面的角色一致性训练。
- 自动判断所有候选图是否角色一致。

### 4.5 分镜工作台

负责：

- 调用 `shot_generate`。
- 展示 AI 生成的待确认分镜预览。
- 展示和编辑当前章节 `Shot`。
- 在同一次分镜生成中产出漫画画格字段和基础漫剧镜头字段。
- 用户确认后保存当前章节 `storyboard.json` / `Shot[]`，并推进章节到 `storyboard_done`。
- 管理当前章节分镜顺序和状态。
- 为图片生成准备 `shot_prompt_generate` 输入。
- 为后续轻漫剧制作准备基础镜头、配音角色、台词和画面类型输入。

不负责：

- 把未确认的分镜预览提供给候选图生成。
- 直接调用图片 provider。
- 直接生成 TTS、字幕或视频成片。
- 保存图片文件。

### 4.6 出图准备

负责：

- 读取当前章节正式 `storyboard.json` / `Shot[]`。
- 检查每个镜头出镜角色是否已绑定到项目角色库，或明确标记为临时/背景角色。
- 展示剧情结构或分镜阶段发现的待处理新角色；普通路径以本章角色图卡片、编辑生图描述 / prompt、重新生成和应用当前图为主，加入角色库、合并、标记临时或忽略仅作为底层归类或高级/异常处理。
- 检查 `lead`、`recurring` 和当前章重要出镜 `chapter` 角色是否有可用参考图。
- 检查当前章候选图生成所需场景、画风和漫画形式参考。
- 确认后允许进入候选图工作台。

不负责：

- 生成剧情结构或分镜。
- 直接批量生成候选图。
- 替代完整项目角色库管理。

### 4.7 生成任务中心

负责：

- 创建、执行、重试、取消生成任务。
- 记录输入、输出、错误、耗时和 provider 元数据。
- 对章节内任务记录 `chapterId`。
- 向前端推送任务事件。
- 任务完成后注册产物。

不负责：

- UI 展示。
- 业务模块中的人工选择逻辑。

当前实现状态：

| 内容 | 状态 | 代码入口 |
| --- | --- | --- |
| 章节作用域任务校验 | 已实现 | `story_parse`、`shot_generate`、`shot_prompt_generate`、`image_generate`、`layout_export` 创建时强制 `target.chapterId` |
| 项目级素材包导出 | 未强制单章节 | `asset_package_export` 后续可通过 `chapterIds` 导出章节子集 |

### 4.8 漫画图候选

负责：

- 调用 `image_generate`。
- 管理当前章节候选图状态。
- 支持选择、锁定、废弃和重生成。
- 读取已经通过出图准备确认的角色、场景和风格参考。

不负责：

- 页面排版。
- 视频时间轴。

当前实现状态：

| 内容 | 状态 | 代码入口 |
| --- | --- | --- |
| 候选图工作台页面 | 已实现第一版 | `apps/web/src/components/workbench/ImageCandidatesWorkspace.vue` |
| 单镜头候选生成任务入口 | 已实现第一版 | 前端 `workbench-store.generateImageCandidates` 调用 `POST /api/tasks` 创建 `image_generate` |
| 出图准备 guard | 已实现 | `ProjectsService.guardGenerationTaskCreate` 校验正式分镜和已确认 `preflight.json`，并注入追溯字段 |
| 候选图资产落库 / 选择 / 锁定 | 未实现 | 后续需补 `Candidate` 持久化、`Shot.lockedCandidateId` 更新和排版入口 |

### 4.9 漫画排版

负责：

- 基于当前章节已锁定候选建立页面布局。
- 管理格子位置、尺寸和顺序。
- 调用 `layout_export` 输出 PNG/PDF。

不负责：

- 图片生成。
- TTS 和视频导出。

### 4.9 轻漫剧基础视频

负责：

- 将已锁定漫画图组织成时间轴。
- 生成 TTS。
- 管理字幕和 BGM。
- 调用 `video_export` 输出 MP4。

不负责：

- 复杂镜头运动和自动剪辑。
- 替代漫画排版主线。

### 4.10 素材管理

负责：

- 统一注册 `Asset`。
- 维护文件路径、类型、尺寸、时长、来源任务。
- 区分项目级共享素材和章节级产物。
- 导出素材包。
- 支持后续清理和孤儿文件检查。

不负责：

- 决定某个候选是否被选中。
- 修改业务实体状态。

### 4.11 AI 对话与上下文

负责：

- 维护项目内左侧公共“对话框”所需的数据边界。
- 以 OpenCode 作为第一阶段对话运行时，承接消息发送、流式输出、模型选择和 provider 配置；停止生成仍待实现。
- 读取全局设置模块提供的默认 `providerId/modelId`；当设置中保存了 API Key 时，后端只在服务端同步给 OpenCode auth，不向前端回传完整密钥。
- 维护 `apps/server/opencodeAI` 下的 OpenCode AI 资产源码层，逐步沉淀各流程的 agent、skill 和受控 tool。
- 按 `projectId + stepKey` 保存步骤对话记录；剧本等章节内步骤使用 `projectId + stepKey + chapterId` 隔离章节对话。
- 在线程 DTO 中维护 `toolResults`，让前端把 AI 思考、技能调用和受控工具结果挂回对应 assistant 消息展示。
- 为当前步骤组装 AI 上下文。
- 在剧本步骤中读取当前章节正文和章节状态。
- 维护项目级已确认事实。
- 记录 AI 建议的应用状态。
- 支持读取当前步骤产物和项目级已确认事实。

不负责：

- 把整个项目的原始聊天历史自动注入每个步骤。
- 把未确认聊天内容提升为项目事实。
- 提供跨步骤手动引用原始聊天消息作为默认能力。
- 自动覆盖右侧主文档。
- 让 OpenCode 直接写入项目文件、执行 bash 或绕过用户确认动作。
- 迁移 Aurora 的完整 Docker sandbox、Phaser 工具、计费或团队权限体系。
- 直接替代故事、分镜、候选图或排版模块的业务状态。

上下文注入规则：

```text
当前步骤系统提示词
  -> 项目级已确认事实
  -> 当前步骤主文档或产物
  -> 当前步骤对话记录
  -> 用户本轮输入
```

### 4.12 前端项目工作台 UI

负责：

- 展示项目库。
- 支持创建项目。
- 支持项目卡片封面 hover 删除和二次确认。
- 支持进入项目工作区。
- 在项目工作区展示 7 步流程。
- 在剧本步骤展示章节列表或章节切换器。
- 支持保存当前章节草稿、完成本章并进入下一章。
