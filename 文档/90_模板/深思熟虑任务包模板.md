## 1. 使用方式

当任务满足项目 `AGENTS.md` 与 `.agents/skills/deep-think/SKILL.md` 的适用条件时，创建目录：

```text
文档/05_执行与记录/任务记录/YYYY-MM-DD_<任务短名>/
```

并放入：

```text
task_plan.md
progress.md
findings.md
```

如果阶段较多，可增加：

```text
handoff.md
evidence/
```

## 5. 阶段完成检查

阶段进入 `complete` 前至少满足：

- [ ] 该阶段目标已完成。
- [ ] 改动文件已记录。
- [ ] 验证或跳过原因已记录。
- [ ] Handoff 已写。
- [ ] 无未说明 P0/P1 风险。

## 6. 任务完成检查

整个任务完成前至少满足：

- [ ] 长期事实源已更新。
- [ ] 完成记录已创建。
- [ ] 路线图或模块文档已同步。
- [ ] 验收证据已记录。
- [ ] 残留风险已说明。
