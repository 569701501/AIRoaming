## 1. 目录结构

复杂任务新建目录：

```text
文档/05_执行与记录/任务记录/YYYY-MM-DD_<任务短名>/
  task_plan.md
  progress.md
  findings.md
```

## 2. task_plan.md 模板

```markdown
# 任务计划：<任务名>

## 目标

说明本任务要完成什么。

## 当前阶段

阶段 1

## 阶段列表

### 阶段 1：需求与发现
- [ ] 理解用户意图
- [ ] 读取相关事实源
- [ ] 在 findings.md 中记录首轮发现
- **状态：** pending

### 阶段 2：方案与拆解
- [ ] 输出方案
- [ ] 拆分任务
- [ ] 确认验收标准
- **状态：** pending

### 阶段 3：实现与同步
- [ ] 完成实现
- [ ] 更新相关文档
- [ ] 记录变更文件
- **状态：** pending

### 阶段 4：验证与交付
- [ ] 运行验证
- [ ] 写完成记录
- [ ] 交付总结
- **状态：** pending

## 关键问题

1. 

## 已做决策

| Decision | Rationale |
| --- | --- |
|  |  |

## 遇到的错误

| Error | Attempt | Resolution |
| --- | --- | --- |
|  |  |  |

## 注意事项

- 随着进度推进更新阶段状态：pending -> in_progress -> complete。
- 重大决策需要记录原因。
- 错误要记录，避免重复。
```
