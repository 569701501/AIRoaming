## 1. 文档目的

本文档定义 AI漫游当前版本的核心用户路径。

它回答以下问题：

1. 用户打开产品后先看到什么。
2. 用户如何从项目库进入某个项目。
3. 用户进入项目后，如何通过 6 个主步骤完成从故事到漫画产物的生产流程。
4. 项目库页面和项目工作区页面分别承担什么职责。
5. 哪些能力是主流程，哪些只是辅助入口或后置能力。

本文档只描述用户路径、页面层级、阶段输入输出和交互原则，不描述具体视觉样式、组件实现和代码细节。

---

## 2. 当前结论

AI漫游当前采用 **项目库优先** 的产品入口。

用户不是一打开产品就进入 AI 对话，也不是直接进入某个生成工具，而是先进入项目库，查看已有项目或创建新项目。

核心页面层级分为两层：

```text
全局层：项目库 / 素材库 / 任务队列 / 设置

项目层：项目与故事 / 剧情结构 / 分镜工作台 / 候选图工作台 / 排版导出 / 素材包
```

当前核心路径：

```text
用户打开平台
  -> 进入项目库
  -> 如果没有项目，创建第一个项目
  -> 如果已有项目，点击项目卡片进入项目
  -> 进入项目工作区
  -> 通过 6 步流程推进当前项目
  -> 导出漫画页面和素材包
```

当前稳定的 6 个项目内主步骤为：

```text
1 项目与故事
2 剧情结构
3 分镜工作台
4 候选图工作台
5 排版导出
6 素材包
```

这些命名应在产品文档、前端路由、UI 步骤条、数据状态和任务流中保持一致。不要在当前主流程中混用“线稿工作台”“视觉草稿”“上色与修饰”“发布与交付稿”等其他名称。

## 3. 产品主流程

当前漫画主链路为：

```text
项目库
  -> 创建项目 / 打开项目
  -> 项目与故事
  -> 剧情结构
  -> 分镜工作台
  -> 候选图工作台
  -> 排版导出
  -> 素材包
```

| 顺序 | 步骤 | 用户目标 | 主要产物 |
| --- | --- | --- | --- |
| 1 | 项目与故事 | 创建项目，输入故事原文 | `Project`, `StoryVersion.sourceText` |
| 2 | 剧情结构 | 把故事拆成摘要、角色、场景、剧情节拍 | `StoryVersion.structureJson` |
| 3 | 分镜工作台 | 把剧情节拍变成可编辑镜头列表 | `Shot[]` |
| 4 | 候选图工作台 | 为每个分镜生成多张候选图，选择并锁定 | `Candidate[]`, `Shot.lockedCandidateId` |
| 5 | 排版导出 | 把锁定图片排成漫画页并导出 | `LayoutPage`, `PanelPlacement`, `Asset(image/pdf)` |
| 6 | 素材包 | 归档故事、分镜、候选图、锁定图、页面和 manifest | `Asset(archive)`, `manifest.json` |

轻漫剧基础视频属于后续 P0.5 能力，不进入当前 6 步主流程。

## 4. 全局层流程

### 4.1 用户进入平台

用户打开应用后，首先进入：

```text
项目库
```

项目库负责展示所有漫画项目，而不是直接展示单个项目的创作工具。

### 4.2 全局导航

当前全局左侧导航应保持简洁：

```text
项目库
素材库
任务队列
设置
```

说明：

- 不再同时展示“工作台”和“项目”，避免入口层级混乱。
- `项目库` 是用户管理和打开作品的主入口。
- `素材库` 是全局素材视图，区别于某个项目内的 `素材包`。
- `任务队列` 是异步任务状态入口。
- `设置` 是产品配置入口。

### 4.3 项目库页面目标

项目库页面只解决三件事：

1. 查看所有项目。
2. 创建新项目。
3. 打开已有项目继续创作。

### 4.4 项目库页面主要内容

项目库页面应包含：

- 项目列表。
- 项目卡片。
- 项目状态。
- 新建项目入口。
- 项目筛选。
- 项目搜索。
- 任务队列轻量入口。
- 简化的 6 步创作流程说明。

项目库页面不默认展示：

- 升级计划。
- 团队协作。
- 最近活动大面板。
- 常驻对象检查器。
- 常驻下一步建议。
- 大面积右侧辅助栏。
- 大面积营销 hero 文案。
- 默认“导入剧本”主按钮。

如果后续需要导入剧本，应作为次级入口或新建项目流程中的导入方式，不应抢占项目库主按钮位置。

### 4.5 项目库中的创作流程说明

项目库可以展示简化版创作流程：

```text
项目与故事 -> 剧情结构 -> 分镜工作台 -> 候选图工作台 -> 排版导出 -> 素材包
```

在项目库中，这条流程的作用是：

```text
告诉新用户这个产品怎么使用。
```

它不是当前项目进度条。

### 4.6 空项目状态

如果用户没有任何项目，显示空状态：

```text
你还没有漫画项目

从一个故事开始，AI 会帮你拆剧情、生成分镜、生成候选图并排版导出。

[创建第一个项目]
```

空状态下可以展示简化版 6 步流程，帮助用户理解产品。

### 4.7 有项目状态

如果用户已有项目，展示项目卡片列表。

每个项目卡片至少包含：

| 信息 | 说明 |
| --- | --- |
| 项目名称 | 例如：迷雾之城 |
| 项目封面 | 作品视觉摘要 |
| 当前阶段 | 例如：分镜工作台 |
| 进度 | 当前项目完成比例或阶段进度 |
| 最近编辑时间 | 用于判断继续哪个项目 |
| 主按钮 | `继续创作` |

项目列表页中的 `继续创作` 表示：

```text
进入该项目工作区。
```

注意：`继续创作` 只适合出现在项目列表页，不适合出现在项目内页。

## 5. 项目工作区通用流程

### 5.1 进入项目

用户点击项目卡片后，进入项目工作区。

示例：

```text
项目库
  -> 点击《迷雾之城》
  -> 进入《迷雾之城》项目工作区
```

### 5.2 项目工作区顶部

项目工作区顶部应包含：

```text
返回项目库
项目切换器：迷雾之城 ▼
搜索当前项目内容
任务队列入口
用户入口
```

其中：

- `返回项目库` 用于回到所有项目。
- `迷雾之城 ▼` 是项目切换器，用于切换到其他项目。
- 搜索只搜索当前项目内的故事、角色、场景、镜头和素材。
- 任务队列是轻量入口，不占据主内容区。

### 5.3 项目工作区主体

项目工作区主体应包含：

```text
项目名称
当前阶段
第几话 / 第几章状态
6 步流程条
当前步骤工作区
```

当前设计原则：

- 不使用大面积装饰 hero 图占据主内容高度。
- 不默认展示右侧常驻辅助栏。
- 主工作区应占据页面主要高度和宽度。
- 用户进入项目后，应优先看到当前阶段的可操作内容。

### 5.4 项目内流程条

项目内始终显示 6 步流程条：

```text
1 项目与故事
2 剧情结构
3 分镜工作台
4 候选图工作台
5 排版导出
6 素材包
```

在项目内，这条流程的作用是：

```text
显示当前项目做到哪一步。
```

它同时承担两种职责：

1. 显示用户现在在哪一步。
2. 显示当前项目各步骤状态。

状态包括：

| 状态 | 含义 |
| --- | --- |
| 未开始 | 前置步骤未完成或当前步骤还没有数据 |
| 进行中 | 当前正在编辑或生成 |
| 已完成 | 当前步骤已有可进入下一步的产物 |

### 5.5 项目内页面按钮规则

项目内页不要再使用泛化按钮：

```text
继续创作
```

因为用户已经进入项目工作区，已经在创作环境里。

项目内页应使用更明确的动作按钮，例如：

| 当前阶段 | 合适主动作 |
| --- | --- |
| 项目与故事 | `AI 分析剧情` |
| 剧情结构 | `生成分镜` |
| 分镜工作台 | `生成候选图` |
| 候选图工作台 | `锁定入选图` / `前往排版导出` |
| 排版导出 | `导出当前页` / `导出整话 PDF` |
| 素材包 | `下载素材包` / `导出 manifest` |

## 6. 步骤一：项目与故事

### 6.1 用户目标

用户创建项目，并输入故事原文或章节大纲。

### 6.2 用户操作

1. 输入项目名称。
2. 输入故事标题。
3. 选择题材 / 类型。
4. 选择漫画格式。
5. 选择画风方向。
6. 输入或粘贴故事原文。
7. 保存草稿。
8. 点击 `AI 分析剧情`。

### 6.3 页面主要内容

项目与故事页面应展示：

- 项目名称。
- 故事标题。
- 题材标签。
- 漫画格式。
- 画风方向。
- 故事原文编辑器。
- 保存状态。
- `保存草稿`。
- `AI 分析剧情`。

### 6.4 输入

- 项目名称。
- 故事标题。
- 故事原文。
- 题材标签。
- 漫画格式。
- 画风方向。

### 6.5 输出

- `Project`
- `StoryVersion`
- `StoryVersion.sourceText`

### 6.6 下一步

故事保存后，用户进入：

```text
剧情结构
```

---

## 7. 步骤二：剧情结构

### 7.1 用户目标

用户确认 AI 是否理解了故事，并把故事变成后续分镜可用的结构化数据。

### 7.2 用户操作

1. 查看故事摘要。
2. 查看角色卡片。
3. 查看场景列表。
4. 查看剧情节拍。
5. 编辑角色、场景和节拍。
6. 点击 `生成分镜`。

### 7.3 页面主要内容

剧情结构页面应展示：

- 故事摘要。
- 角色卡片。
- 场景列表。
- 剧情节拍。
- 结构化剧情状态。
- `重新分析`。
- `编辑角色`。
- `编辑场景`。
- `生成分镜`。

### 7.4 输入

- `StoryVersion.sourceText`
- 用户选择的结构化方式。
- 项目风格和题材信息。

### 7.5 输出

```json
{
  "summary": "故事摘要",
  "characters": [],
  "scenes": [],
  "beats": []
}
```

### 7.6 下一步

剧情结构确认后，用户进入：

```text
分镜工作台
```

---

## 8. 步骤三：分镜工作台

### 8.1 用户目标

用户把剧情节拍变成可编辑、可生成图片的镜头列表。

### 8.2 用户操作

1. 查看场景列表。
2. 查看镜头卡片。
3. 编辑镜头描述。
4. 编辑景别、运镜、动作、对白和情绪。
5. 调整镜头顺序。
6. 新增或删除镜头。
7. 点击 `生成候选图`。

### 8.3 页面主要内容

分镜工作台应展示：

- 场景列表。
- 镜头卡片。
- 镜头缩略预览。
- 镜头字段。
- `AI 拆分镜头`。
- `重写镜头`。
- `调整节奏`。
- `生成候选图`。

### 8.4 输入

- `StoryVersion.structureJson`
- `StoryBeat[]`
- `Character[]`
- `SceneLocation[]`

### 8.5 输出

- `Shot[]`
- `Shot.promptDraft`

### 8.6 下一步

分镜确认后，用户进入：

```text
候选图工作台
```

---

## 9. 步骤四：候选图工作台

### 9.1 用户目标

用户为每个分镜生成多张候选漫画图，并选择最满意的一张锁定。

### 9.2 用户操作

1. 选择场景和镜头。
2. 查看当前分镜信息。
3. 设置角色一致性、画风锁定和场景预设。
4. 生成多张候选图。
5. 对比候选图。
6. 选择候选图。
7. 锁定入选图。
8. 进入排版导出。

### 9.3 页面主要内容

候选图工作台应展示：

- 场景与镜头列表。
- 当前镜头信息。
- 候选图网格。
- 一致性评分。
- 已入选图片槽位。
- `批量生成候选图`。
- `重新生成`。
- `锁定入选图`。
- `前往排版导出`。

### 9.4 输入

- `Shot`
- `Shot.promptDraft`
- `Character`
- `SceneLocation`
- 画风和生成参数。

### 9.5 输出

- `Candidate[]`
- `Asset(image)`
- `Shot.lockedCandidateId`

### 9.6 下一步

候选图锁定后，用户进入：

```text
排版导出
```

---

## 10. 步骤五：排版导出

### 10.1 用户目标

用户把已锁定的分镜图片排成漫画页面，并导出 PNG 或 PDF。

### 10.2 用户操作

1. 查看页面列表。
2. 选择页面。
3. 在画布中查看漫画页。
4. 调整格子布局。
5. 添加或编辑对白气泡。
6. 调整页面设置。
7. 导出当前页。
8. 导出整话 PDF。

### 10.3 页面主要内容

排版导出页面应展示：

- 页面列表。
- 漫画页面画布。
- 页面工具栏。
- 气泡工具。
- 字体设置。
- 页面尺寸。
- 出血和边距设置。
- `导出当前页`。
- `导出整话 PDF`。

### 10.4 输入

- 已锁定 `Candidate`
- `Shot.dialogue`
- 页面模板。
- 排版配置。

### 10.5 输出

- `LayoutPage`
- `PanelPlacement`
- `Asset(image)`
- `Asset(document/pdf)`

### 10.6 下一步

漫画页导出后，用户进入：

```text
素材包
```

---

## 11. 步骤六：素材包

### 11.1 用户目标

用户归档项目全部产物，便于备份、复用、交付或后续轻漫剧制作。

### 11.2 用户操作

1. 查看故事原文。
2. 查看剧情结构。
3. 查看分镜数据。
4. 查看候选图。
5. 查看锁定图。
6. 查看漫画页面。
7. 查看导出文件。
8. 导出素材包。
9. 导出 manifest。

### 11.3 页面主要内容

素材包页面应展示：

- 素材分类。
- 素材数量。
- 当前素材包预览。
- 文件包元数据。
- 内容概览。
- `下载素材包`。
- `导出 manifest`。
- `查看导出记录`。

### 11.4 输入

- `Project`
- `StoryVersion`
- `Shot[]`
- `Candidate[]`
- `Asset[]`
- `LayoutPage[]`
- 导出配置。

### 11.5 输出

```text
manifest.json
story.json
shots.json
characters.json
scenes.json
assets/
  images/
  pages/
exports/
```

### 11.6 完成状态

素材包导出后，当前漫画主流程完成。

## 12. 辅助能力定位

以下能力不是主流程步骤，只是辅助入口。

### 12.1 AI 命令区

AI 命令区是快捷操作入口，不是产品主体。

它可以帮助用户触发：

- 分析剧情。
- 生成分镜。
- 重写镜头。
- 生成候选图。
- 调整排版。
- 导出素材包。

但 AI 命令区产生的结果必须落回 6 个主步骤中的某个页面。

当前版本不把 AI 命令区作为左侧常驻主工作区。

### 12.2 任务队列

任务队列用于展示异步任务状态。

包括：

- 排队中。
- 运行中。
- 已完成。
- 失败。
- 已取消。

任务队列可以作为顶部入口或独立页面，不默认占据项目工作区主内容高度。

### 12.3 对象检查器与下一步建议

对象检查器和下一步建议属于上下文辅助能力。

当前版本不默认作为右侧常驻栏展示。

后续可作为：

- 抽屉。
- 弹层。
- 当前对象详情面板。
- 局部辅助卡片。

它们不应压缩主工作区。

## 14. 状态映射

### 14.1 项目阶段状态

| UI 阶段 | 含义 |
| --- | --- |
| `project_story` | 项目与故事 |
| `story_structure` | 剧情结构 |
| `storyboard` | 分镜工作台 |
| `image_candidates` | 候选图工作台 |
| `layout_export` | 排版导出 |
| `asset_package` | 素材包 |

### 14.2 阶段完成条件

| 阶段 | 完成条件 |
| --- | --- |
| 项目与故事 | 已保存项目和故事原文 |
| 剧情结构 | 已生成并确认摘要、角色、场景和剧情节拍 |
| 分镜工作台 | 已生成并确认可用于出图的分镜列表 |
| 候选图工作台 | 每个需要排版的分镜已有锁定候选图 |
| 排版导出 | 已生成漫画页并导出 PNG 或 PDF |
| 素材包 | 已导出素材包和 manifest |

### 14.3 项目状态建议

| 项目状态 | 含义 |
| --- | --- |
| `draft` | 项目草稿中 |
| `story_ready` | 故事已保存，准备结构化 |
| `structure_ready` | 剧情结构已确认 |
| `shots_ready` | 分镜已确认 |
| `images_ready` | 候选图已锁定 |
| `layout_ready` | 漫画页已排版 |
| `exported` | 已导出页面或素材包 |

## 15. 当前非目标

当前主流程不包含：

- 升级计划。
- 商业化套餐。
- 团队协作。
- 多人权限。
- 复杂通知中心。
- 最近活动大面板。
- 大面积右侧辅助栏。
- 大面积装饰 hero 图。
- 一次性自动生成完整商业漫画。
- 高复杂度轻漫剧视频制作。

轻漫剧基础视频保留为后续 P0.5 能力，不进入当前项目内 6 步主流程。

## 16. 验收标准

更新后的用户流程应满足：

- 用户打开应用后，先进入项目库。
- 用户可以从项目库创建或打开项目。
- 用户进入项目后，可以看到当前项目名称和项目切换器。
- 用户进入项目后，可以看到 6 步创作流程。
- 用户能明确知道当前处于哪一步。
- 每一步都有清晰输入、操作、输出和下一步。
- 项目列表页和项目工作区职责不混淆。
- 项目列表页中的 `继续创作` 只用于进入项目。
- 项目内页不再使用泛化的 `继续创作` 按钮，而使用当前阶段的具体动作。
- 辅助能力不抢占主工作区。
- 轻漫剧不抢占漫画主链路。
