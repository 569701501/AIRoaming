## 1. 当前结论

应用入口采用“项目库优先”。

用户路径：

```text
进入应用
  -> 项目库
  -> 新建项目 / 打开项目
  -> 项目工作区
  -> 默认进入第 1 步“剧本”
  -> 选择或创建当前章节
  -> 左侧对话框 + 章节列表 + 右侧剧本文档编辑器
  -> 通过 6 步流程推进当前章节
```

当前不再沿用旧六面板试错页面、输出 Tab 页面或大面积 hero 工作台。下一版代码实现必须先对齐本文档和 `文档/01_愿景与产品/当前UI信息架构.md`。

## 2. 品牌与命名

| 类型 | 名称 | 用途 |
| --- | --- | --- |
| 项目内部代号 | AI漫游 | 文档、代码、仓库、内部讨论 |
| 前端展示品牌 | 绘界漫画 | 用户界面展示 |

如果代码、文档、UI 同时出现两个名称，按上表理解，不应再混用为两个产品。

## 3. 全局导航

当前全局导航只保留轻量入口：

| 入口 | 当前状态 | 说明 |
| --- | --- | --- |
| 项目库 | current | 应用默认入口 |
| 素材库 | planned | 全局素材视图，后续实现 |
| 任务队列 | current/ui_shell | 轻量入口，可先显示任务状态壳 |
| 设置 | planned | 产品配置入口 |

不再同时展示“工作台”和“项目”两个并列主入口。

## 4. 项目库页面

用途：

- 查看所有项目。
- 创建项目。
- 打开项目。
- 删除项目。
- 展示简化的 6 步创作流程说明。

可以展示：

- 项目卡片。
- 项目状态。
- 新建项目入口。
- 项目筛选。
- 项目卡片封面 hover 删除按钮。
- 删除二次确认弹窗。
- 任务队列轻量入口。

创建项目只创建项目记录，创建弹窗用户可见标题为“创建项目”，只保留“项目名称”一个字段，不展示内部语义或“下一步”提示文案，不要求填写剧本、故事标题、题材标签、漫画格式、画风方向或故事原文。当前第 1 步“剧本”只在右侧编辑和保存剧本正文；故事标题、题材标签、漫画格式和画风方向等元信息后置，不在当前剧本文档页展示。

创建项目成功后：

```text
关闭创建弹窗
  -> 直接进入项目工作区
  -> 默认打开第 1 步“剧本”
  -> 左侧显示公共对话框
  -> 右侧显示剧本文档编辑器
```

不展示：

- 升级计划。
- 团队协作。
- 最近活动大面板。
- 大型右侧栏。
- 常驻对象检查器。
- 常驻下一步建议。
- 大面积营销 hero 文案。

## 5. 项目工作区页面

用途：

- 围绕当前项目进行创作。
- 显示返回项目列表按钮。
- 显示 6 步流程。
- 根据当前步骤展示主工作面板。

顶部可包含：

- 返回项目列表按钮。
- 项目名称。
- 6 步流程条。

主体应包含：

- 左侧公共“对话框”。
- 当前步骤需要的对象导航，例如剧本步骤的章节列表。
- 右侧当前步骤主文档或工作内容。

不默认展示：

- 全局左侧导航。
- 顶部搜索框。
- 大 hero 图。
- 常驻右侧栏。
- 常驻下一步建议。
- 常驻对象检查器。

主工作区优先，辅助信息不能挤压主要创作空间。

“对话框”是项目内公共 AI 面板，不是弹窗。它随当前步骤切换注入不同提示词和上下文。对话框组件公共，但对话记录按步骤隔离：剧本、剧情结构、分镜等步骤各自维护对话记录，项目级只共享用户已确认的事实、文档和产物。剧本阶段中，对话框当前支持询问剧本内容、给出建议、总结和改写版本；上传剧本、应用到剧本和插入到光标处是后续能力。AI 不直接覆盖右侧剧本文档，必须由用户点击“应用”或“插入”后才改动正文。

当前实现：

- 项目库点击 `继续创作` 进入项目工作区。
- 创建项目成功后进入项目工作区。
- 工作区顶部区域提供 `返回项目库`。
- 工作区主体展示紧凑 6 步流程栏。
- 项目工作区已隐藏全局左侧导航和顶部搜索。
- 当前已实现左侧“对话框”和右侧“剧本文档编辑器”，右侧只展示剧本正文，支持保存剧本草稿。
- 剧本步骤对话已接入 OpenCode：支持发送消息、流式展示 assistant 回复、读取模型列表、切换 provider/model，并按当前步骤加载对话记录。
- 其他步骤切换时仍保留左侧公共对话框，右侧工作面板暂显示开发占位。
- 上传剧本、停止生成、应用建议和插入到光标处仍未接入，不能当作已完成能力。
- 其他步骤保留流程展示，不提供未完成的真实业务操作。

### 5.1 章节列表与章节推进

剧本步骤需要章节列表或章节切换器。章节列表只管理项目内章节，不恢复全局左侧导航。

章节列表当前定位：

| 功能 | 当前状态 | 说明 |
| --- | --- | --- |
| 查看章节 | `next` | 显示章节顺序、标题、状态和更新时间 |
| 切换章节 | `next` | 切换后右侧编辑器加载当前章节剧本 |
| 保存章节草稿 | `next` | 保存当前章节正文，不推进到下一章 |
| 完成本章 | `next` | 保存当前章节并标记剧本完成 |
| 进入下一章 | `next` | 如果下一章不存在则创建，存在则切换 |
| 回到上一章编辑 | `next` | 允许修改，但应提示后续产物可能需要重新生成 |

章节不是前端临时状态，后续必须进入数据模型、后端 API 和本地 workspace 文件契约。

## 6. 六个项目内页面

| 顺序 | 页面 | 目标 | 当前状态 |
| --- | --- | --- | --- |
| 1 | 剧本 | 通过对话框辅助询问和改写当前章节剧本，并在右侧保存章节正文；章节列表、上传和应用/插入后续补齐 | current/next |
| 2 | 剧情结构 | 结构化当前章节摘要、角色、场景、节拍 | next |
| 3 | 分镜工作台 | 生成和编辑当前章节镜头列表 | next |
| 4 | 候选图工作台 | 为当前章节生成多候选图并选择锁定 | next |
| 5 | 排版导出 | 生成当前章节漫画页并导出 | next |
| 6 | 素材包 | 归档项目共享素材、章节产物、manifest 和交付素材 | next |

这 6 个页面是项目内主流程。轻漫剧基础版不进入当前 6 步 UI 主流程。

## 7. UI 元素状态

| UI 元素 | 当前状态 | 处理 |
| --- | --- | --- |
| 搜索 | `deferred` | 当前项目库和项目工作区都不展示顶部搜索 |
| 任务队列 | `current` | 轻量入口可以保留 |
| 项目删除 | `current` | 只在项目卡片封面 hover 时显示删除入口；确认后删除项目记录和本地 workspace 项目目录 |
| 通知铃铛 | `deferred` | 先不展示，或仅作为视觉占位但不进主流程 |
| 用户头像 | `ui_shell` | 可以展示，但不做团队/账号系统 |
| 对象检查器 | `deferred` | 不默认常驻右侧 |
| 下一步建议 | `deferred` | 不默认常驻右侧，可后续做抽屉或局部卡片 |
| 对话框 | `current` | 项目内公共 AI 对话面板，左侧常驻，不是弹窗 |
| 步骤对话记录 | `current` | 每个步骤独立记录对话历史，切换步骤时只加载当前步骤记录 |
| 项目级已确认事实 | `current` | 跨步骤共享已确认事实和产物，不共享未确认聊天假设 |
| 章节列表 | `next` | 剧本步骤内显示和切换章节，不作为全局导航 |
| 完成本章 | `next` | 保存当前章节，标记章节状态，进入下一章 |

## 8. 页面能力状态

| 状态 | 含义 | UI 规则 |
| --- | --- | --- |
| `current` | 当前版本要围绕它设计 | 可以进入主路径 |
| `ui_shell` | 可以有界面壳，但没有完整真实能力 | 必须弱化或明确标识 |
| `next` | 后续核心能力 | 可以在流程中展示状态，但不伪装可用 |
| `deferred` | 当前不做或后置 | 不占据主流程空间 |

## 9. 禁止事项

- 不把参考图里的搜索、通知、团队、升级计划直接搬进当前产品。
- 不把对象检查器或下一步建议做成默认右侧常驻栏。
- 不用大 hero 图抢占项目工作区主内容。
- 不把轻漫剧基础版混入当前漫画 6 步主流程。
- 不把归档中的旧 UI 试错文档当作当前事实源。
- 不允许 AI 对话结果自动覆盖用户文档，必须经用户确认后应用或插入。
- 不把整个项目的原始聊天历史自动注入每个步骤；跨步骤上下文必须来自用户已确认事实、保存文档和锁定产物。
- 不把章节只做成前端 Markdown 标题解析；章节必须能被后端、任务、文件路径和后续产物追溯。
- 不把章节内素材和项目级共享素材混在一起；角色、世界观、通用场景和共享素材优先保留项目级复用能力。
