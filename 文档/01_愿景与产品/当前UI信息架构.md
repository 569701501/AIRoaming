## 1. 当前结论

```text
应用入口：项目库
项目内部：项目工作区
项目主流程：6 步
```

页面结构必须先服务真实工作流，而不是先做营销式欢迎页、对话页或展示型大图。

## 2. 页面一：项目库

用途：

- 查看项目。
- 创建项目。
- 打开项目。
- 删除项目。
- 看到简化创作流程。

主要内容：

- 顶部品牌：绘界漫画。
- 项目列表或项目卡片。
- 新建项目入口。
- 项目卡片封面 hover 删除入口。
- 项目状态和更新时间。
- 轻量任务队列入口。

不展示：

- 升级计划。
- 最近活动大面板。
- 团队协作。
- 常驻右侧栏。
- 常驻对象检查器。
- 常驻下一步建议。
- 大面积营销 hero 文案。

## 3. 页面二：项目工作区

顶部：

- 返回项目库。
- 项目切换器。
- 搜索当前项目内容。
- 任务队列入口。
- 用户头像入口。

主体：

- 项目名称。
- 当前阶段。
- 6 步流程条。
- 当前步骤工作区。

不默认展示：

- 大 hero 图。
- 常驻右侧栏。
- 下一步建议。
- 对象检查器。

## 4. 六个项目内页面

| 顺序 | 页面 | 主目标 |
| --- | --- | --- |
| 1 | 项目与故事 | 创建项目，输入和保存故事 |
| 2 | 剧情结构 | 将故事整理为摘要、角色、场景、节拍 |
| 3 | 分镜工作台 | 生成和编辑镜头列表 |
| 4 | 候选图工作台 | 生成、比较、选择并锁定候选图 |
| 5 | 排版导出 | 生成漫画页面并导出 |
| 6 | 素材包 | 归档项目素材和 manifest |

## 5. 辅助入口

| 辅助入口 | 当前处理 |
| --- | --- |
| 搜索当前项目内容 | 可以展示为 `ui_shell`，不接全局搜索 |
| 任务队列 | 可以作为顶部轻量入口 |
| 通知铃铛 | 后置，不进入主路径 |
| 用户头像 | 可以展示，但不做团队和账号系统 |
| 对象检查器 | 后置为抽屉、弹层或局部详情，不默认常驻 |
| 下一步建议 | 后置为局部辅助，不默认常驻 |
| AI 命令区 | 后置为快捷入口，不作为当前默认主工作区 |

## 6. 设计原则

- 主工作区优先。
- 项目库先于项目工作区。
- 项目工作区先显示流程和当前步骤。
- 参考图只借鉴信息密度、图标语言和工作台气质，不直接搬功能。
- 未实现能力必须灰态或后置，不能伪装成当前可用。
