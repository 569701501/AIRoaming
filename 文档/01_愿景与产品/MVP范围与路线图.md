## 1. MVP 一句话

MVP 要证明一件事：用户能从章节剧本出发，经过结构化剧情、分镜编辑、漫画图多候选生成、候选选择，最终导出漫画页面和素材包。

## 2. MVP 主线

```text
创建项目
  -> 创建或进入当前章节
  -> 输入当前章节剧本
  -> AI 整理当前章节剧情结构
  -> AI 生成当前章节分镜
  -> 人工编辑分镜
  -> 为分镜生成漫画图候选
  -> 人工选择并锁定候选
  -> 排版漫画页面
  -> 导出 PNG/PDF/素材包
```

## 3. MVP 功能范围

| 模块 | MVP 范围 | 不进入 MVP 的内容 |
| --- | --- | --- |
| 项目管理 | 新建项目、项目状态、基础版本号 | 团队权限、多工作区 |
| 章节管理 | 默认章节、章节列表、保存草稿、完成本章并进入下一章 | 自动长篇拆卷、多人章节协作 |
| 故事输入 | 粘贴当前章节文本、保存章节原文、生成结构化剧情 | 复杂设定库 |
| 剧情结构化 | 提取当前章节场景、角色、事件、对白线索 | 世界观知识图谱 |
| 分镜生成 | 根据剧情生成可编辑分镜数组 | 专业电影级镜头语言优化 |
| 分镜编辑 | 修改角色、场景、动作、对白、镜头、情绪 | 多人同时编辑 |
| 漫画图生成 | 单分镜生成多候选图 | 完整角色 LoRA 训练 |
| 候选选择 | 查看、选择、锁定、废弃候选 | 高级 A/B 数据统计 |
| 漫画排版 | 选择已锁定图片，导出单页或多页 PNG/PDF | 复杂印刷规范 |
| 素材管理 | 图片、PDF、manifest、任务输入输出归档 | 对象存储、CDN、多端同步 |
| 轻漫剧基础版 | P0.5 / M4 后续扩展，不进入当前 6 步 UI 主流程 | 复杂运镜、自动剪辑策略 |

## 4. 里程碑

### M0：文档与契约成型

目标：让后续实现有清晰事实源。

交付物：

- 文档体系
- 产品总览
- MVP 范围
- 架构总览
- 数据模型
- 生成任务协议
- 素材路径契约

退出标准：

- AI 能通过 `文档/README.md` 找到所有核心事实源。
- 每个 P0 模块都有明确输入输出。
- 每个功能完成后有固定记录位置。

### M1：章节剧本到分镜

目标：验证故事结构化和分镜编辑闭环。

交付物：

- 项目创建
- 章节列表和当前章节剧本输入
- 剧情结构化任务
- 分镜生成任务
- 分镜列表和编辑

退出标准：

- 输入当前章节剧本后能得到结构化剧情 JSON。
- 结构化剧情能生成分镜数组。
- 用户能修改分镜字段并保存。

### M2：分镜到漫画图候选

目标：验证单分镜多候选生成和人工选择。

交付物：

- 角色模板
- 场景模板
- 图片生成任务
- 候选图列表
- 候选选择和锁定

退出标准：

- 每个分镜可生成至少 2 个候选图。
- 候选图能追溯到生成任务输入。
- 用户能锁定一个候选作为该分镜当前图片。

### M3：漫画排版与导出

目标：验证选定素材能形成可交付漫画页。

交付物：

- 页面排版模型
- 单页/多页排版
- PNG/PDF 导出
- 素材包导出

退出标准：

- 已锁定分镜图可生成漫画页面。
- 导出物包含图片文件和元数据。
- 素材包能追溯项目、章节、分镜和候选关系。

### M4：轻漫剧基础版

目标：



交付物：

- 图片序列时间轴
- TTS 音频
- 字幕文件
- BGM 引用
- MP4 导出

退出标准：

- 已锁定漫画图序列能导出基础 MP4。
- 字幕与 TTS 有对应关系。
- MP4 与源素材关系可追溯。

## 5. 优先级表

| 优先级 | 功能 | 原因 |
| --- | --- | --- |
| P0 | 项目、章节、剧情结构化、分镜、图片候选、漫画排版、素材包 | 构成漫画创作和交付闭环 |
| P0.5 | 基础轻漫剧、TTS、字幕、BGM | 基于漫画产物的后续扩展 |
| P1 | 局部重生成、角色一致性增强、批量操作 | 提升生产效率 |
| P2 | 多人协作、云端扩容、商业化、复杂视频 | 等主链路稳定后再做 |

## 6. MVP 非目标

- 不要求 AI 完全自动理解所有文学隐喻。
- 不要求漫画图一次生成即最终可用。
- 不要求轻漫剧达到专业动画剪辑质量。
- 不要求第一版支持云端多用户并发。
- 不要求第一版具备商业权限体系。
- 轻漫剧基础版：P0.5 / M4，不进入当前 6 步 UI 主流程。

## 7. 验收样例

MVP 应至少用一份短篇故事做端到端验收：

1. 创建项目并进入第 1 章。
2. 输入 800 到 1500 字当前章节剧本。
3. 生成至少 3 个剧情场景。
4. 生成至少 8 个分镜。
5. 每个分镜生成 2 个漫画图候选。
6. 锁定每个分镜的候选图。
7. 导出至少 1 页漫画 PNG。
8. 导出素材包，包含 JSON 元数据。
