## 1. 产品定位

AI漫游是面向内部创意生产团队的 AI 制作工作台。它把模糊故事创意转化为可编辑、可复用、可追溯的漫画生产素材，并为后续轻漫剧扩展保留素材基础。

| 类型 | 名称 |
| --- | --- |
| 项目内部代号 | AI漫游 |
| 前端展示品牌 | 绘界漫画 |

产品不是单次“AI 生图工具”，而是围绕故事生产建立一条可控流水线：

```text
故事创意
  -> 按章节写剧本
  -> 当前章节结构化剧情
  -> 当前章节分镜
  -> 当前章节漫画图候选
  -> 人工选择与锁定
  -> 当前章节漫画页面
  -> 素材包归档
```

轻漫剧成片、剪辑和导出是后续扩展能力，不进入当前漫画主链路。但分镜阶段需要提前生成基础漫剧镜头字段，避免后续制作漫剧时重新理解剧情、人物和镜头意图。

## 2. 核心价值

| 价值 | 说明 |
| --- | --- |
| 快速起稿 | 把故事文本整理成结构化剧情和分镜，降低从想法到可视化草稿的时间 |
| 可控生成 | 每个分镜可以编辑、重生成、多候选选择，不强迫一次性自动完成 |
| 素材复用 | 角色、场景、分镜、候选图和交付物进入资产体系，后续可扩展到音频和视频 |
| 版本留痕 | 支持故事版本、分镜版本、候选图、导出物的关系追踪 |
| 章节推进 | AI 创作按章保存和完成；仅在已确认大纲存在下一章卡时增加入口并停留当前章。已有剧本在拆章目录确认后一次创建全部章节入口，避免两条路线互相套用 |
| 制作协作 | 让创意、漫画、视频制作角色围绕同一套素材和状态推进 |

## 3. 目标用户

| 用户 | 目标 | 典型操作 |
| --- | --- | --- |
| 创意策划 | 把故事想法快速拆成可视化制作任务 | 输入故事、修剧情结构、确认分镜 |
| 漫画作者 | 控制分镜和画面效果 | 编辑分镜、选择候选图、锁定角色与画风 |
| 轻漫剧制作人员 | 后续将漫画素材转为基础视频资产 | 排序镜头、生成 TTS、添加字幕和 BGM |
| 项目负责人 | 管理版本、素材和交付 | 查看状态、导出素材包、追踪完成度 |

## 4. 产品原则

### 4.1 流程自动化 + 人工可控

AI 负责生成初稿、候选和建议；人负责确认、编辑、锁定和取舍。所有关键中间结果都应可见、可改、可重跑。

### 4.2 生成素材可复用

系统不只保存最终图片或视频，还要保存生成输入、提示词、角色模板、场景、候选关系和版本关系。

### 4.3 多版本、多候选

同一故事、同一分镜、同一图片任务允许多个版本和候选。用户可以比较、选择、回退或派生。

### 4.4 先稳工作流，再追求智能度

MVP 的成功标准不是生成效果一次到位，而是工作台能稳定承载反复修改、生成、选择、导出的真实流程。

## 5. 产品边界

### 5.1 当前要做

- 故事输入、剧情结构化、分镜、出图准备和候选图生成。
- 章节列表、章节草稿保存、正式章节进入本章剧情结构；AI 创作完成后仅在大纲存在下一章卡时增加入口但不自动切换，不提供“继续下一章”动作；已有剧本拆章后一次创建全部入口并逐章确认；角色库待处理项只提示，不阻塞剧情结构。
- 项目角色库：提取主角、常驻角色和章节中新出现的重要角色，管理角色身份信息、生图描述 / prompt、预览图、定稿图和视觉版本，作为常驻资产入口保障后续漫画和漫剧画面的角色一致性。
- 分镜生成与人工编辑；分镜阶段同时生成漫画画格字段和基础漫剧镜头字段。
- 角色与场景基础模板。
- 出图准备：检查当前章节出镜角色绑定、待处理角色、角色参考图、场景和画风参考。
- 单分镜多候选漫画图生成。
- 候选选择、锁定、重生成。
- 漫画页基础排版与导出。
- 素材归档与导出。

### 5.2 当前不做

- 一次性自动生成完整商业漫画。
- 高复杂度视频镜头调度和 3D 运镜。
- 多人实时协同编辑。
- 商业化权限、计费和发布平台。
- 完全自动保证角色一致性的闭环训练系统。
- 完整轻漫剧成片、自动剪辑、TTS 和视频导出不进入当前漫画主链路；但分镜数据应为后续漫剧保留可编辑镜头字段。

## 6. 关键成功指标

| 指标 | MVP 判断方式 |
| --- | --- |
| 从章节剧本到分镜 | 输入当前章节故事后能生成可编辑分镜列表 |
| 从分镜到图 | 每个分镜能生成多个候选漫画图 |
| 人工可控 | 用户能编辑分镜、选择候选、锁定结果 |
| 可导出 | 能导出漫画页面 PNG/PDF 和素材包 |
| 可追溯 | 每个导出物能追溯到项目、章节、分镜、候选和任务输入 |

## 7. 产品风险

| 风险 | 说明 | 应对 |
| --- | --- | --- |
| 角色一致性不足 | 多张图中角色外观漂移 | 先用角色模板、参考图、锁定候选和提示词约束；高级一致性后置 |
| 分镜不可控 | AI 生成的镜头不符合创作者意图 | 分镜必须可编辑，支持逐镜头重生成 |
| 视频范围失控 | 轻漫剧生成容易膨胀成复杂视频工具 | 分镜阶段只保存基础漫剧镜头字段；成片、TTS、字幕、剪辑和复杂运镜后置 |
| 素材混乱 | 多候选、多版本容易丢关系 | 从第一天建立 Asset、GenerationTask、Candidate 关系 |
| 长篇创作失控 | 多章节内容如果只存在一份项目级文本中，后续结构化和分镜会混乱 | 将 Chapter 作为项目内一等工作单元，并把章节产物挂到 chapterId |
