## 1. 建模原则

- 中间产物必须可追溯，不能只保存最终图片或视频。
- AI 任务的输入输出必须留存，便于复跑、调试和版本比较。
- 图片、音频、视频、PDF 都统一抽象为 `Asset`。
- 生成候选与分镜之间通过 `Candidate` 连接。
- 当前锁定结果与历史候选分离，避免覆盖历史。

## 2. 实体关系图

```text
Project
  ├─ StoryVersion
  │    ├─ StoryBeat
  │    └─ Shot
  │         ├─ Candidate
  │         │    └─ Asset(image)
  │         └─ lockedCandidateId
  ├─ Character
  │    └─ Asset(reference image)
  ├─ SceneLocation
  │    └─ Asset(background/reference)
  ├─ GenerationTask
  │    ├─ inputJson
  │    └─ outputJson
  ├─ LayoutPage
  │    └─ PanelPlacement
  ├─ VideoDraft
  │    └─ VideoSegment
  └─ Asset
```

## 3. Project

项目容器，承载一个作品的全部故事、分镜、素材和导出物。

```json
{
  "id": "project_001",
  "name": "月下旅人",
  "type": "comic",
  "status": "draft",
  "storyTitle": "月下旅人：第一话",
  "genreTags": ["悬疑", "都市"],
  "comicFormat": "vertical_scroll",
  "artStyle": "dark_realistic",
  "currentStoryVersionId": "story_v001",
  "createdAt": "2026-05-23T00:00:00.000Z",
  "updatedAt": "2026-05-23T00:00:00.000Z"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 项目 ID |
| `name` | string | 项目名称 |
| `type` | enum | `comic/light_motion/mixed` |
| `status` | enum | `draft/story_ready/shots_ready/images_ready/layout_ready/exported` |
| `storyTitle` | string | 故事标题，用于项目内创作和故事版本默认标题 |
| `genreTags` | string[] | 题材标签或类型标签，创建项目时保存，项目库卡片当前不展示 |
| `comicFormat` | enum | `vertical_scroll/page_horizontal/four_panel` |
| `artStyle` | enum | `dark_realistic/semi_realistic/japanese_realistic/comic_style/cyberpunk/custom` |
| `currentStoryVersionId` | string | 当前故事版本 |

当前开发阶段还没有接入数据库持久化，项目创建和草稿保存先由后端维护进程内 `Project`，并同步写入本地 workspace：

```text
workspace/projects/{projectId}/project.json
workspace/projects/{projectId}/story/story_draft.source.txt
```

草稿保存接口：

```text
PATCH /api/projects/{projectId}
```

请求字段：

```json
{
  "name": "迷雾之城",
  "storyTitle": "迷雾之城：第一话",
  "genreTags": ["悬疑", "都市"],
  "comicFormat": "vertical_scroll",
  "artStyle": "dark_realistic",
  "description": "迷雾之城：第一话",
  "sourceText": "故事原文"
}
```

响应返回更新后的 `ProjectListItem` 和 `WorkbenchSnapshot`。

## 4. StoryVersion

保存故事原文和结构化剧情。

```json
{
  "id": "story_v001",
  "projectId": "project_001",
  "version": 1,
  "sourceText": "故事原文",
  "summary": "一句话摘要",
  "structureJson": {
    "characters": [],
    "scenes": [],
    "beats": []
  },
  "status": "structured"
}
```

| 状态 | 含义 |
| --- | --- |
| `draft` | 只有原文 |
| `structured` | 已结构化 |
| `shots_generated` | 已生成分镜 |
| `archived` | 历史版本 |

## 5. StoryBeat

剧情节拍，是分镜生成的上游语义单元。

```json
{
  "id": "beat_001",
  "storyVersionId": "story_v001",
  "order": 1,
  "sceneId": "scene_001",
  "summary": "主角进入雨夜街道",
  "characters": ["char_hero"],
  "emotionalTone": "lonely",
  "dialogueHints": []
}
```

## 6. Character

角色模板，约束图片生成一致性。

```json
{
  "id": "char_hero",
  "projectId": "project_001",
  "name": "林舟",
  "role": "protagonist",
  "appearance": "黑发，短外套，神情克制",
  "personality": "冷静，敏感",
  "referenceAssetIds": ["asset_char_ref_001"],
  "promptFragment": "young man, black hair, short jacket"
}
```

## 7. SceneLocation

场景或地点模板。

```json
{
  "id": "scene_001",
  "projectId": "project_001",
  "name": "雨夜街道",
  "description": "潮湿的老城区街道，路灯昏黄",
  "timeOfDay": "night",
  "mood": "quiet, melancholy",
  "referenceAssetIds": []
}
```

## 8. Shot

分镜单元，是图片生成和排版的核心。

```json
{
  "id": "shot_001",
  "projectId": "project_001",
  "storyVersionId": "story_v001",
  "beatId": "beat_001",
  "shotNumber": 1,
  "sceneId": "scene_001",
  "characterIds": ["char_hero"],
  "action": "林舟站在雨夜街口抬头看灯",
  "dialogue": "",
  "caption": "雨越下越密。",
  "camera": "medium shot, slight low angle",
  "composition": "character left third, street depth on right",
  "emotion": "lonely",
  "promptDraft": "comic panel, rainy old street at night...",
  "lockedCandidateId": null,
  "status": "draft"
}
```

| 状态 | 含义 |
| --- | --- |
| `draft` | 初始生成或编辑中 |
| `ready_for_image` | 可用于图片生成 |
| `image_generated` | 已有候选图 |
| `locked` | 已锁定候选图 |
| `needs_revision` | 需要重改 |

## 9. GenerationTask

所有 AI 和导出任务的统一记录。

```json
{
  "id": "task_001",
  "projectId": "project_001",
  "type": "image_generate",
  "status": "running",
  "targetType": "shot",
  "targetId": "shot_001",
  "inputJson": {},
  "outputJson": null,
  "errorJson": null,
  "attempt": 1,
  "createdAt": "2026-05-23T00:00:00.000Z",
  "startedAt": "2026-05-23T00:00:01.000Z",
  "finishedAt": null
}
```

任务类型见 `文档/02_架构与契约/生成任务协议.md`。

## 10. Candidate

候选结果，通常关联一个分镜和一个图片 Asset。

```json
{
  "id": "candidate_001",
  "projectId": "project_001",
  "shotId": "shot_001",
  "taskId": "task_001",
  "assetId": "asset_img_001",
  "index": 1,
  "status": "generated",
  "score": null,
  "notes": ""
}
```

| 状态 | 含义 |
| --- | --- |
| `generated` | 已生成 |
| `selected` | 当前选中 |
| `locked` | 锁定用于分镜 |
| `rejected` | 废弃 |
| `superseded` | 被替代 |

## 11. Asset

统一素材记录。

```json
{
  "id": "asset_img_001",
  "projectId": "project_001",
  "type": "image",
  "mimeType": "image/png",
  "path": "projects/project_001/assets/images/shot_001/candidate_001.png",
  "width": 1024,
  "height": 1536,
  "durationMs": null,
  "sourceTaskId": "task_001",
  "metadataJson": {}
}
```

| 类型 | 说明 |
| --- | --- |
| `image` | 漫画图、参考图、背景图 |
| `audio` | TTS、BGM、音效 |
| `video` | MP4、预览视频 |
| `document` | PDF、JSON、字幕、manifest |
| `archive` | 素材包 |

## 12. LayoutPage 与 PanelPlacement

漫画排版模型。

```json
{
  "id": "layout_page_001",
  "projectId": "project_001",
  "pageNumber": 1,
  "format": "vertical_comic",
  "width": 1440,
  "height": 2560,
  "placements": [
    {
      "shotId": "shot_001",
      "candidateId": "candidate_001",
      "x": 0,
      "y": 0,
      "w": 720,
      "h": 640
    }
  ]
}
```

## 13. VideoDraft 与 VideoSegment

轻漫剧基础视频模型。

```json
{
  "id": "video_draft_001",
  "projectId": "project_001",
  "name": "第一版轻漫剧",
  "status": "draft",
  "segments": [
    {
      "shotId": "shot_001",
      "assetId": "asset_img_001",
      "subtitle": "雨越下越密。",
      "ttsAssetId": "asset_audio_001",
      "durationMs": 3000,
      "transition": "fade"
    }
  ]
}
```

## 14. 最小数据库实现建议

MVP 第一版可以先落以下表：

1. `Project`
2. `StoryVersion`
3. `Character`
4. `SceneLocation`
5. `Shot`
6. `GenerationTask`
7. `Candidate`
8. `Asset`
9. `LayoutPage`

`StoryBeat`、`PanelPlacement`、`VideoSegment` 可先以 JSON 字段嵌入，等查询需求明确后再拆表。
