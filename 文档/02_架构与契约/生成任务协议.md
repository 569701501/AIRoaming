## 1. 协议目标

生成任务协议定义所有 AI 和导出任务的统一输入、输出、状态和错误格式。无论后续接云端 API、本地模型还是 FFmpeg，都必须通过任务协议与业务系统交互。

## 2. 统一任务信封

```json
{
  "taskId": "task_001",
  "projectId": "project_001",
  "type": "image_generate",
  "target": {
    "type": "shot",
    "id": "shot_001",
    "chapterId": "chapter_001"
  },
  "input": {},
  "options": {
    "candidateCount": 4,
    "provider": "default"
  },
  "trace": {
    "requestedBy": "user_001",
    "source": "web"
  }
}
```

`target.type` 可以是 `project`、`chapter`、`story`、`shot`、`asset` 或 `export`。凡是处理章节内产物的任务，都必须携带 `chapterId`，避免后续生成结果只挂到项目级而无法追溯到具体章节。

当前已强制 `chapterId` 的章节作用域任务：

```text
story_parse
shot_generate
shot_prompt_generate
image_generate
layout_export
```

创建上述任务时，`target.chapterId` 必须存在。`input.chapterId` 建议同步传入；如果省略，服务端会按 `target.chapterId` 规范化写回任务输入；如果传入但与 `target.chapterId` 不一致，服务端必须拒绝创建任务。

暂不强制单个 `chapterId` 的任务：

| 类型 | 原因 |
| --- | --- |
| `asset_package_export` | 可按项目导出，也可携带多个 `chapterIds` 导出章节子集 |
| `tts_generate` / `video_export` | 属于 P0.5 轻漫剧链路，等视频草稿模型接入后再决定是否强制章节作用域 |

## 3. 统一任务输出

```json
{
  "taskId": "task_001",
  "status": "succeeded",
  "outputs": [],
  "usage": {
    "provider": "default",
    "model": "unknown",
    "inputTokens": 0,
    "outputTokens": 0,
    "cost": null
  },
  "warnings": []
}
```

## 4. 错误格式

```json
{
  "taskId": "task_001",
  "status": "failed",
  "error": {
    "code": "PROVIDER_TIMEOUT",
    "message": "图片生成服务超时",
    "retryable": true,
    "details": {}
  }
}
```

## 5. 任务类型总表

| 类型 | 输入 | 输出 | MVP |
| --- | --- | --- | --- |
| `story_parse` | 当前章节剧本 | 结构化剧情 JSON | 是 |
| `shot_generate` | 用户已确认的当前章节结构化剧情 | 分镜数组 | 是 |
| `shot_prompt_generate` | 分镜 + 角色 + 场景 + 风格 | 图片提示词 | 是 |
| `image_generate` | 分镜提示词 + 参考图 | 候选图片 Asset | 是 |
| `layout_export` | 已锁定候选 + 页面模板 | PNG/PDF Asset | 是 |
| `tts_generate` | 文本 + 声音配置 | 音频 Asset | P0.5 |
| `video_export` | 图片序列 + 字幕 + 音频 | MP4 Asset | P0.5 |
| `asset_package_export` | 项目范围和导出选项 | ZIP/文件夹 Asset | 是 |

## 6. story_parse

### 输入

```json
{
  "chapterId": "chapter_001",
  "sourceText": "当前章节剧本正文",
  "mode": "faithful",
  "language": "zh-CN"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `chapterId` | string | 当前章节 ID；剧情结构逐章生成，不能省略或用项目级结构替代 |
| `sourceText` | string | 当前章节原始剧本文本 |
| `mode` | enum | `faithful/dramatic/comic_pacing` |
| `language` | string | 语言 |

前置条件：

- `chapterId` 对应章节必须至少处于 `script_done`，且存在非空章节剧本正文。
- `draft` 章节不能运行 `story_parse`，应提示用户先完成本章剧本。
- 对 `structured` 及后续状态章节重新运行 `story_parse` 前，必须提示会影响后续分镜、候选图和排版。

### 输出

```json
{
  "title": "故事标题",
  "summary": "一句话摘要",
  "characters": [],
  "scenes": [],
  "beats": [
    {
      "id": "beat_001",
      "order": 1,
      "summary": "剧情节拍",
      "sceneName": "场景名",
      "characterNames": [],
      "visualFocus": "轻量画面重点",
      "dialogueHints": []
    }
  ]
}
```

### 验收

- 输出必须包含 `summary`、`characters`、`scenes`、`beats`。
- 输出只描述当前 `chapterId` 对应章节，不一次性输出整本剧本的结构。
- `characters` 和 `scenes` 默认是本章结构卡，不自动写入项目级角色库或场景库。
- `beats` 必须有稳定顺序。
- `beats` 表示关键剧情事件，不和最终分镜或镜头一一对应；一个 beat 后续可拆成多个 shot。
- `beats.visualFocus` 只写轻量画面重点，不写镜头编号、景别、机位、构图或完整分镜稿。
- 不允许只输出自然语言总结。
- AI 生成后必须由用户确认，确认后的结构化剧情才能作为 `shot_generate` 输入。
- 待确认结构可以在右侧预览，但不能作为 `shot_generate` 输入。
- 用户确认结构后，当前章节状态推进到 `structured`，并绑定当前 `StoryVersion`。

## 7. shot_generate

### 输入

```json
{
  "chapterId": "chapter_001",
  "storyVersionId": "story_v001",
  "structureJson": {},
  "styleIntent": "漫画分镜，节奏清晰",
  "shotDensity": "medium"
}
```

### 输出

```json
{
  "shots": [
    {
      "order": 1,
      "beatId": "beat_001",
      "sceneId": "scene_001",
      "characterIds": ["林舟"],
      "coreAction": "林舟站在街口抬头看灯",
      "emotion": "lonely",
      "comic": {
        "panelDescription": "雨夜街口，林舟抬头看向忽明忽暗的路灯。",
        "composition": "中景，人物位于左三分之一",
        "dialogue": "",
        "caption": "雨越下越密。",
        "panelRhythm": "慢节奏停顿"
      },
      "motion": {
        "visualDescription": "雨线和路灯微闪，林舟缓慢抬头。",
        "compositionDesign": "中景，平视",
        "cameraMovement": "轻微推近",
        "voiceRole": "",
        "line": "",
        "durationHint": "约 2-4s",
        "frameType": "氛围镜头"
      },
      "promptDraft": "雨夜街口，孤独人物，路灯微闪"
    }
  ],
  "notes": "按剧情节拍拆分镜头，保留漫画和漫剧两套表达字段。"
}
```

### 验收

- 每个 shot 必须有 `order/coreAction/comic/motion`。
- shot 顺序必须连续。
- shot 可追溯到 `beatId`，如果无法追溯要写 `sourceNote`。
- AI 生成结果先写入 `storyboard.pending.json` 作为待确认预览；用户确认后才写入正式 `storyboard.json`。
- `shot_prompt_generate`、候选图和排版只能读取已确认的正式分镜。

## 8. shot_prompt_generate

### 输入

```json
{
  "chapterId": "chapter_001",
  "shot": {},
  "characters": [],
  "scene": {},
  "style": {
    "name": "clean manga",
    "colorMode": "full_color",
    "lineArt": "clean"
  }
}
```

### 输出

```json
{
  "positivePrompt": "comic panel, rainy old street...",
  "negativePrompt": "low quality, extra fingers...",
  "promptParts": {
    "character": "",
    "scene": "",
    "action": "",
    "camera": "",
    "style": ""
  }
}
```

### 验收

- 提示词必须显式包含角色、场景、动作、镜头和风格。
- 不允许丢失用户手动编辑的分镜字段。

## 9. image_generate

### 输入

```json
{
  "chapterId": "chapter_001",
  "shotId": "shot_001",
  "positivePrompt": "comic panel...",
  "negativePrompt": "low quality...",
  "referenceAssetIds": [],
  "candidateCount": 4,
  "image": {
    "width": 1024,
    "height": 1536
  }
}
```

### 输出

```json
{
  "candidates": [
    {
      "index": 1,
      "asset": {
        "type": "image",
        "mimeType": "image/png",
        "path": "projects/project_001/chapters/chapter-001/candidates/shot_001/candidate_001.png",
        "width": 1024,
        "height": 1536
      },
      "providerMetadata": {}
    }
  ]
}
```

### 验收

- 生成数量等于 `candidateCount` 或在 warnings 中说明原因。
- 每个候选必须注册为 `Asset` 和 `Candidate`。
- 失败时保留 provider 错误和输入。

## 14. 重试规则

| 错误码 | 是否可重试 | 说明 |
| --- | --- | --- |
| `PROVIDER_TIMEOUT` | 是 | provider 超时 |
| `PROVIDER_RATE_LIMIT` | 是 | 限流 |
| `INVALID_INPUT` | 否 | 输入不合法 |
| `GENERATION_TASK_CHAPTER_ID_REQUIRED` | 否 | 章节作用域任务缺少 `target.chapterId` |
| `GENERATION_TASK_CHAPTER_ID_MISMATCH` | 否 | `input.chapterId` 与 `target.chapterId` 不一致 |
| `GENERATION_TASK_INPUT_CHAPTER_ID_INVALID` | 否 | `input.chapterId` 非字符串或为空 |
| `ASSET_WRITE_FAILED` | 视情况 | 文件写入失败 |
| `USER_CANCELLED` | 否 | 用户取消 |

## 15. 任务事件

```json
{
  "event": "task.progress",
  "taskId": "task_001",
  "projectId": "project_001",
  "progress": 0.5,
  "message": "正在生成第 2 张候选图"
}
```

事件类型必须与 `系统架构总览.md` 中的事件表保持一致。
