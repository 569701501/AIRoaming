## 1. 协议目标

生成任务协议定义所有 AI 和导出任务的统一输入、输出、状态和错误格式。无论后续接云端 API、本地模型还是 FFmpeg，都必须通过任务协议与业务系统交互。

## 2. 统一任务信封

```json
{
  "taskId": "task_001",
  "projectId": "project_001",
  "type": "image_generate",
  "target": {
    "type": "shot",
    "id": "shot_001"
  },
  "input": {},
  "options": {
    "candidateCount": 4,
    "provider": "default"
  },
  "trace": {
    "requestedBy": "user_001",
    "source": "web"
  }
}
```

## 3. 统一任务输出

```json
{
  "taskId": "task_001",
  "status": "succeeded",
  "outputs": [],
  "usage": {
    "provider": "default",
    "model": "unknown",
    "inputTokens": 0,
    "outputTokens": 0,
    "cost": null
  },
  "warnings": []
}
```

## 4. 错误格式

```json
{
  "taskId": "task_001",
  "status": "failed",
  "error": {
    "code": "PROVIDER_TIMEOUT",
    "message": "图片生成服务超时",
    "retryable": true,
    "details": {}
  }
}
```

## 5. 任务类型总表

| 类型 | 输入 | 输出 | MVP |
| --- | --- | --- | --- |
| `story_parse` | 故事原文 | 结构化剧情 JSON | 是 |
| `shot_generate` | 结构化剧情 | 分镜数组 | 是 |
| `shot_prompt_generate` | 分镜 + 角色 + 场景 + 风格 | 图片提示词 | 是 |
| `image_generate` | 分镜提示词 + 参考图 | 候选图片 Asset | 是 |
| `layout_export` | 已锁定候选 + 页面模板 | PNG/PDF Asset | 是 |
| `tts_generate` | 文本 + 声音配置 | 音频 Asset | P0.5 |
| `video_export` | 图片序列 + 字幕 + 音频 | MP4 Asset | P0.5 |
| `asset_package_export` | 项目范围和导出选项 | ZIP/文件夹 Asset | 是 |

## 6. story_parse

### 输入

```json
{
  "sourceText": "故事原文",
  "mode": "faithful",
  "language": "zh-CN"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sourceText` | string | 原始故事文本 |
| `mode` | enum | `faithful/dramatic/comic_pacing` |
| `language` | string | 语言 |

### 输出

```json
{
  "title": "故事标题",
  "summary": "一句话摘要",
  "characters": [],
  "scenes": [],
  "beats": [
    {
      "id": "beat_001",
      "order": 1,
      "summary": "剧情节拍",
      "sceneName": "场景名",
      "characterNames": [],
      "dialogueHints": []
    }
  ]
}
```

### 验收

- 输出必须包含 `summary`、`characters`、`scenes`、`beats`。
- `beats` 必须有稳定顺序。
- 不允许只输出自然语言总结。

## 7. shot_generate

### 输入

```json
{
  "storyVersionId": "story_v001",
  "structureJson": {},
  "styleIntent": "漫画分镜，节奏清晰",
  "shotDensity": "medium"
}
```

### 输出

```json
{
  "shots": [
    {
      "shotNumber": 1,
      "beatId": "beat_001",
      "sceneName": "雨夜街道",
      "characters": ["林舟"],
      "action": "林舟站在街口抬头看灯",
      "dialogue": "",
      "caption": "雨越下越密。",
      "camera": "medium shot, slight low angle",
      "composition": "character left third",
      "emotion": "lonely"
    }
  ]
}
```

### 验收

- 每个 shot 必须有 `shotNumber/action/camera`。
- shot 顺序必须连续。
- shot 可追溯到 `beatId`，如果无法追溯要写 `sourceNote`。

## 8. shot_prompt_generate

### 输入

```json
{
  "shot": {},
  "characters": [],
  "scene": {},
  "style": {
    "name": "clean manga",
    "colorMode": "full_color",
    "lineArt": "clean"
  }
}
```

### 输出

```json
{
  "positivePrompt": "comic panel, rainy old street...",
  "negativePrompt": "low quality, extra fingers...",
  "promptParts": {
    "character": "",
    "scene": "",
    "action": "",
    "camera": "",
    "style": ""
  }
}
```

### 验收

- 提示词必须显式包含角色、场景、动作、镜头和风格。
- 不允许丢失用户手动编辑的分镜字段。

## 9. image_generate

### 输入

```json
{
  "shotId": "shot_001",
  "positivePrompt": "comic panel...",
  "negativePrompt": "low quality...",
  "referenceAssetIds": [],
  "candidateCount": 4,
  "image": {
    "width": 1024,
    "height": 1536
  }
}
```

### 输出

```json
{
  "candidates": [
    {
      "index": 1,
      "asset": {
        "type": "image",
        "mimeType": "image/png",
        "path": "projects/project_001/assets/images/shot_001/candidate_001.png",
        "width": 1024,
        "height": 1536
      },
      "providerMetadata": {}
    }
  ]
}
```

### 验收

- 生成数量等于 `candidateCount` 或在 warnings 中说明原因。
- 每个候选必须注册为 `Asset` 和 `Candidate`。
- 失败时保留 provider 错误和输入。

## 14. 重试规则

| 错误码 | 是否可重试 | 说明 |
| --- | --- | --- |
| `PROVIDER_TIMEOUT` | 是 | provider 超时 |
| `PROVIDER_RATE_LIMIT` | 是 | 限流 |
| `INVALID_INPUT` | 否 | 输入不合法 |
| `ASSET_WRITE_FAILED` | 视情况 | 文件写入失败 |
| `USER_CANCELLED` | 否 | 用户取消 |

## 15. 任务事件

```json
{
  "event": "task.progress",
  "taskId": "task_001",
  "projectId": "project_001",
  "progress": 0.5,
  "message": "正在生成第 2 张候选图"
}
```

事件类型必须与 `系统架构总览.md` 中的事件表保持一致。
