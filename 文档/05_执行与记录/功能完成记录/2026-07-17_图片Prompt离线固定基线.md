# 图片 Prompt 离线固定基线完成记录

## 功能摘要

为角色参考图、场景参考图和候选图建立可供后续真实视觉 A/B 直接复用的机器可读固定语料与离线编译报告；不调用真实图片服务，不修改生产 Prompt。

## 影响范围

- 新增 3 个角色/场景参考 Prompt 案例。
- 新增无角色远景、单人近景、双人对话、多人群像、场景特效 5 类候选镜头。
- 每个候选镜头编译 OpenAI、Doubao、Grok 三个 provider profile。
- 固定后续真实验收规模为 30 张，但当前保持 `not_run`。

## 已知风险

- 离线通过不代表真实图片的人物、场景、构图或审美质量通过。
- 多人参考图省略策略必须在真实 task output/warnings 中核对。
- Prompt 不能保证模型绝不生成乱码或气泡，最终仍需人工选图。

## 后续建议

不要继续无证据地增加图片 Prompt 规则。用户授权后直接按固定 30 张矩阵执行 S4 真实视觉 A/B，并按 provider 独立决定放行或保守降级。
