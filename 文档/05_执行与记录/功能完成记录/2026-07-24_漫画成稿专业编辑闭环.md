# 漫画成稿专业编辑闭环完成记录

## 1. 功能摘要

完成漫画成稿 P0/P1/P2：`LayoutDocumentV2` 已能经过预检保存为不可变 Revision、恢复、替换正式图片来源并出版；Web 以 Konva 作为纯交互适配器，显性开放既有气泡、富文本、SFX 和图层能力，同时保持 V1 历史与在途出版兼容。

## 3. 完成内容

- Shared 提供 V1/V2 Revision、Preflight、Publication、RenderPlan、Manifest 与 Source Replacement 联合合同。
- V2 正式身份同时冻结完整 `revisionDocumentDigest` 与 V1 可见投影 `visibleDocumentDigest`。
- V2 预检覆盖对白闭合、来源/锁集合 freshness、composition provenance、source override、保护范围和可见投影稳定性。
- 同一 Shot 的所有 appearance 通过一个用户 CommandBatch 原子替换到同一 CandidateLockRevision，并保留 automation/protections。
- Prisma migration `0019_layout_revision_v2_publication` 以 forward-only 方式增加双摘要与 V1/V2 状态约束；历史 V1 不回填、不改写。
- Publication worker 从数据库 sealed source rows 重建来源投影、精确校验 schema policy/consumer 并重算双摘要后渲染。
- Web 加入 Pending 权威完整预览、桌面/手机正式预览、显式双预检与 Revision/Publication 控制。
- 固定 `konva@10.3.0` 为 Web 交互层；选择、框选、多选、拖动、缩放、吸附、裁切、尾巴与 viewport 手势最终只提交 Shared command/batch。
- 气泡、文字/SFX、图层面板开放 V2 已有字段；未增加滤镜、阴影、发光、新轮廓或图层命名等 V3 字段。

## 6. 数据或协议变化

- `LayoutRevision` 增加 `visible_document_digest`；`ExportRevision` 增加完整与可见双摘要。
- V1 仍使用原 wire shape；其可见摘要等于完整摘要。
- V2 Revision 保存完整 automation、dialogueBindings、dispositions、protections，并另存 V2→V1 可见投影摘要。
- V2 publication task/RenderPlan/Manifest 绑定 schema、kind、双摘要、source lock-set、preflight 与规范化 warning acknowledgement。
- 来源 policy 固定为 `layout-publication-source-v1` / `layout-publication-source-v2`，consumer 固定为 `layout_export`。
- V2 Working Copy 可以恢复 V1/V2 Revision，但恢复 V1 时升级为 V2；禁止降级为 V1。
- Konva node、selection、viewport、cache、scale 和 history 不进入正式文档或数据库。

## 8. 已知风险

- 浏览器验收图片来自 `1×1 PNG` fake provider，能证明真实状态/接口/worker/产物接线，不能替代真实漫画素材的美术质量验收。
- Pending 当前要求用户展开完整视觉预览，但尚未把图片/字体 render-ready 或滚动到底设为应用硬门。
- 成功 E2E 偶见已取消图片流的 `ERR_STREAM_PREMATURE_CLOSE` 日志，未影响页面、任务和产物。
- 更细的 V2 migration trigger 摘要错绑/来源篡改负向矩阵可继续补强；现有 API 校验、worker 独立重算和不可变 trigger 已通过。

## 9. 后续建议

1. 用真实漫画素材做 P3 视觉质量验收，评估 crop、旋转、富文本、气泡尾巴和移动端阅读效果。
2. 只有在新 ADR 和 `LayoutDocumentV3` 合同完成后，再进入滤镜、网点、阴影、发光、新气泡轮廓与图层命名。
3. 为 Pending 预览增加 render-ready/加载失败状态，并降低取消图片流的日志噪声。
4. 补充 V2 migration trigger 的篡改负向矩阵和更多 P2 保存→刷新→恢复 UI E2E。
