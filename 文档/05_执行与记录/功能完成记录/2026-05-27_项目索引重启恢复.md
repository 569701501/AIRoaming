## 功能摘要

后端启动或首次访问项目接口时，会从本地 `workspace/projects/*` 恢复项目索引，避免服务重启后项目库丢失已有项目。

## 背景

当前数据库持久化尚未接入，项目 API 运行时依赖进程内 `Map`。此前创建项目时虽然已写入 `project.json`、`chapter.json` 和 `script.md`，但服务重启后没有反向扫描 workspace，导致项目库为空、直接进入工作台返回 `PROJECT_NOT_FOUND`。

## 影响范围

- `GET /api/projects` 改为异步读取，确保项目列表可在启动后恢复。
- `ProjectsService` 实现启动加载和懒加载保护，从 `workspace/projects/{projectId}/project.json` 恢复项目。
- 恢复章节列表、当前章节、章节状态、章节正文和章节剧本版本文件。
- `GET /api/projects/{projectId}/workbench`、章节接口、草稿保存、完成本章和删除项目都通过恢复后的项目索引工作。
- 工作台阶段 evidence 改为指向当前章节脚本，而不是固定 `chapter-001`。

## 修改文件

- `apps/server/src/projects/projects.service.ts`
- `apps/server/src/projects/projects.controller.ts`
- `文档/02_架构与契约/核心数据模型.md`
- `文档/02_架构与契约/素材文件与版本契约.md`

## 数据或协议变化

未新增前端 API 契约。新增后端运行时恢复规则：

```text
workspace/projects/{projectId}/project.json
workspace/projects/{projectId}/chapters/{chapterSlug}/chapter.json
workspace/projects/{projectId}/chapters/{chapterSlug}/script.md
workspace/projects/{projectId}/chapters/{chapterSlug}/script.versions/script-vNNN.md
```

这些文件在数据库接入前同时承担本地恢复源职责。

## 验证结果

```text
corepack pnpm typecheck
corepack pnpm --filter @airoaming/web build
git diff --check
```

结果：通过。

临时 server 验证：

```text
PORT=4341 AIROAMING_WORKSPACE_ROOT=/tmp/airoaming-project-loss.eq5gRv OPENCODE_AUTO_START=false corepack pnpm --filter @airoaming/server dev
POST /api/projects
PATCH /api/projects/{projectId}/chapters/chapter_001/draft
重启服务
GET /api/projects
GET /api/projects/{projectId}/workbench
GET /api/projects/{projectId}/chapters/chapter_001
POST /api/projects/{projectId}/chapters/chapter_001/complete
再次重启服务
GET /api/projects/{projectId}/chapters
GET /api/projects/{projectId}/workbench?chapterId=chapter_002
```

结果：

- 重启后项目库仍列出已创建项目。
- 工作台可读取当前章节正文。
- 章节详情可读取 `chapter_001`。
- 完成本章后创建的 `chapter_002` 在再次重启后仍存在，并可作为当前章节打开。

## 风险

- 当前仍未接数据库，恢复依赖本地 workspace 文件完整性。
- 对话线程和任务队列仍是进程内数据，本次只解决项目与章节索引恢复。
- 若某个项目目录中的 JSON 损坏，后端会跳过该项目并记录 warning，后续可补项目修复工具或孤儿文件扫描。

## 后续建议

- 接入 SQLite 后，将 `Project`、`Chapter`、`ChapterScriptVersion` 作为正式数据库事实源，workspace 保持文件实体和导出物事实源。
- 为项目恢复链路补自动化集成测试，覆盖项目创建、保存章节、服务重启、章节列表和工作台读取。
