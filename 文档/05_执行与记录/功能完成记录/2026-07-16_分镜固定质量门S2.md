# 分镜固定质量门 S2 完成记录

## 功能摘要

在不改页面字段、数据库 Schema、Storyboard payload 和用户确认流程的前提下，为分镜首次生成与调整待确认草稿增加：

- 新 AI 输出严格契约；
- 高确定性固定质量门；
- JSON、字段、质量和引用错误共用的一次定向修复；
- 二次失败不写入 pending 的失败关闭。

## 影响范围

| 范围 | 影响 |
| --- | --- |
| 分镜对话服务 | 生成/调整的新 AI 输出经统一校验和一次修复 |
| 分镜 JSON 解析 | 生产输出在兼容 normalize 前严格校验 |
| 固定质量规则 | 检查 coverage/order/beat-scene/required/duplicate/comic-motion/promptDraft |
| 测试 fake-provider | 按确认结构动态生成分镜，支持首次漏 beat 模式 |
| 页面与数据 | 无字段、Schema、确认节点或公开 Skill 变化 |

## 已知风险

- 固定门不判断主观艺术质量、商业节奏或构图美感。
- 本轮没有调用真实文本模型或图片 provider；S3/S4 需用户分别明确授权。
- 完整 DB 矩阵运行期间出现两条已知资产下载取消的 `Premature close` 日志，测试全绿，与 S2 分镜校验无关。

## 后续建议

1. 若授权真实文本模型，执行 S3：分别用 AI 创作和 import 正式 StoryVersion 验收同一分镜 Prompt。
2. 若授权真实图片 provider，执行 S4：分 provider/profile 做固定镜头图片评测。
