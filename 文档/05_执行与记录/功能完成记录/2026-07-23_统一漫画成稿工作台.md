# 统一漫画成稿工作台完成记录

## 1. 功能摘要

“漫画成稿”已形成一条普通用户可直接使用的连续路径：

```text
候选图全部确认
  -> 首次进入自动生成完整 V2 成稿
  -> 直接进入现有正式编辑器
  -> 手动调整并自动保存
  -> 不满意时整章重新排一版
  -> 对比当前稿与新排法
  -> 保留 / 应用 / 一次撤销
```

首次进入不再要求选择模板、画布尺寸或创建数据库草稿；已有成稿时直接恢复，不会重复生成。人工确认不再是 158 项专业评分，而是对一版具体结果做“保留当前排法 / 使用这版新排法”的轻量决定。

## 2. 影响范围

- Shared：full reflow 可避开当前可见摘要，选择另一份合法且稳定的新排法。
- Server：composition create/status/apply 接入工作台；无变化 Pending 安全收口，不触发 no-op WC 写入。
- Web：V2 编辑会话、自动成稿状态机、当前/新排法可视对比、条漫/页漫统一入口。
- 产品文案：用户可见第 6 步统一为“漫画成稿”；内部 `layout_export` 和 publication 协议不改名。
- E2E：增加条漫与页漫零设置路径，并为旧 G5 E2E 提供 V1 Working Copy 初始化辅助。

## 4. 数据与协议变化

- 本阶段没有新增 migration；继续使用 M4 的 `0018_layout_document_v2_working_copy`。
- `LayoutWorkingCopyRecoveryV1.document` 扩展为 V1/V2 联合文档，恢复包可无损保存 V2 automation、dialogue binding 和 protection。
- 旧画布只消费 V2 的可见 V1 投影；保存、Undo/Redo 和 autosave 的业务事实仍是完整 V2。
- V1 编辑命令统一以 `actor=user` 应用到 V2 reducer；绑定气泡的删除/隐藏/恢复转为语义命令。
- full reflow 可携带当前可见 document digest 作为避让条件；候选质量规则和稳定排序不变。
- Pending 结果与当前文档摘要相同时，apply 只把 Pending 标记为已应用，不增加 WC rowVersion。

## 7. 已知风险

- 生产 persistent worker 仍使用 `rule_fallback`，没有连接真实视觉分析 Provider。页面会诚实显示规则来源，不宣称已经看懂画面。
- 假图片 Provider 的黑色图片只验证业务路径，不能签收气泡形状、间距、主体保护和专业节奏。
- 用户已接受“部分气泡较丑或形状不自然”作为当前风险；同一编辑器可以手调。
- 场景、页面、段落和选区的 scoped reflow 尚未开放。
- V2 正式 Revision、来源替换、阅读预览和 publication 仍在 M7；当前 V2 顶部显示“导出（开发中）”。

## 8. 后续建议

1. M6 先接真实视觉分析 Provider，并做逐 Shot 超时/非法输出 fallback。
2. 再开放带明确 scope 和 protection 的局部调整。
3. 用真实漫画图优先改善气泡形状、外观、间距和页/段节奏。
4. M7 复用既有 renderer/publication，完成 V2 一键预览并导出，不建立第二套出版服务。
