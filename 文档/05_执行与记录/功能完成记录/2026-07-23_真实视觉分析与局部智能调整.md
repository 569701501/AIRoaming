# 真实视觉分析与局部智能调整完成记录

## 1. 功能摘要

“漫画成稿”在 M5 的完整初稿、同一编辑器和整章重排基础上，新增了安全的画面分析与局部调整：

```text
选择对象 / 当前页段 / 当前场景
  -> 读取当前定稿图与对白
  -> 逐 Shot 视觉分析，失败则规则回退
  -> 生成只影响所选叙事范围的细粒度修改
  -> 保留手调和锁定字段
  -> 对比当前稿与新排法
  -> 保留 / 应用 / 一次撤销
```

人工修改后的对象默认受保护。用户明确希望系统重新接手时，可对当前选中对象使用“允许智能再次调整”；该动作只清除智能保护，不解除显式锁定。

## 2. 影响范围

- Shared：局部 scope 解析、安全命令计划、高权重关键区域裁切/避让、composition 输出追溯。
- Server：受限图片附件、视觉 Asset 安全读取、严格分析 adapter、逐 Shot fallback、历史分析复用和 worker 接线。
- Web：同一工作台的选区/页段/场景入口、四种调整意图、预览提示和保护释放。
- E2E：条漫选中画格的预览/应用/Undo/释放保护；页漫当前页的预览/放弃。

## 4. 数据与协议变化

- 没有新增数据库 migration。
- `LayoutCompositionFrozenSourceV1` 新增可空 `visualAnalysisProvider`，只保存 `providerId/modelId`；旧任务缺字段时按 null 兼容。
- `LayoutCompositionTaskOutputV1` 新增 `visualAnalyses`，报告 `analysisMode` 扩展为 `vision/mixed/rule_fallback`；旧 output 缺字段时按空数组兼容。
- 缓存身份固定为 `assetId + assetDigest`。任务输出不包含 API Key、base URL、secretRef、Authorization、绝对路径、原图字节或 Provider 原始响应。
- scoped reflow 使用既有 `canvasIds/elementIds/shotIds`：canvas 对应页/段，element 扩完整 NarrativeGroup，纯 shot scope 扩同场景后再扩 NarrativeGroup。
- 局部智能首版只允许 geometry、crop、balloon style 和 tail，不改台词、来源、阅读顺序，不新增或删除对象。

## 5. 安全与失败回退

- 图片发送前逐项核对 DB ready Asset、storageKey 安全路径、realpath、字节数、SHA-256、尺寸和 MIME。
- 源图最大 50 MiB，只接受 PNG/JPEG/WebP；分析附件转为最大边 1536px 的 JPEG。
- Provider 只能使用 `StructuredOutput` 返回固定 Schema，不能直接写 Working Copy 或调用业务工具。
- 每个 Shot 独立超时；非法结构、越界、伪造角色映射、超时、失败或未配置时只回退该 Shot。
- 受保护或显式锁定字段逐项跳过并提示；其他安全变化仍可形成预览。
- preview、discard、apply、Undo 和 base/source stale 继续复用既有 Pending 与 CAS 边界。

## 7. Static/Scrutiny Review

结论：`passed`。

- 模型输出没有直达文档或像素坐标。
- scope 不存在或没有分镜对象时 fail-closed，不静默扩大为整章。
- 局部命令没有文字、来源、阅读顺序、增删对象等越权类型。
- protection 与 locked 分别检查；释放 protection 只允许 user actor，且不解除锁定。
- 视觉缓存绑定 Asset 摘要；输出敏感字段边界未放宽。
- full reflow 在存在人工保护时使用细粒度安全命令，不能整文档覆盖保护。

## 8. Runtime/User Review

结论：`passed`（功能和安全路径）。

- 条漫：选中画格后生成“更舒展”预览，预览前 WC 不变；应用后摘要变化；Undo 保存后恢复原摘要。
- 页漫：无选中对象时默认当前页；生成预览后保留当前排法，WC 摘要和行版本不变。
- 手调保护：手动对象出现“允许智能再次调整”；执行并保存后对应 protection 清除。
- 页面没有要求用户判断专业画格节奏，只需决定保留当前稿还是使用新稿。

## 9. 已知风险

- 本轮没有发起付费外部视觉调用。provider 接线、严格输出、回退和状态机已验证，但具体视觉模型对真实漫画的主体识别、气泡美观和节奏改善质量仍未验收。
- 无配置或不支持图片的当前文本模型会稳定回退到规则模式，功能仍可用，但不会获得视觉增强。
- 当前 focal region 能保护脸、手、武器、关键动作和关键物体的区域，但没有为这些类别分别持久化类型枚举。
- V2 来源替换、阅读预览、LayoutRevision、publication 和真实下载属于 M7。

## 10. 后续建议

1. M7 复用现有来源替换、renderer 与 publication，完成 V2 正式出版闭环。
2. 若未来需要评估具体多模态模型，先明确 Provider、模型、预算和最大调用数，再用少量真实章节抽样；不得用接线测试替代审美结论。
3. 继续保留规则 fallback 和人工编辑，不把视觉模型变成打开成稿页的单点故障。
