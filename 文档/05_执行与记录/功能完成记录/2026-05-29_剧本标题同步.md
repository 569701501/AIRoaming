## 功能摘要

修复剧本阶段的标题边界：`剧本名称` 表示作品/故事名，`第 X 章：章节标题` 表示当前章节名。AI 从灵感种子生成章节时，剧本名称使用选中的灵感标题；保存或 AI 写入后，正文里的章节标题会同步到 `Chapter.title`，顶部章节选择器与编辑器标题保持一致。

## 影响范围

| 范围 | 说明 |
| --- | --- |
| 固定章节剧本格式 | 在 `# 章节剧本` 下新增 `剧本名称：` 字段 |
| AI 生成章节 | `script-chapter-drafting` prompt 要求剧本名称使用选中的灵感标题 |
| AI 改写章节 | 保留已有剧本名称，章节标题变化时同步写回章节元数据 |
| 章节保存 | 保存草稿、完成本章、AI 写入都会从正文解析章节标题和剧本名称 |
| 项目事实 | 正文中的剧本名称可同步到 `Project.storyTitle` |
| 旧数据恢复 | 服务从 workspace 恢复项目时，也会从 `script.md` 解析剧本名称和章节标题 |

## 数据或协议变化

- `script.md` 固定格式新增用户可见行：`剧本名称：...`。
- 未新增 API 字段；后端从章节正文解析 `剧本名称` 和 `第 X 章：章节标题`，分别同步到 `Project.storyTitle` 和 `Chapter.title`。
- 旧的章节剧本文档仍兼容；没有 `剧本名称` 时不会阻止读取和保存。
- 已同步当前本地 workspace 中项目“测试 1”的第 1 章：`Project.storyTitle = 地铁尽头的倒影`，`Chapter.title = 第 1 章：黑站`，并在 `script.md` 中补入 `剧本名称：地铁尽头的倒影`。
