## 功能摘要

修复“确认分镜后才突然出现角色定稿要求、导致出图准备回头补图”的根因。角色视觉素材要求现在在剧情结构确认时固定，分镜和出图准备读取同一规则；出图准备恢复为缺项阻断的纯检查门。

## 影响范围

- Shared：新增角色视觉素材策略、满足关系和群体保守身份键。
- Server：结构角色映射、参考图任务、分镜引用范围、file/DB 预检、v2 来源快照、类型化 Prompt 装配。
- Web：剧情结构角色素材卡、出图准备检查、旧群体别名素材投影。
- OpenCodeAI：creature/group 单张参考模板。
- 文档：产品流程、数据契约、模块职责、测试矩阵和 ADR。

## 正式规则

| 主体 | 必需素材 |
| --- | --- |
| human + lead/recurring/chapter | final_reference |
| human + minor/extra | preview_front |
| creature/group | preview_front |
| voice | none |

`appearanceCount` 只展示，不参与判定。final 可满足 preview，反向不成立。

## 数据与协议变化

- 无数据库 migration、无 StoryStructure/Storyboard 新字段。
- 新 PreflightRevision 使用 `preflight-source-v2`。
- 历史 `preflight-source-v1` 仍可解析，但当前生产状态视为 stale。
- group 别名只在视觉素材身份层保守归并，不删除历史正式内容。
