## 1. 功能摘要

完成 AI漫游第一版 monorepo 工程骨架：`apps/web`、`apps/server`、`packages/shared`、Prisma SQLite schema 初稿和本地 workspace 占位目录。

## 2. 影响范围

| 范围 | 影响 |
| --- | --- |
| 工程结构 | 新增 pnpm workspace，分为 web、server、shared |
| 前端 | 新增 Vue/Vite 工作台壳、任务中心壳、Pinia store、API service |
| 后端 | 新增 NestJS 服务、健康检查、workspace 信息、任务 mock API |
| 共享契约 | 新增任务枚举、DTO、workspace 虚拟路径工具 |
| 数据模型 | 新增 Prisma schema 初稿，包含 Project、StoryVersion、Shot、Candidate、Asset、GenerationTask |
| 文档 | 更新 AI 上下文入口、任务记录和完成记录索引 |

## 6. 已知风险

- `GenerationTask` 当前是内存 mock，服务重启会丢失任务。
- Prisma schema 尚未迁移到数据库，也未接入 service。
- SSE 任务流尚未实现，前端目前通过刷新读取任务列表。
- 本地全局 `pnpm 7.12.1` 与 Node 22 有 registry 请求兼容问题，开发命令应使用 `corepack pnpm`。
- 当前未做浏览器截图验证，后续 UI 复杂化后需要补自动化截图。
