# 漫画成稿基础版收缩完成记录

## 功能摘要

漫画成稿已从包含二次 AI、撤销重做、版本中心和四步出版的专业工作台，收缩为首次无感自动排版、人工画布、自动保存和单一导出。对白与旁白准确性成为导出硬门：系统问题阻断，用户主动变化显示原文/当前文字并确认。

## 影响范围

- Shared V2 对白 preflight 与正式气泡显隐命令。
- Web 编辑 Session、首次 composition Session、富文本编辑器和成稿工作台。
- Web Publication 异步状态合并与精确重试。
- 产品、模块、ADR、验收、任务记录和长期记忆。
- 无数据库迁移，无 `LayoutDocumentV3`。

## 数据与协议变化

- V2 preflight 增加 `CUSTOM_TEXT_PRESENT` 与 `UNOWNED_TEXT_PRESENT`。
- 文字 issue details 增加 `dialogueItemId`、镜头/行顺序、说话者、类型、原文和当前文字。
- 现有数据库、V1 wire shape、Revision/Publication 和 renderer 协议保持兼容。

## 验证

- Shared：37 files / 257 tests passed。
- Web：55 / 55 passed。
- Server Layout：4 files / 11 tests passed。
- Shared、Web、Server typecheck passed。
- 真实浏览器：首次自动成稿、改字、自动保存、显隐恢复、差异确认、正式导出、重载恢复和只读预览 passed。
- 静态复核：无 S0/S1；复核指出的 Revision/Publication 恢复、提示文案和状态回退问题均已修复。

## 已知风险

- 具体编辑属性仍偏多，本轮未重新设计。
- 规则 fallback 的视觉初稿仍需人工检查和移动气泡。
- full/scoped Shared/Server 历史能力尚保留兼容代码，但普通 Web 已无入口且不会创建对应请求。

## 后续建议

- 下一轮只围绕“选择对象 → 移动/缩放 → 改字/显隐”真实任务简化属性区。
- 保持正式文字 preflight、双摘要和确定性出版为不可削弱边界。
- 不恢复二次 AI 排版、撤销重做或多步出版 UI。
