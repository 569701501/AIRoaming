# 2026-08-11 角色定妆前端 UI（阶段 1）

## 功能摘要

角色库（ProjectCharactersWorkspace）接入「定妆」功能，用户为角色生成并选定一张定妆照/锚点图：

- 未定妆角色（`anchorAssetId` 为空且非纯声音角色）显示琥珀色「待定妆」标签。
- 角色行新增「定妆照」图片槽位：已定妆显示锚点图（可点击放大预览），未定妆显示占位。
- 交互模式下每个角色行有「去定妆 / 重设定妆」按钮，打开定妆弹窗。
- 定妆弹窗（CharacterAnchorModal）：标题「{角色名} 定妆选择」，生成 3 张候选图（不同 seed），点击选中高亮、双击直接确认；底部「重新生成 | 取消 | 确认定妆」；生成中显示骨架屏；失败显示友好错误与重试入口。
- 确认后角色卡片立即显示定妆图（经 store 更新 snapshot），并弹出对话面板提示「已确认「{角色名}」的定妆照」。

阶段 2（阶段管理 tab：CharacterStage 列表/创建/编辑/删除/重新生成）留待后续任务。

## 已知风险

- 候选图与定妆图依赖后端 DB 模式（File 模式抛 DB_PERSISTENCE_REQUIRED），e2e file 模式未覆盖真实生成链路；真实链路验证需 db 模式 + 图像 provider。
- 定妆确认后 snapshot 只补丁 character，候选资产不进当前内存 assets 池（后端资产池在下一次全量刷新时自然包含），当前 UI 无依赖此点的展示。
- 弹窗未做 customPrompt 输入（阶段 1 按验收标准最小实现），API 已支持。
- 双击确认在触屏设备上不可用，移动端走「选中 + 确认定妆」按钮路径。
