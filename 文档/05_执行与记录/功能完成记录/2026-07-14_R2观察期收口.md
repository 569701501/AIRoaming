## 数据或协议变化

- 新增 migration `0011_g2_project_purge_pointer_teardown`。只有 Project=`deleting`、匹配 delete-files Outbox=`processed`、无 active runtime task 时允许协调拆除 Chapter reverse pointers；普通业务 trigger 不放宽。
- 新增 backup kind `db-only-coordinated`。manifest 同时保存当前 release schema identity 和历史 cutover lineage identity，并保留 `db_only/cutoverRunId/activatedAt/firstBusinessWriteAt`。
- DB Asset 文件读取以 Asset `storageKey` 为物理事实源，合法前缀为当前项目的 `projects/` 或 `legacy-import/`。
- DB Workbench chapterId 选择为纯读取投影，不修改数据库 current pointer。
