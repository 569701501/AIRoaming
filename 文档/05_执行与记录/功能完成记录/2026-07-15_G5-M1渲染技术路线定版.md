# G5-M1 渲染技术路线定版

## 功能摘要

完成两条完整 E0 薄切片并选择 A：Konva 交互 adapter + DOM 富文本 + 独立 HTML RenderScene + 固定 Chromium PNG/PDF。B 的 SVG/resvg 路线因 8192 高切片 native abort 被否决。

实现提交：`68b00cb`。

## 影响范围

- 新增隔离、可一条命令复现的 `prototypes/layout-editor-e0`。
- 锁定 Konva/Playwright/Chromium、Inter/Noto 字节、字体 cmap 预检和 renderer 升级门。
- 新增 ADR-0016、E0 机器证据、Scrutiny 与 Runtime/Visual Review。
- 不改生产数据库、API、Web 页面或用户数据；M2～M8 仍待实现。

## 主要文件

- `prototypes/layout-editor-e0/`
- `文档/04_方案与决策/ADR-0016_G5画布与确定性渲染技术路线.md`
- `文档/05_执行与记录/任务记录/2026-07-14_G0至G5剩余连续施工/evidence/g5_m1_e0_report.json`

## 数据与协议

无数据库变化。新增技术不变量：adapter 私有状态不落盘；正式 scene 独立；字体/图片只来自 manifest；条漫按同一 RenderScene 切片；B native renderer 不进入主链。

## 验证

- `corepack pnpm prototype:g5-e0`：退出码 0；A 15/15 门通过，B 失败被隔离。
- PNG：`1800×2400`，三次与黄金 sha=`sha256:26c7029eda5af46cea0c1a4b66310ee2472a136f64e28e1a0788a8a2fde3aec4`。
- PDF：单页三次 sha=`sha256:abcbacde62c69bddac427a8b788051d4f28a369d343bd49d54e9d395a2eb9e57`；40 页能力通过。
- 条漫：`8192/8192/8192/8192/5632`，拼接/source pixel digest 均为 `sha256:bb1ef1dfa192ab6c5d24214d748a54559158ca0df5041b71f148f9981cb9211d`。
- 性能：20 canvases/200 elements，p95=`19.9ms`，pointerup=`0.2ms`。
- 回归：`corepack pnpm test:g5:fixtures` 3/3；全仓 typecheck、E2E typecheck、build、Shared 54/54、Server 536/536 全部通过。
- 阶段红灯：`corepack pnpm test:render` 按设计非零，仅报告 M5/M7 负责的生产 renderer、浏览器语义和 CJK 字体 provision，未把未实现能力伪装为通过。

## 风险与后续

- Chromium/font/policy 任一升级必须重跑 golden 并升级 rendererVersion。
- 浏览器 binary 的最终发行 notices 在 M7 打包方式确定后复核。
- 正式 grapheme policy、domain kernel、编辑器与 renderer 继续由 M2～M8 实现。
