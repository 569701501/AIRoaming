## 1. 功能摘要

将项目工作区右侧剧本文档从原生 `textarea` 替换为真实 CodeMirror Markdown 文本编辑器，并让工具栏写入真实 Markdown 文本。

## 2. 完成内容

- 新增 `MarkdownTextEditor` 组件，封装 CodeMirror 6。
- 剧本文档编辑器改为使用 CodeMirror Markdown 编辑正文。
- 支持标题、无序列表、有序列表、加粗、斜体、下划线、删除线、引用和图片 Markdown 插入。
- 保存接口保持不变，只提交 `sourceText`。
- 右侧大纲未改动，本阶段不接入真实大纲解析。
