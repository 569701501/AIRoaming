# 第一章正文恢复与防空覆盖

## 功能摘要

从第一章当前剧本版本恢复被清空的正式正文，并为加载和写入链路增加两层保护：非草稿章节可从当前版本自愈；草稿保存和完成本章不能把规范化后的空正文写盘。

## 影响范围

- 章节 workspace 加载与恢复。
- 章节草稿保存、完成本章和版本创建。
- 真实项目第一章正式正文文件。

## 数据或协议变化

- API 字段无变化。
- 非 `draft` 章节正式正文为空且当前版本非空时，仓储读取以当前版本正文自愈。
- `saveChapterDraft` 与 `completeChapter` 在剥离项目级剧本名称后再次校验正文；为空返回 `CHAPTER_SCRIPT_REQUIRED`，不写盘、不创建版本。

## 已知风险

- 没有历史 HTTP 请求日志，无法唯一确认当时是哪次保存动作触发空覆盖。
- 自愈依赖当前剧本版本仍存在且正文非空；如果正式正文和版本文件同时损坏，仍需从外部备份恢复。

## 后续建议
