# G5-M8 手机、AI 与旧排版切换完成记录

## 功能摘要

完成 G5 最后一个技术切片：手机只读预览、AI 待应用编辑命令、旧排版转换/重建和旧导出后门删除，并补齐 profile resize、图片标准化、安全与可访问性验收。技术验收和最终用户签收均已通过。

## 影响范围

- Shared Layout V1 命令、pending、resize 与 preflight。
- Server DB-only Working Copy、legacy migration、图片/renderer 门禁。
- Web 排版工作区、手机预览、AI drawer 与键盘可访问性。
- G5 Playwright、render/migration gate 和完整回归。

- `apps/server/src/projects/layout-pending-command.service.ts`、`layout-legacy-converter.ts`、`layout-image-normalization.util.ts`、renderer/versioning/working-copy/controller/module 及测试。
