# 双流程真实模型验收修复完成记录

## 功能摘要

AI 创作与已有完整剧本两条路线已在独立 SQLite、独立 workspace、新建项目和真实 `self/gpt-5.5` 下完成浏览器复验。修复后，AI 章节生成完成可不刷新直接采用；完整剧本可完成“分析与拆章目录 → 一次确认目录 → 后台生成全部章节待确认稿 → 失败章单独重试 → 逐章确认正式版本”。

真实复验还补齐了导入 Prompt 的两条忠实度边界：有原文证据的结构化摘要或氛围标签不是新增剧情；标签、录音、屏幕文字、档案、书信和广播不能被改写或重分类为人物对白。

## 影响范围

- Web：DB-only 章节生成/修订结果后的 pending 运行态同步。
- Server Prompt：B2 `excludedRanges` 条目形状；B4 忠实整理和忠实度验证口径。
- `script-import-normalize`：与生产 Prompt 保持一致的字段和忠实度规则。
- E2E：AI 生成后不刷新立即采用的浏览器回归。
- 文档：双流程来源状态契约、会话记录和长期记忆。
