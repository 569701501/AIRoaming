## 功能摘要

首页全局设置页已支持 `AI 密钥` 与 `外观设置` 两个功能，设置入口位于项目库左侧导航。

## 影响范围

- 前端新增 `/settings` 页面、设置 store、侧边栏导航行为和浅色主题覆盖。
- 后端新增 `settings` 模块，保存本地全局设置。
- OpenCode runtime 默认模型改为读取全局设置，并在存在 API Key 时服务端同步到 OpenCode auth。
- 共享契约新增 `AppSettings`、`AppearanceTheme` 和设置更新请求 DTO。

## 数据或协议变化

- 新增 `GET /api/settings`。
- 新增 `PATCH /api/settings`。
- 本地设置保存到 `workspace/settings/app-settings.json`。
- API 响应只返回 AI 密钥掩码和指纹，不返回完整 API Key。
- `appearance.theme` 支持 `system`、`dark`、`light`。

## 已知风险

- 当前本地设置文件仍是开发期 workspace 文件持久化；后续正式桌面或多用户形态应换成系统 keychain、数据库加密字段或专用密钥服务。
- 浅色主题通过全局覆盖实现，已覆盖首页和设置页主路径；后续新增页面时仍需补齐浅色细节。
- OpenCode provider 的 baseURL 热更新能力依赖 OpenCode 本身；当前后端可同步 API Key 和默认 `providerId/modelId`。

## 后续建议

- 在对话面板内重做可见模型选择和 variant 选择。
- 增加设置页密钥连通性测试按钮。
- 接入更安全的本机密钥存储。
