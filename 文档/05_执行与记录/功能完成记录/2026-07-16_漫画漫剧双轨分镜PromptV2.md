# 漫画 / 漫剧双轨分镜 Prompt V2

## 功能摘要

当前分镜生成仍一次输出页面已有的 `comic / motion` 字段，但生产 Prompt 已把两者改为并列媒介设计：先共享正式剧情事实，再分别生成漫画静态画格规则和漫剧时间过程规则。漫剧不再被定义为漫画画格的动态说明。

## 影响范围

- 修改首次生成与待确认草稿调整共用的分镜 Prompt。
- 修改一次定向修复 Prompt。
- 增加 Prompt 契约和质量门兼容测试。
- 更新正式方案、实施顺序、任务留痕和项目记忆。
- 页面、Schema、数据库、API、正式枚举和用户确认流程均未改变。

## 数据与协议

没有数据迁移和协议字段变化。当前 M1 继续使用一个 `Shot[]`，共用 order、beat/scene/characters、`shotType`、`cameraAngle` 和镜头数量；`comic` 与 `motion` 只在内容字段上独立设计。

## 主要规则

- 漫画：静态决定性瞬间、阅读动线、气泡留白、画格节奏和格间连续。
- 漫剧：开始状态、主要动作/表演/信息变化、结束状态、动态调度、运镜用途、内容时长、正式配音来源和尾首帧连续。
- 双轨：共享且不冲突的是正式剧情事实；画面描述、构图、节奏、表演和运动无需相同。
- `promptDraft`：只属于静态候选图，不承担漫剧动态 Prompt。
