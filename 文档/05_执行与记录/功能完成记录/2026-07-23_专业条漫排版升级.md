# 专业条漫排版升级完成记录

## 功能摘要

完成“无视觉也安全”的竖向条漫排版升级：规则降级时所有自动气泡主体放在画格外、尾巴关闭，视觉模式只允许气泡完整位于经过验证的文字安全区；对白按语义呈现普通、思考、强调和旁白四种形态，并使用可移植的真实中文字体面。目标章节先通过自动安全排版替换为 v71，再完成两处手机断行精修，最终为 Working Copy v73。

## 影响范围

- Shared：冻结 typography preset、语义气泡样式、规则/视觉候选、质量硬门、中文文字测量和旧任务兼容。
- Web：编辑器、气泡属性、只读预览、FontFace 注册、真实行盒字号和响应式阅读。
- Server：字体资产 provision、来源投影、worker 接线、正式 renderer 的真实字体面和语义形状。
- 数据：目标章节 Working Copy 从旧遮挡版本替换为自动排版 v71，并经两处 geometry 人工精修保存为 v73；替换前 JSON 已备份。
- 文档：任务协议、智能成稿保护契约、模块边界、运行验收和本完成记录。

## 数据或协议变化

- `LayoutCompositionFrozenSourceV1` 新增 `typographyPreset: layout_typography_preset_v1`。
- 新 task policy digest 包含 typography preset；缺少该字段和上一版 digest 的历史任务保持可读。
- Noto Sans SC 受控字体扩展为 400/500/700/900 四个真实 face，并固定文件长度、SHA-256、cmap 与许可来源。
- `rule_fallback` 不再生成画格内部候选，且不再获得无证据的视觉保护满分。
- 正式 `balloonKind` 和对白绑定不被视觉推断改写；显示形态可从短句语气保守推断。
