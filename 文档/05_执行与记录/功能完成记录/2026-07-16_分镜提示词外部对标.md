# 分镜提示词外部对标完成记录

## 完成摘要

已把当前 `storyboard-shot-generate` 与 GitHub 开源漫画/故事板项目、Boords 商业分镜流程、Runway 官方 Prompt 方法和 Promptfoo 评测方法逐项对照，形成不改变现有字段和确认流程的 V2 适配方案。

## 关键结论

- 每个 beat 先有一个主镜，只有原因/结果、揭示/反应、选择/代价、关系变化或空间连续确有需要时增加辅助镜。
- 用镜头叙事用途和状态接力替换泛化的“多用不同景别”规则。
- 把现有 `comicFormat`、`artStyle` 注入分镜 Prompt，不新增字段。
- `comic` 先确定静态决定性瞬间，`motion` 再投影一个主体动作和最多一个主要运镜。
- 黄金钩子只能强化正式结构已有钩子，不能在分镜阶段创造新剧情。
- 固定秒数、9:16、CTA、九宫格、8K/焦段/负面词不进入通用漫画分镜。
