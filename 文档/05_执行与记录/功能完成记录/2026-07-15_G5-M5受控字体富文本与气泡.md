# G5-M5 受控字体、富文本与气泡

## 功能摘要

成稿编辑器已能使用项目内受控 CJK FontAsset 编辑横排/竖排富文本，安全处理 IME 与外部粘贴，按 grapheme 范围设置样式，并创建四类受控气泡和单尾巴。文字、气泡和字体引用全部进入既有 DB-only LayoutDocument/command/autosave，不保存 DOM 私有状态，不依赖用户机器字体。

实现提交：`cd35053`。

## 影响范围

- Shared 增加严格字体 metadata/catalog、cmap 覆盖、Asset-ID family、缺字/embedding/overflow 预检和富文本 plain-text/grapheme offset 工具。
- Server 增加固定字体包校验、FontAsset provision/catalog/verified file API，并在 Working Copy 初始化与保存时保证字体可用。
- Web 增加受控 FontFace loader、contenteditable 富文本 adapter、横竖排预览、范围样式、四类气泡、tail 和 overflow 交互。
- E2E 增加 G4→M5 的 fresh SQLite 用户路径，并纳入 DB 模式穷尽矩阵。

## 数据与协议变化

- 字体复用 `Asset(type=font, role=layout_font)`，不增加新模型；metadata 固定 family/face/format/license/embedding/cmap/package/source。
- provision 走 staged→Outbox→ready；字体文件按项目 storageKey 保存，数据库不保存 base64。
- 新增 layout fonts catalog/provision/file API；客户端只能加载当前项目 catalog 中的 verified Asset。
- Text/Balloon 继续使用 LayoutDocument V1 与既有 Editor Command；不引入第二套 DOM/Canvas JSON 事实源。

- 两张 ready FontAsset 与 processed Outbox 真实落库；400/700 字节 sha、cmap、weight/style、OFL-1.1 与 embedding 元数据均复核通过。
