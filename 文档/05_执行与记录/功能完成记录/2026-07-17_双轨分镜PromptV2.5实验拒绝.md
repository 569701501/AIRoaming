# 双轨分镜 Prompt V2.5 实验拒绝完成记录

## 功能摘要

完成“低权重、定向缺失提示”的 V2.5 QA 实验。新规则只检查声音触发、身份结论和行动结果，并禁止因检查本身新增镜头。真实 A/B 没有产生目标语义增益，且出现镜头膨胀和非目标语义退化，因此未接生产。

## 影响范围

- 生产分镜默认 Prompt 保持 V2.3。
- 新增显式 QA 实验变体、3 个新文本夹具和 A/B CLI。
- 页面、Schema、DTO、数据库、确认流程和媒体服务无变化。

- `apps/server/src/dialogue/dialogue-prompt.util.ts`
- `apps/server/src/dialogue/dialogue-creative-prompt.spec.ts`
- `apps/server/src/dialogue/storyboard-prompt-ab.cli.ts`

- 方案、任务记录、证据、双 Review、Handoff、会话与长期记忆。

## 数据或协议变化

没有业务数据或 API 协议变化。新增 fixture/report 协议只用于 QA 文件。

## 验证结果

- 6/6 分镜生成首次通过；12/12 新样本 evaluator 首次通过。
- 固定 corpus 5/5 成功，人工预期一致 27/28。
- V2.5 改善样本 0 个；屏幕身份样本 4→6 镜，超过上限；声音样本抽象关系 outcome 退化。
- 定向测试、全量 Server、类型检查、构建和差异检查通过。

## 已知风险

- 每个生成变体只运行一次；当前证据足以拒绝，但不能用于估算生成模型方差。
- 显式实验变体必须继续与生产服务隔离。
- evaluator 仍有已知边缘判断，不能接生产硬门。

## 后续建议

停止继续堆叠生成 Prompt 规则。保留 V2.3 和独立 QA evaluator，把语义发现交给人工复核，而不是自动补镜或强制重写。
