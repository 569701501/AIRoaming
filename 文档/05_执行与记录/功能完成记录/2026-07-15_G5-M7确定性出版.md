# G5-M7 确定性出版

## 功能摘要

成稿编辑器已能从当前 sealed LayoutRevision 创建持久 DB-only publication。固定 Chromium renderer 生成页漫 PNG/PDF 或条漫 slices/条件长图，所有产物经 staged Asset、精确 Outbox promotion 和 canonical manifest 验证后才原子切为 ready/current；失败、取消、重试和迟到结果不会覆盖旧 current。

实现提交：`d8ed6cc`。

## 影响范围

- Shared 增加 publication profile、RenderPlan、slice plan、manifest 和严格请求/响应契约。
- Server 增加固定 renderer、publication 创建/查询/取消/Artifact 读取、`layout_export` worker 与 0015 DB trigger overlay。
- Web 增加真实出版预检、warning 确认、持久任务提交、活动状态轮询、current/historical 展示、取消和 Artifact 链接。
- E2E 增加真实页面→任务→renderer→DB current→PNG file 的 DB-only 路径。

## 数据与协议变化

- 一次 publication 聚合一个 ExportRevision、一个 GenerationTask、多条 ExportArtifact/Asset 和一个不自列的 canonical manifest。
- 任务固定 `concurrencyKey=layout-render`、全局并发 1、最多 2 次；TaskSource 在创建事务封存。
- 完成时重新计算 LayoutRevision 与 G4 source applicability；只有仍为 current 才移动 `currentExportRevisionId`。
- 0015 只增加 forward-only triggers，不执行 down migration。
