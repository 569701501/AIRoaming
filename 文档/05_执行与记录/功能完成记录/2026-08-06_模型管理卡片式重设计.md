# 2026-08-06 模型管理卡片式重设计

## 功能摘要

设置页「模型管理」从「整行点击即选中」的行式列表重设计为卡片式 + 显式操作：

- 对话模型 / 图片生成模型两个分区，分区头带类型图标、数量徽标和添加按钮。
- 每张卡片：左侧类型色头像（显示名首字符，对话紫/图片薄荷绿）、名称、`providerId · modelId · baseUrl` 等宽字体元信息行、密钥状态行（🔑已配置 / ⚠未配置琥珀色警告）。
- 激活从隐晦的「点整行」改为显式「设为当前」按钮；当前生效卡片有渐变左边条 + 紫色底 + 「✓ 使用中」徽章。
- 未配置密钥的卡片「设为当前」按钮呈琥珀警告色，提示先编辑补充密钥。
- 新增编辑入口（铅笔图标）：复用 AddModelModal，预填现有值，标题「编辑模型」，隐藏类型切换 tab，API Key 留空保留原密钥，已配置密钥的模型提供「清除已保存的密钥」勾选（clearApiKey）。
- 删除改为内联两步确认：点删除图标 → 3 秒内变为红色「确认删除？」按钮，再点才真正删除（遵守全站禁用 window.confirm 约定，未新增弹窗组件）；当前生效模型删除按钮保持禁用。

## 影响范围

仅设置页模型管理 tab 的 UI 与交互；后端接口、数据模型、任务协议零变化（PATCH `/settings/managed-models/:id` 为既有能力首次接入 UI）。

## 已知风险

- 删除二次确认 3 秒超时自动复位，用户慢操作需重新点一次删除，属可接受取舍。
- 编辑弹窗的「清除已保存的密钥」勾选与输入新密钥可同时提交（服务端 clearApiKey 优先），UI 上勾选后输入框已禁用，无冲突路径。
- In-app browser 本次会话不稳定（broker id mismatch / 截图失败），截图改用仓库内 Playwright 临时脚本完成，脚本在 /tmp 未入库。

## 后续建议

- 可考虑在卡片上补「测试连接」按钮（需后端新增探测接口，当前无）。
- 模型较多时分区可折叠或加搜索；当前量级（个位数）不需要。

## 追加（2026-08-06 当日二次反馈）

用户反馈服务端异常（如 `MANAGED_MODEL_SECRET_UNSUPPORTED_IN_DB`）不能以常驻红色横幅直接展示。已改为：

- 设置页错误/成功提示改为顶部居中 toast：毛玻璃深色、4.5 秒自动消失、可手动关闭、z-index 120 覆盖弹窗；`settings-store` 新增 `clearFeedback()`；展示前剥离 `ERROR_CODE:` 前缀只留可读中文。
- 弹窗内联错误改为本地留存（`localError`）：toast 自动清空 store error 不影响弹窗内错误展示，且同样剥离错误码前缀；下次打开弹窗时重置。
- 验证：`output/ui-check/toast-error.png`（toast+弹窗内联错误并存、无错误码前缀）、`toast-auto-dismissed.png`(toast 消失后弹窗内错误保留）；确认错误路径未创建垃圾模型。

## 追加二（2026-08-06 删除 AI 密钥/图片生成 tab)

用户确认「之前怎么处理现在就怎么处理，只是删入口」，移除设置页「AI 密钥」「图片生成」两个 tab，设置页只剩「模型管理」「外观设置」，默认落模型管理。

- **产品决策（用户明示）**：接受数据库模式下不再有任何 UI 路径配置/轮换/清除对话与图片密钥；密钥仍由服务端既有渠道管理（`updateAIKeySettings`/图片槽位接口与运行时凭证共享机制不变，`settings-store` 对应 action 保留未删）。运行时解析链路不受影响：仍优先 active managed model，同 providerId 共享槽位凭证，兜底 aiKey/图片槽位。
- **前端** `AppSettingsView.vue`：删除两个 tab 的模板、5 个表单 reactive、全部 provider 状态 computed 与 watch、save/clear/switch 函数、`providerOptions`、`formatTime`，及 `.provider-*`/`.key-meta`/`.secret-input`/`.field-grid`/`.status-pill` 等孤儿样式；tabs 只剩 models/appearance。
- **服务端** `settings.service.ts` 三处错误文案不再指向已删页面（错误码不变，spec 22/22 仍绿）：`MANAGED_MODEL_SECRET_UNSUPPORTED_IN_DB` 两条改「密钥由运行时既有渠道管理」，`MANAGED_MODEL_FIXED_SLOT_DELETE_FORBIDDEN` 改「由固定密钥槽位镜像生成」。
- 验证：web typecheck 零报错、web 契约 55/55、server typecheck 零报错、settings spec 22/22；截图 `output/ui-check/settings-two-tabs.png`。
- **恢复路径**：两个 tab 的完整实现可从 git 历史（本记录对应提交之前）找回。
