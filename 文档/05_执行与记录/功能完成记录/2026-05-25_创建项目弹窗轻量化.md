## 1. 功能摘要

创建项目弹窗已从“填写项目和剧本基础信息”收敛为轻量创建。用户可见标题为“创建项目”，弹窗只保留“项目名称”一个字段，不展示内部语义或“下一步”提示文案。创建成功后进入项目工作区，第 1 步“剧本”再填写故事标题、题材标签、漫画格式、画风方向和故事原文。

## 3. 数据或协议变化

本次不修改后端接口和共享 DTO。前端创建弹窗只提交：

```json
{
  "name": "迷雾之城",
  "type": "comic"
}
```

后端仍保留故事字段的默认值和兼容处理；故事相关字段由项目内“剧本”面板通过草稿保存接口写入。

## 5. 已知风险

- 旧完成记录曾描述“创建时填写故事字段”，已标记为 `superseded`，后续 AI 应以当前产品文档和本记录为准。
- 后端接口仍兼容可选故事字段，当前约束来自前端 UI 和文档事实源；如后续开放外部 API，需要再决定接口层是否强制收窄。
