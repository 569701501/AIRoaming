# 功能完成记录：角色参考图优先提示词

## 功能摘要

角色参考图生成 Prompt 改为「参考图优先」：角色已有参考图（定妆锚点图 / 定稿参考 / 已确认预览图）时，外貌设定不再堆叠文字 appearance，改为「参考所提供的角色图片，保持面部特征、发型和整体气质一致」；若此时仍有文字 appearance，降级为「补充细节」单独成行。无参考图时行为完全不变。

## 影响范围

- 角色预览图、定稿图、生物参考图、群体参考图的 Prompt 编译（v1/v2 全部模板）。
- 参考图生成任务（file 队列与 DB 持久任务）共用同一编译入口，行为一致。
- 仅影响新生成任务的 Prompt；历史资产、任务与数据模型无变化。

## 数据或协议变化

无。不涉及 DTO、数据库、任务协议、素材路径或资产 meta。

## Prompt 行为契约

| 场景 | APPEARANCE | ADDITIONAL_NOTES |
| --- | --- | --- |
| 有参考图 + 有 appearance | `参考所提供的角色图片，保持面部特征、发型和整体气质一致` | `补充细节：{appearance}` |
| 有参考图 + 无 appearance | 同上 | `''` |
| 无参考图 | `appearance \|\| "根据项目风格补全，但保持简洁稳定"` | `''` |

实际渲染示例（preview_front v2，appearance=黑色短发，灰蓝风衣，左眉浅疤）：

```text
有参考图：- 外貌设定：参考所提供的角色图片，保持面部特征、发型和整体气质一致 | 补充细节：黑色短发，灰蓝风衣，左眉浅疤
无参考图：- 外貌设定：黑色短发，灰蓝风衣，左眉浅疤
```

## 已知风险

- creature / group 模板沿用任务指定的统一文案（含"面部特征、发型"等偏人形化表述），非人主体语义上略不精确，但外观设定栏语义仍成立，任务文案为全局指定。
- `image-prompt-baseline.util.ts` 基线编译未传 `hasReferenceImage`（默认 false）：基线 fixture 无参考图维度，行为符合预期；后续如要测参考图场景需扩展 fixture。
- 生成任务 promptDigest 会随文案变化，仅影响新任务审计，历史任务不受影响。

## 后续建议

- 如需非人实体更贴切的文案，可将参考图文案按 `entityType` 细分（如 creature 用"参考所提供的角色图片，保持整体轮廓、材质与配色一致"）。
- 可在 `image-prompt-baseline` 增加带参考图的 fixture 以覆盖该分支的 A/B 语料。
