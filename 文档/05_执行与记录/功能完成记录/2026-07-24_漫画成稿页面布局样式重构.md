# 漫画成稿页面布局与样式重构（P1+P2）

## 功能摘要

把漫画成稿页从"四列专业编辑器平铺"收敛为更干净的三列工作台：

- 顶栏瘦身：立即保存/手机预览改为图标按钮；「版本与出版」更名「导出本章」并作为唯一主按钮（发布四步流程：成稿预检→保存 Revision→出版预检→提交出版任务不变）
- 左侧 48px 工具列删除，8 个工具（选择/平移/裁切/加画格/加自由图/加文字/加气泡）改为画布内左上悬浮工具条
- 建立组件级 design tokens（`--le-*`），替换关键硬编码色值
- 画布改米白纸色（`#f6f3ec`）浮于深色舞台，去掉点阵背景；强调色统一为蓝色，语义色（红/橙/绿）保留
- 字号上调：淘汰 8/9/10px 小字

P2 交互收敛：

- 智能入口合一：顶栏「重新排一版」与画布工具栏「智能调整」合并为顶栏单一「智能调整」；抽屉首屏统一为范围选择（整章重排/选中内容/当前页段/当前场景）+ 显式生成，打开时不再自动发起整章重排；有选中默认"选中内容"，无选中默认"当前页/段"
- 左栏（页面列表+镜头素材）可通过画布工具栏按钮收起/展开；收起后增量宽度全部给画布，右侧属性栏固定 320px 不动
- 新增换图镜头条：选中带图画格或自由图时，画布底部滑出本章镜头缩略图条，点击即替换
- 属性面板"图片与裁切"新增「在画布上拖调裁切」可见入口（Konva 裁切工具的发现性入口）

P3-1 属性面板按对象收敛：

- 未选中：提示语 + 阅读顺序（迁出选中态，本就是画布级）+「页面设置」折叠区（画布尺寸+画格模板，默认展开）
- 选中：对象名 + 常用操作（锁定/允许智能/隐藏/删除）+「精确调整」折叠（坐标/尺寸/旋转/透明，默认收起）+ 类型专属区（画格/裁切/文字/气泡）；「页面设置」自动收起

拖拽失效修复：

- 根因：`addText()`/`addBalloon()` 把 `activeTool` 置为 `"text"`，文字模式下 Konva 层 pass-through 且无任何拖拽路径，用户添加文字/气泡后一切拖不动，界面也没有切回选择工具的引导；画布文字预览是纯静态的，文字模式在画布上不提供任何编辑能力
- 修复：添加文字/气泡后保持选择工具，新对象立即可拖；顺带修复 `layout-editor-m4.spec.ts` 既有失败（画格点击改坐标点击、阅读顺序断言前先取消选中）

## 已知风险

- `activeTool === "text"` 相关分支（`selectDomElementInTextTool`、Konva pass-through）已成为不可达死代码，保留未删，后续清理。
- `layout-editor-m6` 的 `database is locked` 是 spec 第 120 行自建 DatabaseSync 直读 SQLite 的既有竞态，与 UI 无关，建议后续给 spec 加 busy_timeout 或改走 API 断言。
- 智能抽屉打开后整章重排需两次点击（整章重排 → 生成一版看看），不再自动发起；这是显式生成的有意取舍，避免误触消费生成额度。
