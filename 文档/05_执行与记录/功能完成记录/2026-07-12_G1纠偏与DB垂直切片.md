# G1 纠偏与 DB 垂直切片完成记录

## 1. 功能摘要

已把 G1 从“自签审查流程优先”纠正为“可运行数据库产物与业务垂直切片优先”：移除 Reviewer/attestation/sealed bundle/CAS 的生产门禁，生成正式 Prisma migration tree，并通过现有公开 Service 打通 Project/Chapter/Script 的最小 DB 创建、草稿、完章和重启读回链路。

本记录只签收上述纠偏范围，不代表完整 G1 数据接管、生产 DB-only 切换或 G2 已完成。

## 2. 完成内容

- 删除自签 review gate 的生产实现、对应测试和 CLI 入口；历史 review 文档仅保留为历史留痕。
- 保留并收紧直接事实校验：manifest source freshness、自摘要、Schema exact、Prisma validate、migration exact tree、fresh replay、ledger、integrity/FK。
- 生成 `migration_lock.toml` 与 `0001～0008/migration.sql`，包含 44 个模型、195 个 CHECK 和 194 个 trigger。
- 新增显式 DB 模式下的 Prisma 生命周期；默认 file 模式保持不变。
- 沿 `ProjectsService -> ProjectStore -> ProjectRepository` 支持 `create_project`、`save_chapter_draft`、`complete_chapter`，其他 DB 写入稳定 fail-closed，不回落 file 或双写。
- 应用连接后、业务加载前核验正式 8 段 migration artifact 与实际 `_prisma_migrations` ledger；missing、extra、duplicate、checksum drift、failed/P3018、rollback、logs、steps 或无 ledger 均拒绝启动并断开。
- DB 读回对 null/无效 current chapter 指针 fail-closed；自动创建的下一章在重启后可由 API/DB 读回，当前章仍保持在刚完成章节。
