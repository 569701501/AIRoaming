# 图片 Prompt 专业 V2 离线收口完成记录

## 1. 功能摘要

图片 Prompt 专业 V2 已完成公开资料调研、生产代码编写、独立静态复核、复核返工、固定语料 dry-run 和全量回归。

用户因预算明确停止真实图片生成，因此本任务以离线方式收口：

- V2 代码和离线合同通过；
- V1 编译器继续保留；
- 真实 V1/V2 图片 A/B 未执行；
- 不得宣称 V2 真实成图质量已经通过；
- 在用户未来重新给出预算授权前，不得执行付费图片 A/B。

## 2. 影响范围

### 2.1 参考资产 Prompt

- 角色预览：稳定身份种子、准确一个角色、半身正面、纯背景、无文字和非真人约束。
- 角色定稿：严格继承预览身份，固定四视图顺序和同服装/同比例合同。
- 场景参考：稳定地标、出入口、空间关系、光向、可复用裁切空间和准确零人物合同。

### 2.2 漫画候选图 Prompt

- 继续只读取正式静态分镜事实，不读取对白、旁白、漫剧 motion 或旧 `promptDraft`。
- 新增版本化结构镜头合同：环境、单人、双人、多人、决定性瞬间和条件式特效因果。
- OpenAI、Doubao、Grok 使用同一语义合同但分别编译，不再只更换 `profileId`。

### 2.3 Provider 边界

- OpenAI/Grok 镜头合同使用英文；Doubao 使用中文。
- 实际参考图选定后才追加角色身份或场景空间职责。
- Doubao 文生图、单图编辑、多图候选均关闭水印，并保持正式 3:2 / 2:3 候选尺寸。
- Grok 单参考图和三图上限继续显式 warning，评测时与 Prompt 质量分开。

### 2.4 测试入口

- V1、V2 真实测试入口必须显式选择版本。
- 两个版本使用独立 schema v2 ledger、slot id、计划摘要和 Prompt manifest。
- 不传版本会在读取凭据或调用 Provider 前失败。

## 6. 已知风险

1. V2 真实视觉质量未经验证，只能称为“专业化方法与离线合同通过”。
2. 角色预览、四视图和场景参考 V2 仍是共享英文模板，没有像候选图一样形成三套 Provider 专属编译。
3. Grok 单参考图可能为保持比例而不使用参考图；多人镜头最多三张参考图。
4. V1 回退编译器已保留，但当前没有面向用户的运行时切换按钮；需要代码侧切换并重新部署，不能描述为页面一键回退。

## 7. 回退方案

- 保留 `compileImagePromptForProviderV1` 和 V1 参考模板构造路径。
- 若未来正常生产发现 V2 明显退化，代码侧将候选图编译切回 V1，并保持已创建任务使用自己冻结的 Prompt。
- 不覆盖历史任务，不修改已生成候选图，不伪造视觉验收结果。
