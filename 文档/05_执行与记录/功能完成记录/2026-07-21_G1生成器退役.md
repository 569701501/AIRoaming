# G1 生成器退役完成记录

## 功能摘要

完成 G1 Schema 活跃生成器退役：删除已经完成迁移使命、无正常运行时依赖的 DSL/source rebuild、Prisma/migration writer/check CLI 及专用测试，同时保留所有数据库 artifact 和运行安全门禁。

## 影响范围

- 服务端 TypeScript 净减少 23 个文件、11,066 行。
- 其中生产代码减少 16 个文件、9,142 行，服务端生产代码从 62,912 行降为 53,770 行。
- 删除六个不再有效的 `g1:*` package script。
- 用户页面、API、任务协议、数据库结构、数据和 trigger 均无变化。

## 修改文件

- 删除 `apps/server/src/persistence/` 下 16 个 G1 生成器生产文件和 7 个专用测试。
- 修改 `apps/server/package.json`。
- 修改 `apps/server/src/persistence/g1-schema-trigger-sqlite-semantics.spec.ts`。
- 更新文档入口、AI 上下文、模块总览、ADR-0015、G1 Schema 实施契约和自动化测试体系。
- 新增本任务三件套、会话记忆与本完成记录；更新长期记忆。

## 数据或协议变化

无。`schema.prisma`、历史 manifest、0001～0017 migration SQL 和运行 SQLite 均未修改。

## 验证命令与结果

- 删除前 `g1:manifest:check`、`g1:schema:check`、`g1:migration:check` 与 Prisma validate：通过。
- 保留数据库契约定向测试：4 files / 43 tests 通过。
- 服务端全量：129 files / 790 tests 通过。
- 全仓 typecheck：shared/web/server 全部通过。
- Server build：通过。
- Prisma validate：通过。
- Artifact SHA-256 删除前后相同：`schema.prisma=652ec25a…591a5`、manifest 文件=`a94fc42a…ef46`、migration tree aggregate=`bcc10206…e9a5`。
- 标准库只读检查：`db_only`、17/17 migrations、`integrity_check=ok`、无外键违规。

## 已知风险

- 历史 G1 manifest 不能再从 Markdown/DSL 本地重建；恢复依赖版本控制和冻结 artifact。这是 ADR-0015 已接受的退役后果。
- 历史执行记录仍会出现旧 `g1:*` 命令；当前事实源已明确这些命令不可执行，不应改写历史证据。
- 本次未处理 legacy file 主链分支，也未删除任何表或 trigger。

## 后续建议

1. 先用真实产品路径复核 0017 的 9 张空表/20 个 trigger，再决定是否整体简化。
2. 单独审查 legacy file 分支，将只用于导入/恢复的能力与主运行模块隔离。
3. Trigger 每批最多迁出 5～10 个，先证明等价 FK/事务/CAS，再以 forward-only migration 实施。
4. 下一阶段投入优先转向 UI/UX 和真实用户验证，不再扩建 Schema 生成基础设施。
