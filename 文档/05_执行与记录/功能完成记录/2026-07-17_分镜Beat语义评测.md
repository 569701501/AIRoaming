# 分镜 Beat 语义评测完成记录

## 功能摘要

新增一个独立 P6 QA 工具，能逐 Beat 检查 StoryStructure 的 `summary/outcome` 是否真正进入漫画画格或漫剧镜头，而不是只检查 beatId 是否存在。模型负责语义判断，本地负责严格契约和总状态计算。

## 影响范围

- QA-only Prompt builder。
- 严格语义报告 parser。
- deny-all 文本模型 CLI 和 dry-run。
- 两路线真实重复评测证据。

生产分镜 Prompt、页面、数据库、Schema、DTO、自动修复和用户确认流程均未改变。

## 数据和协议变化

无持久化数据或公开协议变化。评测报告是任务证据文件，不是 Storyboard 核心数据。

## 已知风险

- 边缘 `partial` 判断会波动，单次报告不能作为生产硬门。
- 长章节会增加评测 Prompt 长度和文本成本。
- 当前只评 summary/outcome 覆盖，不评价审美、镜头节奏或商业效果。

## 后续建议

另行建立多题材固定样例，使用重复评测稳定交集比较 V2.3 与候选 V2.4；在证据充分前，不扩 Storyboard 字段，也不自动拦截用户确认。
