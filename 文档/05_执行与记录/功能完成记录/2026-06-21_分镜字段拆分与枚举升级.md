## 1. 功能摘要

把分镜 `StoryboardShot` 字段从"混合自由文本"改造成"分层 + 枚举化"结构，为后续出图提示词、排版、漫剧 TTS/视频等下游消费打基础。具体：景别/机位提到共同核心层、三个自由文本字段升枚举、durationMs 拆出、voiceLines 替换 voiceRole+line。详见 `文档/04_方案与决策/ADR-0007_分镜字段拆分与枚举升级.md`。

## 2. 影响范围

- 类型契约：`packages/shared/src/dto.ts`、新增 `packages/shared/src/storyboard-normalize.ts`、`packages/shared/src/index.ts`。

- 前端：`apps/web/src/components/workbench/StoryboardWorkspace.vue`、`apps/web/src/components/workbench/ProjectDialoguePanel.vue`（仅修复编译错误，UI 布局不重构）。

## 4. 数据或协议变化

### 4.1 StoryboardShot 结构（新）

**共同核心层新增 2 字段**：`shotType: ShotType`、`cameraAngle: CameraAngle`。

**comic**：`composition` 语义收窄(只留构图)；`panelRhythm` 改枚举。

**motion**：`compositionDesign` 语义收窄；`cameraMovement`/`frameType` 改枚举；新增 `durationMs: number`、`voiceLines: StoryboardShotVoiceLine[]`；删除 `voiceRole`、`line`；`durationHint` 语义收窄为展示文本。

### 4.2 枚举值（见 ADR-0007）

- ShotType: establishing/wide/full/medium/close_up/extreme_close_up
- CameraAngle: eye_level/high_angle/low_angle/over_shoulder/top_down/dutch_angle
- PanelRhythm: slow/normal/fast/impact/transition
- CameraMovement: static/push_in/pull_out/pan_left/pan_right/tilt_up/tilt_down/track_left/track_right/slow_zoom/handheld/none
- FrameType: atmosphere/dialogue/action/reaction/detail/transition

### 4.3 schemaVersion 保持 1，不升级。

### 4.4 兼容：normalize 读时兜底（不写迁移脚本）

| 情况 | 兜底 |
| --- | --- |
| shotType/cameraAngle 缺失或非法 | medium / eye_level |
| panelRhythm/cameraMovement/frameType 不在枚举 | normal / static / atmosphere |
| durationMs 缺失 | 从 durationHint 解析，失败 2500 |
| 旧 voiceRole+line | 转 [{characterId:null, name, line, voiceStyle:""}] |
