## 1. 功能摘要

将 AI漫游 OpenCode 对话默认模型从当前不可用的 `aurora/gpt-5.4` 切换为已验证可用的 `self/gpt-5.5`。环境变量仍可覆盖默认 provider 和 model。

## 2. 背景

诊断发现 OpenCode serve 和模型列表正常，但默认 provider 上游返回 `503 No available accounts: no available accounts`；备用 `self/gpt-5.5` 直连成功。

## 3. 影响范围

| 类型 | 内容 |
| --- | --- |
| 后端 | `OpenCodeRuntimeService` 默认兜底模型改为 `self/gpt-5.5` |
| 前端 | 模型列表加载时采用后端当前默认，不继续保留坏掉的旧默认 |
| 配置 | `.env.example` 增加 `OPENCODE_PROVIDER_ID` / `OPENCODE_MODEL_ID` |

## 4. 验证

| 验证项 | 结果 |
| --- | --- |
| `corepack pnpm --filter @airoaming/shared typecheck` | 通过 |
| `corepack pnpm --filter @airoaming/server typecheck` | 通过 |
| `corepack pnpm --filter @airoaming/web typecheck` | 通过 |
| `GET /api/ai-runtime/models` | 通过：`defaultModel = self/gpt-5.5` |
| 临时项目对话 API 冒烟 | 通过：assistant `completed`，模型为 `self/gpt-5.5`，回复“正常” |

## 5. 已知风险

- `self/gpt-5.5` 是当前本机可用 provider；其他机器如果没有该 provider，应通过 `OPENCODE_PROVIDER_ID` 和 `OPENCODE_MODEL_ID` 指向本机可用模型。
