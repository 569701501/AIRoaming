## 1. 功能摘要

新增第 3 条剧本链路：用户给出明确题材（如"生成全职猎人暗黑大陆篇"）时，绕过灵感种子，直接生成项目级大纲。配合之前 hotfix 的正则拓宽，"生成 XX 篇/写个故事/生成 N 章"这类直接要内容的请求不再误走"3 选 1 灵感种子"。

## 2. 影响范围

- 后端：`apps/server/src/dialogue/dialogue.service.ts`（核心改动）
- 类型契约：`packages/shared/src/dto.ts`（tool 枚举）
- 前端：`apps/web/src/components/workbench/ProjectDialoguePanel.vue`（tool 映射）

## 3. 改动

### 3.1 触发判断
`shouldGenerateInspirationSeeds` 返回值从 `boolean` 改为 `{ trigger: boolean; mode: "inspiration" | "topic" }`：
- inspirationMatch 命中（找灵感/点子/创意）→ mode=inspiration → 走 3 选 1（现状不变）
- directContentMatch 命中（生成/写/编 + 故事/篇/章/剧本/剧情）→ mode=topic → 绕过种子直接生成大纲

### 3.2 新增方法
- `generateScriptOutlineFromTopicWithAI` + `buildScriptOutlineFromTopicPrompt`：不依赖 seed，题材来自 input.content。
- `createGenerateScriptOutlineFromTopicToolResult`：调生成 + saveScriptOutlineFromAI + 存 pendingScriptOutlines（source="topic"）。

### 3.3 pending 路由
`PendingScriptOutline` 加 `source: "seed" | "topic"`，seed/seedPrompt 改可选。重新生成时按 source 路由：topic 走 fromTopic，seed 走 fromSeed。

### 3.4 tool 枚举
`DialogueToolResult.tool` 加 `generate_script_outline_from_topic`，前端 toolDisplayNames 映射为 script-outline-drafting。

## 5. 已知风险

- runtime 未验证：需用户本地测"生成 XX 篇"是否直接出大纲（不出 3 个种子）。
- 正则误判风险：directContentMatch 要求同时含动词+内容词，双重限定降低误判，但仍可能漏判/误判个别表达。

## 6. 三条链路总览

```
链路1：找灵感 → 3 个种子 → 选 → 大纲（不变）
链路2：上传剧本 → 整理成章节（不变）
链路3：明确题材 → 绕过种子 → 直接大纲 → 确认 → 章节（新增）
```
