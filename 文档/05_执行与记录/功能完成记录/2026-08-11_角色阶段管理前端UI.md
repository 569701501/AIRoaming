# 2026-08-11 角色阶段管理前端 UI（阶段 2）

## 功能摘要

角色库（ProjectCharactersWorkspace，非 readonly 模式）每个角色行新增紫色「阶段管理」按钮（Layers 图标），打开阶段管理弹窗，用户可管理角色随时间变化的形象阶段：

- **阶段列表**：按 stageOrder 升序的卡片列表，卡片含阶段序号+名称（如「阶段 1 · 凡人期」）、起止章节范围（null 显示「从头」/「至今」）、外观变化描述、预览图缩略图（点击放大），渐变边框卡片。
- **创建/编辑**：内嵌表单切换视图；阶段名称（可选）、起始章节（下拉：「从头」+ 章节列表，选项文案「第{order}章 - {title}」）、外观变化描述（必填 textarea 验证）；保存成功切回列表。
- **删除**：自定义二次确认弹窗（红色危险按钮，符合项目「禁用 window.confirm」约定），成功后刷新列表。
- **重新生成预览**：卡片按钮 loading 旋转，成功后用返回的 stage 更新列表（previewAsset 兜底覆盖 previewAssetId）。
- **加载/错误态**：骨架屏、内联错误横幅、加载失败提供重试；空状态友好提示「还没有创建阶段，点击下方按钮创建首个阶段」。

## 影响范围

- 仅 `apps/web` 前端；后端接口、数据模型、DTO 零变化。
- api.ts 修正一处响应类型：`createCharacterStage` 补上 `previewAsset: WorkbenchAsset | null`（后端实际返回，原类型声明缺失）。
- 阶段管理弹窗 z-index=96（高于定妆弹窗 95），内部预览放大与删除确认弹层 z-index=97。

## 数据或协议变化

无。接口契约与后端一致，前端只消费既有 5 个接口：

| 接口 | 请求 | 响应 |
| --- | --- | --- |
| GET `/characters/:id/stages` | - | `{ stages: CharacterStage[] }`（按 stageOrder 升序） |
| POST `/characters/:id/stages` | `{ name?, fromChapterId?, visualDelta }` | `{ stage, previewAsset: WorkbenchAsset \| null }` |
| PATCH `/characters/:id/stages/:stageId` | `{ name?, fromChapterId?, visualDelta? }` | `{ stage }` |
| DELETE `/characters/:id/stages/:stageId` | - | `{ success: true }` |
| POST `/characters/:id/stages/:stageId/regenerate` | - | `{ stage, previewAsset: WorkbenchAsset \| null }` |

前端约定：后端可选字段以 `undefined` 序列化（name/fromChapterId/toChapterId/previewAssetId/finalAssetId）；表单清空字段传空串，由后端归一为 null（编辑时清空生效）。

## 验证命令与结果

- `pnpm -r typecheck`：shared / web(vue-tsc) / server 全部通过。
- `apps/web` `npm test`：55/55 契约测试通过。
- `apps/web` `npx vite build`：构建成功（chunk 体积告警为既有）。
- 真实浏览器冒烟（localhost:5173 + 4310 DB-only 实例，playwright-core 临时脚本）：项目角色库 → 点「阶段管理」→ 弹窗打开（标题「韩立 阶段管理」）→ 空状态展示 → 创建表单打开（3 字段）→ 空 visualDelta 提交被拦截（「请填写外观变化描述。」）→ 填写保存成功回列表（卡片「阶段 1 · 测试阶段」「从头 - 至今」）→ 删除二次确认弹窗 → 确认后卡片消失 → 关闭弹窗，全程零 JS 错误。
- 样式抽查：`.stage-backdrop` z-index=96；卡片为渐变边框（padding-box/border-box 双渐变）；无预览图时显示「无预览」占位。
- 清理核验：冒烟测试创建的阶段已删除，DB 无残留（`character_stages`=0、`character_stage%` 资产=0），无真实图像 provider 调用（无参考图时后端不生成垫图）。

## 已知风险

- 阶段管理依赖后端 DB 模式（File 模式抛 DB_PERSISTENCE_REQUIRED），File 模式实例上按钮可用但接口报错，错误横幅内联提示。
- 预览图生成依赖图像 provider 与参考图（上一阶段图/锚点图/定稿参考/预览参考）；无参考图时创建成功但无预览，卡片显示「无预览」。
- `finalAssetId` 目前无任何端点写入（后端预留字段），UI 不展示「已定稿」状态；后续定稿确认功能接入后再补。
- 移动端双击/触屏交互未做专门适配（操作按钮均为可点击按钮，无双击依赖）。

## 后续建议
