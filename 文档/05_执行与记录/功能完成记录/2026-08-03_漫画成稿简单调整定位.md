# 2026-08-03 漫画成稿简单调整定位实现

## 功能摘要

按用户产品定位「普通用户 + AI 排版为主 + 简单调整」落地漫画成稿编辑器减负：

1. **选中工具条新增文字样式动作**：选中文字/气泡时，就近工具条直接给「缩小文字 / 放大文字 / 粗体 / 7 色文字色板」，90% 的调整无需打开任何面板。
2. **专业能力默认隐藏**（代码保留，`advancedToolsVisible = false` 统一开关，便于未来恢复）：
   - 画布浮动工具条裁切按钮
   - 选中工具条裁切按钮与自由图放回画格按钮
   - 属性面板：精确调整（X/Y/宽/高/旋转/透明）、画格属性（形状/圆角/边框/分离）、图片与裁切（crop-controls）、文字角色与 SFX 预设、富文本编辑器（LayoutRichTextEditor）、气泡外观/数值/尾巴 5 字段（balloon-controls）
   - 图层 Tab
   - 阅读顺序编辑
   - 换图镜头条（shot-replace-strip）
   - 右键菜单「在画布上拖调裁切」
   - 画布设置抽屉的画格模板（layout-preset-picker）
3. 保留：拖拽实时预览、双击就地改字、Delete 确认删除、有限本地撤销、导出预检与文字差异确认、文字预检摘要（text-preflight-summary）、画布尺寸/段高设置。

## 2026-08-03 追加一（用户画布反馈）

- 默认缩放 0.24 → **0.4**（24% 画布过小，气泡/元素难以操作）。
- 修复选中工具条显示不全：原 `left` 硬编码 `canvas.width * zoom - 240`，工具条加宽（气泡类型+字号+颜色+粗体）后右侧被画布边缘裁切；改为 `ResizeObserver` 实测工具条宽高，`left/top` 按画布边界与工具条尺寸双向钳制（上方放不下则放下方，下方溢出则收进画布）。
- 移除选中工具条最右侧「更多设置」按钮（点击弹出的锁定/隐藏/删除弹窗与工具条重复，普通用户无必要）；`openInspectorForSelection` 一并删除，属性面板仍从顶部「属性」按钮进入。
- 工具条 hover 提示缩短：色板 `文字颜色 #RRGGBB` → 颜色名（黑/白/红/蓝/橙/绿/紫），「复制对象/锁定对象/删除对象」→「复制/锁定/删除」，「显示或隐藏尾巴」→「尾巴」。

## 2026-08-03 追加二（工具条显示不全根治）

- 根因：选中工具条是 `.document-canvas`（`overflow:hidden`，宽度=画布宽×缩放，40% 下仅 432px）的子元素，工具条（气泡类型+字号+颜色+粗体）实际宽度超过画布宽度，右侧必然被画布裁切。上一版「按画布宽钳制 left」无效，因为工具条本身比画布宽。
- 根治：把 `selection-toolbar` 从 `document-canvas` 内**移到 `stage-wrap`（可视区）层**，用「画布在滚动容器内的居中偏移（padding 40/48 + margin auto）+ 元素画布坐标 − 滚动偏移」换算成可视区坐标，再按可视区宽高 + 工具条实测尺寸双向钳制；滚动时 `handleStageScroll` 更新 `stageScrollPos` 重算位置。工具条现在可以浮出画布边缘显示，只要不超出可视区。
- 教训：涉及模板结构调整时，oldString 必须包含被移动区块的完整开合标签，避免误删/误留开标签（本次误删 inline-text-editor 开标签，靠 typecheck 未兜住模板结构错误，靠人工读文件修复）。
- e2e m5 新增断言：选中气泡后工具条 bounding box 必须完整位于视口内（x≥0、y≥0、右缘≤1180、下缘≤900），锁定显示完整回归。

## 2026-08-03 追加三（移除段落列表）

- 产品判断：段落（canvas）是竖条漫的版面容器，普通用户不理解也不需要；「新增/复制/移动段落」属专业操作。左栏移除整个段落导航列表，只保留「镜头素材栏」与「来源状态」。
- 代码：删除 `addCanvas` / `duplicateCanvas` / `moveCanvas` 三个函数与段落列表模板（含 `.canvas-nav-item` / `.canvas-list-actions` 区块）；`selectCanvas` 保留（session 层与设置抽屉仍用）。
- e2e：m4 改为断言段落列表已移除（`canvas-nav-item` 计数 0、无「新增段落/新增页面」按钮）+ 画布数保持 1；m6 的「新增段落制造修改」改为「添加文字元素制造修改」，restore 断言不变。
- 验证：web 契约 55/55、e2e db 18/18 全绿。

## 2026-08-03 追加四（删除/重建二次确认改自定义弹窗）

- 问题：删除对象和「用当前定稿重建」使用浏览器原生 `window.confirm`，与项目深夜蓝黑+紫/红风格不符。
- 修复：新增 `LayoutConfirmDialog.vue`（Teleport 到 body，样式对齐 `DeleteProjectDialog`：模糊遮罩、红色渐变主按钮、危险图标），删除对象（`deleteElementsWithConfirm`）与重建草稿（`rebuildLegacyDraft`）改为状态驱动弹窗（`requestConfirm` + `runConfirmAction`），文案拆为 title/message/confirmLabel。
- 验证：web 契约 55/55、e2e db 18/18 全绿；m4 新增断言——右键删除弹出自定义 dialog（非原生 alert）、取消不删、确认删除生效。

## 影响范围

- 后端协议：无变化（命令/文档模型/导出链路全部未动）。

## 数据或协议变化

无。样式修改全部复用既有正式命令：

- 文字：`text.apply_range_style`（全选 range）

- 粗体按字体目录匹配同 family 的 700/400 字重资产（与富文本编辑器 `matchingFace` 同逻辑）

## 已知风险

- 富文本编辑器隐藏后，段内混排（局部加粗/变色/字距/描边）不再有普通入口；如未来需要，可用 `advancedToolsVisible` 开关恢复（localStorage 键已不采用，因违反 g5-m3 契约；恢复需改为显式设置或路由参数）。
- e2e m4/m5 删除了对模板/裁切/精确调整/图层/阅读顺序的 UI 操作断言，改为锁定「默认隐藏」态；相关后端命令仍由服务端 spec 覆盖。
- 气泡外观预设、尾巴数值、阅读顺序等能力的 UI 入口暂时无普通用户可达路径，底层契约与命令保留。

## 后续建议

- 遮挡硬门（无视觉证据时禁止对白主体进入画格）仍是对白准确性最大缺口，建议独立任务。
- 用户修改回流（排版偏好账本）为远期方向，见设计文档 §6.2。
- 契约测试可补一条「advancedToolsVisible 默认 false」的源码断言，防止未来误开。
