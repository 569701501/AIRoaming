# G5-M0 固定语料与红灯基线完成记录

## 功能摘要

建立 G5 成稿编辑器与确定性出版的可复现起点：8 份固定 LayoutDocument corpus、固定图片/拉丁字体字节、性能规模、known-answer 摘要、旧复制导出见证和 renderer/migration/E2E 红灯入口。

## 影响范围

- 根测试脚本与 G5 专用 gate report。
- `tests/fixtures/layout/` 固定语料。
- file-mode 七阶段旧 layout export 行为刻画。
- G5 E2E vertical-slice 合同。

## 数据或协议变化

无数据库和公开 API 变化。fixture corpus 采用 `g5_layout_fixture_corpus_v1`，corpus digest=`sha256:9acf40013492dd82003fc24af944897db834203e11d02cacee1c457ebe115527`。

## 验证结果

- fixture contract 连续三次 3/3。
- Server 完整 80 files/536 tests。
- 全仓 typecheck、E2E typecheck、build、diff check 通过。
- `test:render`、`test:migration:g5`、`test:e2e:g5` 按 M0 契约输出结构化红灯和非零退出码。

## 已知风险

- 受控 CJK 字体、实际 cmap/许可证、浏览器语义、正式 PNG/PDF/slice 与确定性 sha 仍待 M1。
- legacy runtime 出口尚未删除；必须等 M7 新出版链路 green、M8 migration/cutover 通过后处理。

## 后续建议

直接执行 M1 两条完整技术薄切片；任一候选只有同时通过文字语义、重复 sha、真实 PNG/PDF/slice、字体隔离、IME/Undo、性能和许可才能进入技术 ADR。
