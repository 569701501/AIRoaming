# 功能摘要

完成 G2 剩余两类任务的 DB 闭环：`shot_prompt_generate` 与 `image_generate` 由统一创建门禁冻结当前来源和 generation spec，持久 worker 完成 strict output、provider 调用和 completion transaction；图片结果写入 staged→ready Asset 与 Candidate，迟到结果保留 historical 且不改变当前锁。

# 影响范围

- 新增 `apps/server/src/projects/persistent-g2-task-create-guard.service.ts`。
- 扩展 `ProjectsService`、`ProjectsModule`、`PersistentTaskRepository` 和 `PersistentTaskWorkerService`。
- 新增 fresh SQLite 集成测试，未新增 Prisma migration、表或字段。
- 修正 `story_parse` / `shot_generate` 的并发键为注册表规定的 `llm-provider`，四类 G2 幂等键按施工资料模板生成。

# 数据与协议变化

- prompt/image source projection 至少包含 `storyboard_version`、`shot`、`preflight_revision`；有效角色/场景视觉按 Preflight SourceSnapshot 追加。
- `promptSpec` 使用 shared JCS/SHA-256 `generationSpecDigest`；image 任务额外要求非空 `requestId`。
- Candidate 使用 `generationPurpose=shot_clean_plate`、`generationSpecVersion=2`、`generationSpecDigest`，资产写入时保留 `sourceTaskId` 和 metadata digest。
