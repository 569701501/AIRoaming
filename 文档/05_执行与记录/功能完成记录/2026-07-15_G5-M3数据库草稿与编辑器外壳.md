# G5-M3 数据库草稿与编辑器外壳

## 功能摘要

完成成稿编辑器的数据库草稿层和真实页面外壳。用户现在可以从当前 G4 定稿来源建立默认或空白草稿，在桌面编辑基础几何/锁定/隐藏/图层并自动保存；多标签冲突不会静默覆盖，窄屏只读不会发起写入。

实现提交：`ec71594`。

## 影响范围

- Shared 新增 Working Copy 初始化、保存、响应与 recovery 严格协议。
- Server 新增 0013 forward-only overlay、13 段 runtime ledger、DB-only Working Copy service 和三条公开 API。
- Web 新增内存 history/autosave/conflict session 与完整宽度编辑器外壳。
- E2E 默认门禁按 file/DB 两种模式分开运行，新增 spec 穷尽归属回归。

## 数据与协议变化

- Working Copy 只保存 `schemaVersion=1` 的规范 LayoutDocument，写入使用 expected rowVersion CAS。
- 精确相同 request 可 replay；内容未变返回 no-op；冲突返回服务端状态和可下载的本地 recovery。
- Server 保存时按 DB authority 复核 current lock set、source digest、ready Asset sha/尺寸和受控字体；autosave 不生成正式 LayoutRevision。
- 0013 仅 forward apply；没有 down migration，没有双写 legacy `layout.json`。
