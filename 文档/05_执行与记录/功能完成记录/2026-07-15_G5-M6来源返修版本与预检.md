# G5-M6 来源返修、不可变版本与预检

## 功能摘要

成稿编辑器已能识别上游候选定稿变化，在不改写旧版本、旧导出或源 Asset 的前提下预览并提交单张/批量来源替换；替换可以一次 Undo/Redo。用户可以运行稳定预检、显式确认 warning、保存线性不可变 LayoutRevision，并从历史版本恢复新的 Working Copy 而不移动正式 current。

实现提交：`429ec69`。

## 影响范围

- Shared 增加严格来源替换、正式预检、Revision/历史/恢复请求与响应契约。
- Server 增加 DB-only source replacement preview/commit、Working Copy/Revision preflight、线性不可变 Revision/SourceBinding、历史详情与恢复服务和公开 API。
- Web 增加来源返修控制区、逐项 warning 确认、保存不可变版本、current/stale 历史展示和恢复到草稿。
- Prisma 增加 0014 forward-only migration，修复旧 source binding trigger 对复合 sourceDigest 的错误比较。
- E2E 增加 G4 A→B→M6 来源返修→预检→Revision→历史恢复的真实页面路径。

## 数据与协议变化

- `sourceDigest` 继续是 Candidate source identity 与 Asset sha 的复合摘要；它不是 `Asset.sha256` 的别名。
- 0014 不改变表结构，只替换 `trg_layout_source_bindings_scope_insert`；scope、Candidate/LockRevision、ready Asset、sha 非空与 unsealed revision 门禁继续存在，seal trigger 继续校验文档/绑定集合。
- LayoutRevision 创建固定为 unsealed→SourceBinding[]→seal→Chapter current→Working Copy basedOn 单事务；恢复历史只写 Working Copy。
- warning acknowledgement 必须来自当前 preflight report；重复、未知、缺失确认均 fail-closed。
