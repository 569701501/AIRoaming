# G5-M4 画格、图片、模板与裁切

## 功能摘要

成稿编辑器已能直接消费当前 G4 定稿图片，完成画格、自由图片、Shot 素材栏、七类模板、非破坏裁切、阅读顺序和页漫/条漫批量排版。全部修改继续保存到 DB-only Working Copy，不改源图，不提前创建正式版本或出版物。

实现提交：`93a58b2`。

## 影响范围

- Shared 增加可见 Shot 放置投影和页漫/条漫批量初始化规则；补强模板保留对象、换图保持画格和 crop coverage 测试。
- Server 增加只读 current source catalog API，继续在保存事务内复核 G4 current lock、Asset sha/尺寸和裁切覆盖。
- Web 增加 PanelFrame/FreeImage/Shot tray、模板、crop、reading order、canvas reorder 和批量排版交互。
- E2E 增加 fresh SQLite 的 G4→M4 真实路径，并纳入 DB 模式穷尽矩阵。

## 数据与协议变化

- 新增 `LayoutSourceCatalogResponseV1`，只投影当前完整 G4 lock set；每项包含 `order/source/width/height`。
- catalog 不持久化新权威，不接受客户端指定旧 lock；Working Copy 中仍保存完整 CandidateImageSource 和 source digest。
- Panel contentImage 保持嵌套；FreeImage 才是顶层对象。所有 crop 都是非破坏参数，源 Asset bytes 不变。
