# G3-M3-A1 数据库审计完成记录

## 功能摘要

将 M3-A0 迁移账本接入 Prisma/SQLite，并提供 `db:audit`，可在 fresh G1/G2/G3 migration tree 上持久化 audit run、issue 和 source provenance。

## 影响范围

- 新增 Prisma ledger repository 与 DB audit service/CLI。
- `MigrationAuditService` 改为依赖 ledger port，并在审计中途失败时收敛 failed run。
- package script 与 G1 schema manifest 已同步。
