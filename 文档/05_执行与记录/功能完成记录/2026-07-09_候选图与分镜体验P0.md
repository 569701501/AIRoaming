## 功能摘要

让候选图工作台和分镜工作台的用户体验达到市面主流水准：候选图支持批次分组、prompt 可见、批量生成；分镜支持缩略预览、拖拽重排、批量重编号。

## 影响范围

- 候选图工作台（image_candidates 步骤）：候选展示从平铺改为批次分组；新增 prompt 预览；新增批量生成。
- 分镜工作台（storyboard 步骤）：镜头卡新增候选缩略预览；新增拖拽重排和重新编号。

## 已知风险与残留

- **候选"废弃/备选"主动操作的持久化 API 后置**：当前 5 态视觉已落地，但用户主动废弃/备选的按钮和 `PATCH /candidates/:id/status` 后端接口尚未做。当前 5 态由 lockCandidate 驱动（锁定时其他转 selected/superseded）。
- **拖拽用原生 HTML5**：vuedraggable 因 pnpm store 版本冲突装不上，改用原生 drag/drop。线性列表场景够用，但嵌套表单内拖拽体验不如专门库，后续可评估。
- **候选结果更新依赖 runtime 整快照轮询**：批量生成后需等轮询才看到结果，未做局部更新优化。
- 运行时人工复核待用户验证。

## 后续建议

1. 候选状态持久化 API（`PATCH /candidates/:id/status`）+ 废弃/备选按钮（任务B 后端部分）。
2. 单镜头 AI 重写（P1，需新建后端 service + dialogue tool）。
3. prompt 可编辑（P1，引入持久化+版本）。
4. 对白气泡 / 排版成稿 / PDF 导出（P1）。
