## 功能摘要

设置页“图片生成”新增 `Grok 图片生成` 服务商。用户可独立配置 Grok 生图的服务商名、模型、Base URL 和 API Key；后端在 `activeImageProvider = grok` 时调用 Grok Imagine 图片接口。

## 影响范围

- 全局设置 `AppSettings` 新增 `grokImageProvider`，`ImageProviderType` 扩展为 `openai | doubao | grok`。
- 后端图片 provider 网关新增 Grok 文生图和图生图分支。
- 候选图、角色参考图、场景参考图的 provider metadata 支持 `grok_image`。
- 前端设置页新增 Grok 下拉项和独立配置表单。
- 图片生成串行队列保持不变：候选图通过 `ImageCandidateService.imageQueue` 串行，角色/场景参考图通过 `CharacterReferenceService.characterReferenceQueue` 串行。

## 数据或协议变化

- `workspace/settings/app-settings.json` 归一化后会包含 `grokImageProvider`。
- `activeImageProvider` 支持 `grok`。
- Grok 默认模型为 `grok-imagine-image-quality`，默认官方 Base URL 为 `https://api.x.ai/v1`。
- Grok 文生图使用 JSON `POST /images/generations`；Grok 图生图使用 JSON `POST /images/edits`，参考图以 data URI 传入。

## 已知风险

- 本次没有真实 Grok API Key，未直接发起外部出图；需要用户在设置页填入自己的 Grok 中转 URL/API Key 后做一次真实候选图或参考图生成验收。
- 如果中转服务不是 xAI 官方 JSON 协议或完整 OpenAI 兼容协议，可能需要按中转字段再做适配。

## 后续建议

- 真实出图后记录中转返回格式、耗时和失败码，必要时补 provider 级错误信息解析。
