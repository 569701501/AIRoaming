## 1. 功能摘要

修复并加固灵感种子选择后的写入链路：用户选择某个灵感种子后，应直接生成固定格式「章节剧本」并写入当前章节文档。

## 2. 背景

当前产品口径是“AI 生成 3 个灵感种子，用户选中其一后生成并写入第 1 章”。用户反馈自己已经说了第几个，但没有写入章节。代码中写入链路存在，但选择表达和 UI 显式动作不够稳。

## 3. 影响范围

- 后端增强灵感选择识别，支持裸数字、中文数字和更口语化的选择表达。
- 当用户看起来在选择灵感但无法识别具体序号时，返回明确提示，避免静默落到普通聊天。
- 前端灵感种子卡片新增“生成章节”按钮，直接发送 `generate_script_from_seed` 意图。

## 4. 修改文件

| 文件 | 说明 |
| --- | --- |
| `apps/server/src/dialogue/dialogue.service.ts` | 增强 `resolveSelectedInspirationSeed` 的选择识别和失败提示 |
| `apps/web/src/components/workbench/ProjectDialoguePanel.vue` | 灵感种子卡片增加“生成章节”按钮 |
| `文档/会话/2026-05-29-00-18-灵感选择写入.md` | 记录本次问题和处理结果 |

## 5. 数据或协议变化

无 API 字段变化。前端复用已有 `DialogueIntent = generate_script_from_seed`。

- 未启动真实 OpenCode 模型做端到端生成验收；真实写入仍依赖 OpenCode runtime 可用。
