# M5-A4-2 恢复账本与发布身份

## 功能摘要

restore 现在必须绑定显式 current release identity，并逐项验证 coordinated bundle 的 16 条 MigrationRun、run-summary、open MigrationIssue 和 PersistenceState；外层摘要重算后的语义篡改也会 fail-closed。

## 影响范围

- `verify-only` 与 `materialize` 共享同一完整验证链，materialize 只有在验证结束后才创建 staging。
- 不改变 Prisma schema、migration、trigger、backup fence、final importer、SecretStore 或 activate。
- A4-3/A4-4 未完成，M5 仍为 `hardening_required`。

## 修改文件

- `apps/server/src/backup/app-restore.service.ts`
- `apps/server/src/backup/app-restore.cli.ts`

## 数据与协议变化

- `RestoreInput`/CLI 新增必填 `releaseRoot/--release-root`。
- release identity 不匹配固定返回 `RESTORE_RELEASE_IDENTITY_MISMATCH`。
- run-summary 固定 16-slice 顺序和 exact keys；DB ledger 核对 run/status/importerVersion/摘要/counts/schema versions/verification/open issues。
- PersistenceState 必须与 manifest 精确一致并固定为 `shadow/null/null`。
