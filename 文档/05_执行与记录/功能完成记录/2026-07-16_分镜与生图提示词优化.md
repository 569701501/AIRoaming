# 分镜与生图提示词优化完成记录

## 功能摘要

完成 P23 角色参考图、P24 场景参考图、P25/P26 候选图实际生成与页面预览，并根据下游要求反推 P06 分镜提示。候选图页面预览、普通任务、DB 持久任务和 worker 现在共用同一领域规格，实际发送文本按 Provider Profile 编译。

## 影响范围

- 角色参考图：身份预览与四视图定稿契约。
- 场景参考图：空间、透视、地标、角色活动区、时间天气和光线契约。
- 候选图：单场景、单静态瞬间、单主要构图的干净漫画底图规格。
- Provider 边界：显式单 Prompt profile、任务冻结和配置漂移保护。
- 分镜：漫画单帧、构图、阅读方向、气泡安全区和精简 `promptDraft`。
- 页面：仍使用当前字段，只展示服务端权威实际 Prompt。

## 数据与协议变化

- 无数据库 migration、Schema、页面字段、StoryStructure 或 Storyboard payload 变化。
