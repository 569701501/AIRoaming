## 4. 数据或协议变化

- 没有数据库 schema 或 `LayoutDocumentV2` 字段变化。
- `historyGroupId` 是 Web Session 的执行元数据，不进入 Shared command payload、Working Copy、Revision 或 Publication。
- `LayoutSaveContext` 是 Web 运行时身份，不持久化；迟到响应不能跨项目、章节或加载代次提交。
- Shared Preflight 新增 issue code `VISIBLE_TEXT_EMPTY`，严重度为 `error`，适用 `revision/export`，不可确认绕过。

## 6. 已知风险

- 自动排版的视觉直接可用率未由本次状态修复签收；真实首格仍需移动/放大气泡，避免窄断行和主体遮挡。
- 长属性面板与 24% 默认缩放影响精修效率。
- 内置浏览器的弹出标签未出现在自动化标签列表中；直达只读路由与 blocked/navigation_failed 合同均通过。
- 浏览器菜单/右键原生 Undo、字体恢复/清理、保存超时取消、极端字体缩放布局和 V2 Unicode 显式覆盖仍是低优先级 S2。

3. 用更多真实漫画素材做首屏遮挡、窄断行和 SFX 可读性抽样。
