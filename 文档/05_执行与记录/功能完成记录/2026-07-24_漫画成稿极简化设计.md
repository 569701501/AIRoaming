# 漫画成稿极简化设计完成记录

## 功能摘要

完成漫画成稿下一轮极简化设计：在保留内容正确、人工编辑、并发安全、版本追溯和确定性出版的前提下，把普通用户路径收敛为“打开或恢复 → 编辑或整理 → 预览并导出 → 确认 → 下载”，并明确删除、合并和内收现有重复入口。

本轮交付是实施基线，不包含生产代码、数据库或测试成稿修改。

## 影响范围

- 产品主流程：普通用户只面对一个工作台、一个权威视觉面和一条发布链。
- 架构边界：新增建议性的 `open/change/release` 深门面，不替换底层事实。
- 内容正确性：把正式对白/旁白覆盖从出版末端前置为 Working Copy 内容就绪门。
- 页面删减：AI Drawer、MiniPreview、mode/intent、M6 四步和重复预检 UI 等退出普通路径。
- 实施顺序：先 shadow evaluator 和可撤销内容修复，再 fail-closed，最后删页面与旧 Web 编排。

## 已知风险

- 内容就绪 evaluator 尚未实现，现有错误 Working Copy 仍可能在普通只读页看起来正常。
- 现有 full/scoped reflow 不能补建 dialogue binding，必须先完成 reconciliation 命令。
- 图片像素内 AI 乱码和镜头语义偏差仍属于上游候选图质量，不由排版编辑器修复。
- 页面删减必须晚于 Facade 等价 E2E；不能先删底层恢复和正确性能力。
