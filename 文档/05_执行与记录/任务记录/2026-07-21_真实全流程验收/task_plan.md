# 真实全流程验收计划

## 目标

在正式 DB-only 环境中，以真实用户身份从项目库开始完成一次 G0～G6 主链路：删除旧项目、新建项目、完成剧本、剧情结构、分镜、出图准备、真实候选图生成与定稿、排版出版和素材包，并对发现的问题完成修复和复验。

## 强制边界

- 只使用 Codex 自带隔离浏览器，不操作用户 Chrome。
- 真实文本和图片调用已获用户授权，不以费用或 token 为由缩减验收。
- 验收推进中将第 7 步素材包纳入实测；素材包必须与页面承诺一致，不能只检查入口。
- 不覆盖工作区中已有的旧验收截图改动。
- 所有正式推进必须由页面上的确认、完成、定稿或出版动作产生，不能用接口直接伪造用户路径。

## 阶段

| 阶段 | 工作 | 退出标准 |
| --- | --- | --- |
| O1 基线 | 核对服务、项目清单、Provider 与验收边界 | 记录旧项目 ID、服务地址和当前范围 |
| W1 项目库 | 删除旧项目，测试创建表单，新建竖向条漫项目 | 列表只存在新项目，创建后进入剧本页 |
| W2 剧本 | 通过真实 AI 路径生成、采用并完成第 1 章 | current ScriptVersion 存在，结构解锁 |
| W3 结构 | 生成待确认结构、检查字段/人物/场景/beat 后确认 | current StoryVersion 绑定正式剧本，分镜解锁 |
| W4 分镜 | 生成待确认分镜、检查镜头和详细说明后确认 | current StoryboardVersion 绑定结构，preflight 可用 |
| W5 出图 | 验证 blocked→ready，真实生成候选并定稿 | current PreflightRevision 与所有镜头 CandidateLockRevision 齐全 |
| W6 排版 | 初始化多格布局、预检、保存版本并出版 | layout_publication 成功，PNG/切片与 manifest 可核对 |
| W7 素材包 | 导出数据库正式来源、锁定图和出版物 | manifest 与磁盘文件一一对应，阶段状态不提前完成 |
| R1 修复 | 对页面测试发现的问题定位、修复、回归 | 每个阻断缺陷有复现、修复和页面复验证据 |
| R2 复核 | Scrutiny Review、Runtime/User Review、Handoff | 证据逐项覆盖目标，无未说明的必需项 |

## 正常路径验收

- 创建时不选漫画版式不能提交；正确创建后直接进入剧本页。
- 剧本、结构、分镜都必须先形成待确认结果，再由用户动作成为正式 current。
- 出图准备不得自身触发图片生成；素材缺失时必须明确阻断。
- 至少完成一次真实图片 Provider 调用，核对任务、文件、Asset、来源摘要和页面显示。
- 未逐镜定稿时排版/完成动作应被阻断；全部定稿后才推进。
- 正式出版物可打开，来源、Asset、任务和 manifest 可追溯。
- 素材包必须包含页面列出的 script、structure、storyboard、preflight、candidates、layout、锁定图、出版图、角色索引和根 manifest。

## 负向与交互测试

- 创建弹窗必填门禁、取消与重新打开。
- 直接点击等待步骤、重复点击生成/确认、刷新与返回项目库。
- 出图准备 blocked/ready 状态、候选生成中重复操作、未定稿完成门禁。
- 排版 stale、预检错误/警告、保存与出版状态反馈。
- 浏览器 console error/warn、失败请求和长任务刷新恢复。

## 完成条件

用户要求的删除、新建、逐阶段真实推进、真实出图、多轮点测、问题修复与复验均已有当前证据；静态复核、运行复核和 Handoff 已完成。页面可打开或接口返回 200 未被单独作为通过依据。
