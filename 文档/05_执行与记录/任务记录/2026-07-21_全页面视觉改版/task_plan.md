## 目标

盘点绘界漫画当前全部用户可达页面，在不改变七阶段流程与业务契约的前提下，保存现状截图，并交付一套统一、专业、可用于评审的高保真页面视觉稿。

## 非目标

- 本轮不修改生产前端代码。
- 不改变页面字段、状态机、数据模型、任务协议或素材路径。
- 不触发绘界漫画业务内的图片 Provider 或生成任务。

## 当前阶段

阶段 6：Runtime/User Review 与交付；AI 侧交付已完成，等待用户确认方向。

## 验收标准

1. 当前用户可达页面有明确清单，并为每个页面保留可查看的现状截图。
2. 每个页面都有对应的新版高保真视觉稿或明确合并说明。
3. 新版保持现有深紫夜色、紫色渐变辉光、玻璃感面板和绿色状态语义，不回到已否决的扁平灰方案。
4. 新版隐藏内部 ID、英文技能名、DB Working Copy、门禁和来源等开发术语。
5. 七阶段流程、左对话右工作区、章节工作单元、项目角色库常驻入口等产品事实不变。
6. 交付物保存在仓库内，附清晰索引与静态复核结论。

## 已做决策

| Decision | Rationale |
| --- | --- |
| 保留现有视觉气质，只做系统级精修 | 用户已明确否决扁平灰 V1，并认为现有页面更好看 |
| 先交付视觉稿，不修改生产页面 | 用户当前要求先看逐页重设计图片 |
| 真实页面截图作为每张概念稿的参考输入 | 降低字段、状态和页面身份漂移 |
| 统一按 1440×900 桌面工作台基线评审 | 便于逐页横向对比并覆盖主要桌面场景 |

## 当前深思熟虑角色边界

- Orchestrator：读取事实源、建立页面清单、控制范围与证据。
- Worker：截图、生成并整理本轮视觉稿，不改生产代码。
- Scrutiny Review：只读检查覆盖、契约与视觉一致性。
- Runtime/User Review：用户查看视觉稿并反馈；本轮由 AI 先完成可交付预览和验收清单。
