## 目标

调研 GitHub 上较热门的开源 AI 漫画/图像生成平台，判断它们是否有类似 AI漫游“出图准备”的生成前检查能力，并给出 AI漫游应该保留、强化或后置的功能建议。

## 非目标

- 不修改业务代码。
- 不直接重设计页面 UI。
- 不以闭源商业平台作为主要证据，只在必要时作为背景参照。

## 验收标准

- 读过项目出图准备、候选图和主链路相关事实源。
- 调研对象覆盖漫画垂直项目和通用热门图像生成平台。
- 结论区分“竞品已有”“竞品没有但 AI漫游应保留”“当前应改进”的功能。
- 外部来源保留链接，调研结论可追溯。

## 阶段

| 阶段 | 状态 | 内容 |
| --- | --- | --- |
| 1 | completed | 项目现状探索 |
| 2 | completed | GitHub 热门开源项目调研 |
| 3 | completed | 对比分析与建议 |
| 4 | completed | 留痕与总结 |

## 角色边界

- Orchestrator：读取事实源、规划调研范围、维护任务记录。
- Worker：执行项目探索和外部调研。
- Scrutiny Review：复核证据是否支持结论。
- Runtime/User Review：本任务不涉及真实页面操作，运行复核仅保留为后续产品验证建议。
