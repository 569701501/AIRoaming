## 需求

- 用户确认采用成熟竖向条漫的留白、节奏与气泡关联方式。
- 气泡需要多种专业样式，字体也需要更丰富。
- 当前目标章节必须重新排版，并用截图确认文字不再遮挡角色。

## 研究发现

- 专业条漫常把气泡主体置于画格间留白；本系统在无视觉证据时采用更严格的完全外置合同，视觉模式也要求气泡完整位于已验证安全区。
- 画内气泡只适合真实负空间，不能以“气泡大部分位于画格内”代替主体避让判断。
- 多种气泡应表达对白语气与媒介差异，不应随机选择。
- 字体变化要服务对白、旁白、强调和设备声层级，同时保证中文字形、许可和出版确定性。

## 缺口与风险

| 风险 | 影响 | 建议 |
| --- | --- | --- |
| 规则 fallback 无主体数据 | 画内气泡不可证明安全 | 默认外置并扩展 section |
| 质量门把空主体当通过 | 遮挡错误可获高分 | 空主体不能获得主体保护满分，硬门按模式区分 |
| 字体依赖系统环境 | 编辑与导出漂移 | 只使用受控 FontAsset 与许可台账 |
| 样式随机多样 | 叙事含义混乱 | 由 dialogue kind/voiceStyle 确定性映射 |

## 技术决策

| 决策 | 依据 |
| --- | --- |
| Rule fallback 使用画格外气泡 body | 无视觉证据时的最小安全保证 |
| Vision 使用 verified textSafeRegion 并硬避让保护区 | 保留专业布局自由度且可审计 |
| 样式不增加第二套可见元素 | 复用现有 V1/V2、编辑命令和 renderer |
| 字体策略进入来源与摘要 | 保证重排、预览和正式导出一致 |

## 实施结果

- 新增普通椭圆、思考云朵、强调爆炸形、深色旁白框四种语义形态；样式由对白语义确定，不随机换皮。
- Noto Sans SC 400/500/700/900 四个真实字体面由 FontAsset ID 精确加载；编辑器、只读预览和 renderer 禁止合成字重。
- 最终目标章节为 Working Copy v73，自动排版基线为 v71，随后只有两处气泡宽度人工精修。
- 最终 19 个气泡中：普通椭圆 9、思考云朵 5、强调爆炸形 2、深色旁白框 3；400/500/900 字重分布为 14/3/2。
- 桌面和手机真实预览均为 0 文字溢出、0 气泡碰撞、0 气泡与画格相交。

## 复核发现

### Scrutiny Review

- **结论：PASS。**
- 规则 fallback、视觉安全区硬门、来源关联、Web/renderer 透明色与轮廓、视觉角色稳定性、kind/尾巴原子切换均复核通过。
- 非阻塞边界：生成元素用 fill+stroke 指纹保留推断视觉角色；未来若支持用户只改单一颜色，应升级为显式 `visualRole`，避免回落到 speech 轮廓。

### Runtime/User Review

- **结论：PASS。**
- 自动 v71 已关闭原有角色遮挡；Runtime Review 提出的两处手机断行问题已在 v73 完成精修。
- 桌面 1440×1000、手机 390×844、真实应用、刷新、Undo、读者预览、renderer 和字体嵌入均通过。
