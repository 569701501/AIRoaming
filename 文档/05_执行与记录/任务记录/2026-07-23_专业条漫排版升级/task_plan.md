## 关键问题

1. 现有四类气泡的形状/样式字段能否在不升级可见元素类型的前提下表达专业变化？
2. 哪些中文字体已在仓库或依赖中具备可再分发许可和确定性渲染条件？
3. 规则模式的外置气泡如何与来源画格保持明确关联，同时不依赖伪造尾巴？
4. 视觉模式的画内气泡应以哪些安全区、保护区和质量门为准？

## 已做决策

| Decision | Rationale |
| --- | --- |
| 规则模式气泡主体默认画格外置 | 系统未看见画面时不能证明画格内部安全 |
| 视觉模式只允许气泡完整落在同来源的 verified `textSafeRegion` | 在具备视觉证据时利用真实负空间，同时保持安全合同可验证 |
| 气泡样式由对白语义确定，不随机换皮 | 保持叙事含义、可预测性和可编辑性 |
| 字体必须是受控 FontAsset，编辑/renderer/导出共用 | 避免系统字体漂移和导出不一致 |
| 不另建第二套排版器或扁平图片结果 | 遵守 ADR-0019 与既有 V2 编辑闭环 |

## 退出标准

- 规则模式所有自动气泡主体均不进入来源画格，且 section 会按真实文字测量扩容。
- 视觉模式画内气泡必须位于验证过的安全区，且不遮挡脸、身体、手、关键动作和关键道具。
- 普通对白、思考、喊叫、旁白至少有清晰不同的专业形态；字体角色有确定性语义映射和许可记录。
- Shared、Server、Web、renderer 和导出保持一致，现有 V1/V2 与人工保护回归通过。
- 目标章节完成真实重排、页面截图、renderer/导出复核，遮挡问题被逐段关闭。
- Scrutiny Review 与 Runtime/User Review 均给出明确结论。
