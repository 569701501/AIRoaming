# 漫画成稿编辑器极简重构 task_plan

## 1. 背景与目标

当前漫画成稿（`layout_export`）数据链路已是产品级（自动排版 / CAS 自动保存 / 导出预检），但 2026-07-26 体验评估确认短板在**手动调整环节**：

- 右侧常驻属性面板堆了近 10 个区块（精确几何 / 画格 / 裁切 / 文字语义 / SFX 预设 / 富文本 / 气泡 8+ 字段 / 文字预检 / 阅读顺序 / 页面设置 / 模板）,内部概念（画格 / 自由图 / 语义角色 / 图层 / 阅读顺序）全部平铺暴露。
- 画布操纵不顺：拖拽无实时预览（盲拖）、画布上不能改文字、没有 Undo,调错只能手动调回。
- 第三套私有蓝色主题（`--le-accent:#4f8cff`)，选中态蓝 / 薄荷绿 / 橙三色并存，与项目深夜蓝黑视觉脱节。
- `LayoutExportWorkspace.vue` 已 3901 行，编排器过重。

用户确认的产品流程不变：**自动排版 → 手动调整 → 没问题导出**。本次只让"手动调整"变简单。

**目标**:以「极简画布 + 浮动工具条」重构编辑器 UI/交互，让四类核心调整在画布上就近完成：

| 核心操作 | 目标形态 |
| --- | --- |
| 移动 / 缩放画格 | 画布直接拖拽，拖动过程实时可见 |
| 挪气泡 / 改遮挡 | 画布直接拖拽气泡与尾巴，就近改类型 / 开关尾巴 |
| 改文字内容 | 画布双击就地编辑文字 |
| 调裁切范围 | 选中画格后就近进入裁切，画布拖调 |

**非目标**:

- 不改 LayoutDocument / 命令 / Working Copy / Revision / Publication 任何协议。
- 不改自动排版（rule / visual composer）与导出渲染后端。
- 不改导出对话框流程（预检阻断 → 文字 review → 下载）。
- 不激活沉睡能力（full/scoped reflow、Pending 命令、版本历史 UI)，也不在本任务删除它们的底层代码。
- 不做无限白板、绘画、专业矢量编辑。

## 2. 设计决策（2026-07-30 用户已确认冻结）

| # | 决策 | 结论 |
| --- | --- | --- |
| D1 | 右侧常驻属性面板 | ✅ 移除常驻面板，改为选中元素旁的**浮动工具条**（常用 4~6 个动作）+「更多」弹出层收纳高级设置 |
| D2 | 左侧栏（页面导航 + 镜头素材） | ✅ **默认收起**，顶栏按钮按需展开为浮层；阅读顺序留在该浮层内 |
| D3 | 页面设置 / 画格模板 / 精确几何 / 气泡高级参数 | ✅ 收进「画布设置」抽屉（顶栏入口），默认不可见 |
| D4 | 画布直接操纵 | ✅ 拖拽实时预览（拖动即更新视觉，松手才提交命令）；双击文字 / 气泡**画布就地改字**（复杂排版仍走「更多」）;Delete 删除保留 |
| D5 | Undo | ✅ 做：**有限本地 Undo**,Ctrl/Cmd+Z + 顶栏撤销按钮，内存栈（上限 50 步，仅当前会话，不落协议） |
| D6 | 主题 | ✅ 废弃 `--le-accent` 蓝色私有主题，并入项目深夜蓝黑 + 薄荷绿完成态视觉，选中态统一单色 |
| D7 | 图层面板 | ✅ 保留但降为「更多」里的二级入口（锁定 / 隐藏 / 上下移同时保留在浮动工具条与右键菜单） |
| D8 | 对齐 / 分布按钮 | ✅ 从常驻画布工具条移除，收进多选时的浮动工具条 |

## 3. 阶段划分

| 阶段 | 内容 | 退出标准 |
| --- | --- | --- |
| M0 | 设计定稿：本文档 D1~D8 经用户确认 | 用户明确确认 |
| M1 | 布局骨架：三栏改画布优先；左栏抽屉化；右侧常驻面板移除；主题并入项目视觉；`LayoutExportWorkspace.vue` 拆出导出对话框 / 设置抽屉子组件 | typecheck + web 构建通过；画布在无面板时占满主区 |
| M2 | 浮动上下文工具条：按元素类型（画格 / 气泡 / 文字 / 自由图 / 多选）就近显示核心动作 +「更多」 | 四类核心操作均可不离开画布完成 |
| M3 | 画布直接操纵增强：拖拽实时预览、双击就地编辑文字、裁切就近入口 | 拖动全程可见；文字双击可改 |
| M4 | 有限本地 Undo(Ctrl/Cmd+Z + 顶栏按钮，内存栈 ≤50 步） | 连续调整后能逐步撤回，刷新后清空不报错 |
| M5 | 高级收纳 + 契约测试 / e2e 重写：m4/m5/m6/m7 相关断言按新 UI 重写，contract test 更新 | `corepack pnpm test`、web contract test、layout 相关 e2e 全绿 |
| M6 | 复核与留痕：Scrutiny Review + 用户真实浏览器验收 + 完成记录 + 文档同步 | 双复核通过，完成记录入库 |

## 4. 影响面预估

- 主改：`LayoutExportWorkspace.vue`（拆分为若干子组件）、`LayoutKonvaInteractionLayer.vue`、`layout-editor-session.ts`（拖拽预览态 / undo 栈）、新增浮动工具条组件与就地文字编辑组件。
- 测试重写：`LayoutExportWorkspace.contract.test.mjs`、`LayoutKonvaInteractionLayer.contract.test.mjs`、e2e `layout-editor-m4/m5/m6`、`layout-publication-m7` 中操作路径类断言。
- 不动：`packages/shared`、server 全部 layout service、导出对话框逻辑、手机只读预览。

## 5. 风险

| 风险 | 缓解 |
| --- | --- |
| e2e 大面积重写，工作量大 | M5 单独成阶段；先重写再删旧断言，避免假绿 |
| 拖拽实时预览若处理不当会产生"预览与提交不一致" | 预览态只改视觉投影，命令提交仍以 Konva transformer 最终值为准；提交后校验 |
| 就地文字编辑与 IME 冲突 | 复用 `LayoutRichTextEditor` 的 grapheme 安全逻辑，就地编辑器只做纯文本快速修改，复杂排版仍走「更多」 |
| Undo 栈与 CAS 自动保存交互（撤回后触发保存） | Undo 只回放到文档状态，复用现有命令通道，自动保存天然跟随；不写独立 undo 协议 |
| 砍掉常驻面板后低频操作找不到 | 「更多」入口在浮动工具条固定位置；右键菜单保留全量动作 |

## 6. 验收标准（用户路径）

1. 首次进入章节 → 自动排版完成 → 画布占满主工作区，无左右常驻面板。
2. 拖一个画格：拖动全程可见位置变化，松手生效，自动保存。
3. 点气泡：气泡旁浮出工具条，可直接改类型 / 开关尾巴 / 删除；双击气泡就地改字。
4. 点画格：工具条可进裁切，画布拖调后退出。
5. 调错按 Cmd+Z 逐步撤回。
6. 点导出：现有预检 → review → 下载流程不变。
7. 全程不出现蓝色私有主题；选中态统一。
