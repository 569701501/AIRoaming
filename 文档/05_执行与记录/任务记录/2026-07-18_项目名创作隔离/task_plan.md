# 项目名与创作内容隔离任务计划

## 目标

修复项目名（例如 `1111`）被当作题材、故事标题或创作事实送入模型的问题。项目名只用于项目库、导航、会话标题、日志和内部定位；除非用户本轮明确写出该名称，否则创作 Prompt 不得使用它。

## 非目标

- 不改变现有页面字段、剧本格式、StoryStructure、分镜或图片 JSON Schema。
- 不改变 A2～A5、B1～B5 的确认门和状态机。
- 不迁移或强制清空历史项目已经确认的故事标题。
- 不调用付费文本或图片服务。

## 验收标准

1. 新建项目仅填写项目名时，不再把项目名静默保存为已确认故事标题或项目描述。
2. A2、A3、A4、A5、剧情结构、分镜和通用对话的生产 Prompt 均不包含仅作为管理标签的项目名。
3. 用户本轮明确输入项目名时，原文仍可经 `USER_REQUEST` / 用户消息正常进入模型。
4. 页面继续按现有条件展示故事标题；故事标题为空时不新增占位字段或交互。
5. 回归测试覆盖项目创建和生产 Prompt 全链路，相关全量测试、类型检查和构建通过。

## 阶段

1. Orchestrator：读取事实源、冻结管理名/故事标题边界、建立反馈环。
2. Worker 1：先补失败回归测试，锁定 A2 与所有生产 Prompt 不含管理名。
3. Worker 2：修复 Skill references、动态装配和项目创建默认值。
4. Worker 3：执行专项与全量验证，检查历史兼容和页面投影。
5. Scrutiny Review：只读复核变更范围、事实源、测试和残留风险。
6. Runtime/User Review：用本地真实创建项目与离线 Prompt 装配验证；不调用付费 provider。

## 退出标准

- 所有验收标准都有测试或静态证据。
- 任务 `progress.md`、`findings.md`、静态复核和运行复核完整。
- 对应架构/产品事实源和功能完成记录已同步。

## 完成结论

全部阶段已完成。项目管理名已从生产 Prompt、通用对话和 AI 状态工具输出中隔离；项目创建默认值、历史同值兜底和专项回归均已闭合。
