# 候选图必需引用编译 P0 任务计划

## 目标

把候选图的角色与场景视觉条件从“尽量传入”升级为可验证的必需引用合同：Provider 容量足够时直接传原始单人角色图和场景图；容量不足时确定性生成多人身份板，仍保留场景视觉引用；任何必需条件无法覆盖时在调用模型前失败，不再静默省略。

## 非目标

- 本轮不实现结构化 `ShotStagingPlan`、场景构图板或站位可视化。
- 本轮不实现基于 mask 的局部角色修复。
- 本轮不训练 LoRA、Multi-LoRA 或其他角色专用模型。
- 本轮不运行付费真实图片 A/B，不把“引用已完整送达”描述成“成图质量必然一致”。
- 本轮不把角色、场景和构图压成一张巨型拼图。
- 本轮不改变候选图工作台的用户操作流程。

## 阶段

| 阶段 | 角色 | 状态 | 退出标准 |
| --- | --- | --- | --- |
| P0-0 事实源与实施边界 | Orchestrator | completed | 现有任务、Provider、素材与 Prompt 链路明确；方案和验收门固定 |
| P0-1 引用计划与身份板 | Worker | completed | Provider 无关计划可证明覆盖；身份板确定性生成并有技术清晰度门禁 |
| P0-2 两条生成链路接入 | Worker | completed | 文件兼容路径和 DB-only worker 均消费同一编译逻辑并保留证据 |
| P0-3 测试与事实源同步 | Worker | completed | 单测/集成回归通过；架构、任务协议、模块和 Handoff 一致 |
| P0-4 静态复核 | Scrutiny Review | completed | 只读核对代码、协议、测试和 Handoff，输出通过/不通过及风险 |
| P0-5 运行复核 | Runtime/User Review | completed | 非付费本地运行链路通过；真实 Provider 视觉 A/B 明确留作用户后续验收 |

## 强制验收标准

1. Grok 只有一张角色或场景参考时必须走图片编辑并实际使用该资产，不能退回纯文生图。
2. Grok 的“三个角色 + 一个场景”必须编译为不超过三张物理输入，所有四个原始条件均出现在覆盖证据中，`omittedRequired=[]`。
3. OpenAI 和 Doubao 在容量与输入预算允许时继续直接传独立角色图和场景图，不为跨 Provider 表面统一而强制合板。
4. 引用计划无法覆盖全部必需条件、输入损坏、角色只有布局不确定的 `final_reference` 而没有 ready 的单人 `preview_front`，或身份板低于技术最小单元尺寸时，必须在调用外部 Provider 前失败。
5. 多人身份板只包含角色身份：每个来源角色出现一次、统一单元、无姓名/编号/格线/水印/剧情背景；场景保持独立物理输入。
6. 结果证据至少记录编译策略、原始来源资产、Provider 实际槽位顺序、每槽覆盖条件、身份板布局版本/摘要/尺寸和 `omittedRequired`。
7. 文件兼容路径与 DB-only worker 使用同一 Provider 编译器；候选结果中的 `usedReferenceAssetIds` 表示已被实际物理输入覆盖的原始来源资产，而不是临时身份板 ID。
8. 新增测试覆盖：零引用、单引用、容量内直传、Grok 三角色加场景打包、超出身份板技术容量、损坏图片和 Provider 失败。
9. 不发起真实付费图片调用；运行复核只验证本地确定性编译、请求体和证据链。

## 关键决策

- 完整视觉需求先于 Provider 槽位；压缩只能改变物理封装，不能删除必需条件。
- P0 在统一的 Provider 边界编译引用计划，使文件兼容路径和 DB-only 路径天然共享行为。
- 身份板是由冻结源资产确定性派生的内存输入，不新增项目级角色资产；保存来源、算法版本和字节摘要，以便审计和重建。
- DB-only 的 `final_reference` 是出图准备批准证据，不直接充当候选图身份输入；候选任务另外冻结 ready 的 `preview_front` 单人锚点及其 CharacterVisual 来源。现有四视图布局并不统一，禁止固定格位猜裁。
- 新生成的 `final_reference` 记录实际使用的 preview `sourceVisualId`；候选任务优先沿这条来源冻结身份锚点。旧资产没有来源关系时，仅在同角色存在唯一可验证的更早 preview 时兼容；多解、缺失或已存在但无效的来源关系必须失败关闭。
- 角色板采用固定布局与像素预算形成技术门禁；该门禁只证明输入仍可读，不宣称模型身份保真已通过真实 A/B。
