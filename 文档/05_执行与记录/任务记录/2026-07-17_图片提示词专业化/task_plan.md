# 任务目标

将当前随项目早期形成的图片生成 Prompt 升级为有公开资料依据、符合 AI 漫画生产场景、按 Provider 能力适配并可固定评测的专业 V2；在 V2 完成离线检查前，不调用付费图片服务。

# 非目标

- 不改变当前页面展示字段。
- 不新增用户确认节点。
- 不把漫画静态图与漫剧动态镜头混用同一套 Prompt。
- 不直接照搬未经验证的“万能神词”或泄露的所谓系统提示词。

# 验收标准

1. 每一类 Prompt 均能说明参考来源、吸收的方法和未采用的做法。
2. 漫画静态候选图与漫剧关键帧/视频提示词职责分离。
3. OpenAI、Doubao、Grok 不再只换 `profileId` 而共用完全相同的最终 Prompt。
4. 保持当前页面与领域字段不变。
5. 真实图片测试必须在 V2 和离线门禁完成后，且再次获得用户确认。
6. 2026-07-17 用户明确要求停止图片生成；在用户未来重新提供明确预算授权前，不得执行任何 `--execute` 图片 A/B。

# 回滚策略

- V2 通过独立版本/Profile 接入，保留当前版本作为 A/B 基线。
- 真实测试失败时不替换生产默认 Profile。
- Provider 参数修复与内容 Prompt 改动分别记录，避免把水印、比例、参考图能力问题误判为文案问题。
