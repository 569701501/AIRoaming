# 《雨夜证词》完整两章剧本

## 第 1 章：最后一班渡轮

### 场景 1：旧港候船厅 / 深夜 / 暴雨

停航通知在电子屏上反复闪烁。记者林澈浑身湿透，手里攥着一只贴有红色封条的录音笔。保安老周正在锁门。

林澈：“最后一班船真的走了？”

老周没有看他，只把钥匙插进卷闸门。

老周：“今晚没有船。你也没来过。”

林澈注意到老周袖口沾着蓝色油漆，与失踪证人短信里提到的“蓝门仓库”颜色相同。他悄悄打开录音笔，屏幕显示剩余电量 6%。

### 场景 2：候船厅后门与栈桥 / 连续

卷闸门落下前，一只女人的手从门外伸进来。林澈用肩膀顶住门，老周却死死按住开关。

门外女人：“林记者！别让他们拿到录音！”

林澈松开录音笔去抬门。录音笔摔在积水里，红灯仍在闪。女人从门缝滚进来，右臂有擦伤。她叫许岚，是失踪案唯一愿意作证的会计。

远处车灯扫过栈桥，两名穿雨衣的人下车靠近。老周低声催促林澈把许岚交出去，称这样三个人都能活。

林澈看向水里的录音笔，又看向几乎站不稳的许岚。他先把许岚推入旁边的救生设备间，再故意捡起录音笔朝相反方向冲上栈桥。

### 场景 3：栈桥尽头 / 连续

雨衣人追上林澈。林澈把录音笔举到护栏外，迫使对方停步。

雨衣人：“你不知道里面是谁的声音。”

林澈按下播放键。杂音后传出市长秘书的声音：“名单在渡轮上，零点前处理干净。”

录音随后出现第二个声音。林澈愣住——那是三年前已经死亡的父亲。

父亲的录音：“小澈，如果你听见这段话，说明我没能回来。不要相信穿蓝色制服的人。”

林澈抬头。老周站在远处，雨衣下露出的正是蓝色制服。

本章结束。

## 第 2 章：蓝门之后

### 场景 1：救生设备间 / 凌晨

许岚用急救布包扎手臂，告诉林澈蓝门仓库保存着渡轮公司的假账。门外传来老周拖动铁链的声音。

### 场景 2：旧港仓库区 / 凌晨

林澈和许岚从设备间后窗逃出，沿父亲录音中提到的编号寻找蓝门。录音笔电量降到 2%。

### 场景 3：蓝门仓库 / 凌晨

两人打开仓库，里面没有账本，只有一排仍在运行的监控屏。最新画面显示林澈进入候船厅，而拍摄时间标注为三年前父亲死亡当晚。

本章结束。
