# 《雨夜证词》标准完整两章剧本

# 章节剧本

## 第 1 章：最后一班渡轮

### 一、基础方向
类型：都市犯罪悬疑
主题：证词、信任与旧案真相
风格：克制、紧张、暴雨夜写实
漫画形式：分页漫画
目标篇幅：完整呈现旧港候船厅、栈桥追逐和录音反转

### 二、本章方向
一句话梗概：记者林澈在暴雨夜保护证人许岚并用录音笔引开追兵，却从录音中听见三年前已死亡父亲的警告。
本章目标：让林澈保护许岚与录音证据，并确认老周与蓝色制服线索有关。
核心冲突：林澈持有录音笔并保护许岚，老周与雨衣人持续逼近。
情绪走向：从候船厅里的戒备，升级为栈桥追逐，最终落到听见父亲声音的震惊。
结尾钩子：父亲警告不要相信穿蓝色制服的人，而老周雨衣下正是蓝色制服。

### 三、剧本亮点
亮点 1：暴雨、停航屏幕和只剩 6% 电量的录音笔共同形成紧迫的悬疑开场。
亮点 2：林澈把许岚藏进救生设备间，自己拿着录音笔朝相反方向引开追兵。
亮点 3：录音先揭露市长秘书，随后出现林澈已故父亲的声音，并与老周的蓝色制服形成回扣。

### 四、视觉基调
画面氛围：暴雨、封闭、潮湿、追兵逼近的压迫感。
色调方向：深蓝夜雨与录音笔红灯形成对比。
视觉记忆点：红色封条录音笔、老周袖口的蓝漆、雨衣下露出的蓝色制服。

### 五、剧本正文

#### 场景 1：旧港候船厅
地点：旧港候船厅
时间：深夜
氛围：暴雨中的封闭与戒备
出场人物：林澈、老周

剧情描写：
停航通知在电子屏上反复闪烁。记者林澈浑身湿透，手里攥着一只贴有红色封条的录音笔。保安老周正在锁门。

人物动作：
老周不看林澈，只把钥匙插进卷闸门。林澈注意到老周袖口沾着蓝色油漆，与失踪证人短信里提到的“蓝门仓库”颜色相同。他悄悄打开录音笔，屏幕显示剩余电量 6%。

对白：
林澈：“最后一班船真的走了？”

老周：“今晚没有船。你也没来过。”

旁白：
无

场景结束点：
录音笔屏幕显示剩余电量 6%。

#### 场景 2：候船厅后门与栈桥
地点：候船厅后门与栈桥入口
时间：连续
氛围：追兵逼近的紧迫感
出场人物：林澈、老周、许岚、两名雨衣人

剧情描写：
卷闸门落下前，一只女人的手从门外伸进来。林澈用肩膀顶住门，老周却死死按住开关。林澈松开录音笔去抬门，录音笔摔在积水里，红灯仍在闪。女人从门缝滚进来，右臂有擦伤。她叫许岚，是失踪案唯一愿意作证的会计。远处车灯扫过栈桥，两名穿雨衣的人下车靠近。老周低声催促林澈把许岚交出去，称这样三个人都能活。

人物动作：
林澈看向水里的录音笔，又看向几乎站不稳的许岚。他先把许岚推入旁边的救生设备间，再故意捡起录音笔朝相反方向冲上栈桥。

对白：
许岚：“林记者！别让他们拿到录音！”

旁白：
无

场景结束点：
林澈拿着录音笔冲上栈桥，雨衣人转身追去。

#### 场景 3：栈桥尽头
地点：旧港栈桥尽头
时间：连续
氛围：对峙与真相揭露
出场人物：林澈、两名雨衣人、录音中的市长秘书、录音中的林澈父亲、远处的老周

剧情描写：
雨衣人追上林澈。林澈把录音笔举到护栏外，迫使对方停步。林澈按下播放键，杂音后传出市长秘书的声音。录音随后出现第二个声音。林澈愣住——那是三年前已经死亡的父亲。

人物动作：
林澈抬头。老周站在远处，雨衣下露出的正是蓝色制服。

对白：
雨衣人：“你不知道里面是谁的声音。”

市长秘书的录音：“名单在渡轮上，零点前处理干净。”

父亲的录音：“小澈，如果你听见这段话，说明我没能回来。不要相信穿蓝色制服的人。”

旁白：
无

场景结束点：
老周雨衣下的蓝色制服与父亲的警告重合。

### 六、本章结尾
结尾事件：林澈听见父亲留下的警告，并看见老周的蓝色制服。
悬念：老周是否与林澈父亲三年前的死亡有关。
下一章引子：许岚掌握的蓝门仓库线索将把林澈带入旧港仓库区。

# 章节剧本

## 第 2 章：蓝门之后

### 一、基础方向
类型：都市犯罪悬疑
主题：证据落空与时间异常
风格：克制、紧张、旧港夜逃
漫画形式：分页漫画
目标篇幅：完整呈现设备间脱困、寻找蓝门和监控反转

### 二、本章方向
一句话梗概：林澈与许岚逃进蓝门仓库寻找假账，却只看到一段标注为三年前父亲死亡当晚的实时监控画面。
本章目标：让林澈和许岚抵达蓝门仓库并发现新的异常证据。
核心冲突：两人必须躲开老周、赶在录音笔电量耗尽前找到假账，但仓库里的证据与预期完全不同。
情绪走向：从设备间被困的压迫，转为仓库区逃亡，最后落到监控时间异常的惊疑。
结尾钩子：监控画面显示林澈进入候船厅，时间却标注为三年前父亲死亡当晚。

### 三、剧本亮点
亮点 1：门外铁链拖动声迫使林澈和许岚从设备间后窗逃离。
亮点 2：录音笔电量降到 2%，蓝门编号成为唯一可追踪线索。
亮点 3：蓝门之后没有假账，只有仍在运行并标注三年前时间的监控画面。

### 四、视觉基调
画面氛围：潮湿、空旷、被追踪的不安全感。
色调方向：深蓝仓库区、冷白监控屏和录音笔微弱红灯形成对比。
视觉记忆点：设备间后窗、蓝色仓门、成排监控屏上的三年前时间标记。

### 五、剧本正文

#### 场景 1：救生设备间
地点：旧港候船厅旁的救生设备间
时间：凌晨
氛围：暂时藏身但即将被发现
出场人物：林澈、许岚、门外的老周

剧情描写：
许岚用急救布包扎手臂，告诉林澈蓝门仓库保存着渡轮公司的假账。门外传来老周拖动铁链的声音。

人物动作：
林澈和许岚转向设备间后窗，准备离开。

对白：
无

旁白：
无

场景结束点：
门外铁链声逼近，设备间不再安全。

#### 场景 2：旧港仓库区
地点：旧港仓库区
时间：凌晨
氛围：雨夜逃亡与倒计时压力
出场人物：林澈、许岚

剧情描写：
林澈和许岚从设备间后窗逃出，沿父亲录音中提到的编号寻找蓝门。录音笔电量降到 2%。

人物动作：
两人沿仓库编号前进，最终停在蓝色仓门前。

对白：
无

旁白：
无

场景结束点：
林澈和许岚找到蓝门，录音笔电量只剩 2%。

#### 场景 3：蓝门仓库
地点：蓝门仓库内部
时间：凌晨
氛围：预期落空后的异常与惊疑
出场人物：林澈、许岚

剧情描写：
两人打开仓库，里面没有账本，只有一排仍在运行的监控屏。最新画面显示林澈进入候船厅，而拍摄时间标注为三年前父亲死亡当晚。

人物动作：
林澈和许岚停在监控屏前，盯着画面与时间标记。

对白：
无

旁白：
无

场景结束点：
监控画面中的林澈与三年前的时间标记同时停留在屏幕上。

### 六、本章结尾
结尾事件：林澈和许岚没有找到假账，却发现标注三年前时间的异常监控画面。
悬念：林澈为什么会出现在三年前父亲死亡当晚的候船厅画面中。
下一章引子：故事收束在蓝门仓库的时间异常证据上。
