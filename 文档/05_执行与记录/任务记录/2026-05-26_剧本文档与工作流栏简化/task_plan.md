## 1. 目标

项目工作区第 1 步“剧本”继续保持左侧对话框、右侧文档编辑，但右侧只承载剧本正文，不再展示项目名称、故事标题、题材标签、漫画格式、画风方向等字段。

同时将原来的 6 步流程卡片改为更接近参考图的紧凑工具栏样式，减少顶部占用。

## 2. 非目标

- 不接入真实 OpenCode 对话。
- 不实现模型切换。
- 不实现素材、音效、预览等新 Tab 的真实能力。
- 不改数据库和 API 契约。

- [x] 保留保存草稿能力，只提交 `sourceText`。
- [x] 重做 `WorkbenchStageRail` 为紧凑流程工具栏。
- [x] 构建验证。

## 4. 决策

| 决策 | 依据 |
| --- | --- |
| 右侧剧本文档只编辑正文 | 用户明确指出右侧那些字段不要了，文档应只显示剧本内容 |
| 项目元信息暂不在剧本页展示 | 避免剧本页变成表单页，后续可放入项目设置、对话提取或专门元信息面板 |
| 6 步流程改为紧凑工具栏 | 用户参考图更偏轻量顶部导航，当前卡片式流程占空间 |

## 5. 退出标准

- 进入项目工作区后，右侧剧本文档不再显示项目名称、故事标题、题材标签、漫画格式、画风方向输入。
- 剧本正文仍可编辑和保存。
- 顶部流程不再是 6 个大卡片，而是紧凑工具栏。
- 构建通过，有截图或浏览器验收记录。
