# task_plan

## 目标

让对话模型与图片生成模型支持"多模型配置 + 选中即用 + 随时切换"：

1. 对话中可从模型 a 随时切换到模型 b，无需刷新页面。
2. 切换结果可持久化，刷新后保持。
3. 图片生成模型保持/增强"选中哪个用哪个"。

## 非目标

- 不做 OpenCode 原生 provider 管理 UI（添加/删除 provider）。
- 不改变七阶段流程、对话线程、任务协议。
- 不为每条消息强制弹模型选择（默认沿用当前选择）。

## 关键决策（S2 补充，2026-08-05）

1. 对话运行时默认模型 = 模型管理选中的 text 模型（activeTextModelId），无选中时回退 aiKey。
2. 选中模型凭证解析：模型自带 secretRef（文件模式）→ SecretStore；否则复用 aiKey 同 providerId 的凭证；其余走 OpenCode 原生 provider 自带 auth。
3. 对话面板 header 增加模型选择器（列表 = 模型管理 text 模型，与设置页一致），切换即 activate + 更新运行时选择。
4. 图片生成运行时本期不动（用户未确认）。
