## 目标

把无灵感剧本链路从“选灵感后直接写章节”改为：

```text
生成 3 个灵感种子
-> 用户选择一个
-> 生成并保存项目级剧本大纲
-> 对话中展示大纲并等待确认
-> 用户确认后只生成当前一章
```

## 非目标

- 不一次性生成多章。
- 不把剧本大纲写入右侧章节编辑器。
- 不实现完整大纲版本历史。

## 阶段

| 阶段 | 状态 | 退出标准 |
| --- | --- | --- |
| 事实源收口 | 完成 | 文档明确大纲固定格式、保存位置和确认规则 |
| 协议与存储 | 完成 | DTO 和后端支持 `ProjectScriptOutline` 与 `script-outline.md` |
| 对话链路 | 完成 | 选种子生成大纲，确认大纲生成当前章 |
| 前端展示 | 完成 | 灵感按钮改为生成大纲，大纲卡支持确认 |
| 验证 | 完成 | shared/server/web typecheck 通过，workbench 快照带 `scriptOutline` |

## 退出标准

- 用户选择灵感种子不会直接写章节。
- 大纲保存到项目目录。
- 用户确认大纲后才写入当前章节。
- 不满意大纲时可以在确认前提出要求并重新生成。
