# 全项目已实现流程梳理任务计划

## 目标

从用户视角梳理 AI 漫游当前已经实现的端到端流程，并以代码、页面、数据门禁和验收记录交叉确认。

## 非目标

- 不实现新功能。
- 不把纯方案、占位入口或后置阶段写入已完成主流程。
- 不重新设计页面字段或工作流。

## 验收标准

1. 覆盖创建项目、两种剧本来源、逐章生产、角色资产、剧情结构、分镜、出图准备、候选图、排版出版。
2. 每个阶段说明用户动作、正式产物、进入下一步条件。
3. 明确返修后如何失效下游以及不会覆盖哪些历史版本。
4. 未完成内容单独排除，不与当前主流程混淆。
5. 静态事实复核有明确结论；运行复核若不执行，说明原因。

## 阶段

1. [x] 读取项目事实源与当前验收基线。
2. [x] 核对前端导航、页面入口和后端领域服务。
3. [x] 串联用户主路径、双入口与逐章循环。
4. [x] 做一致性复核并输出结果。

## 退出标准

- 文档、代码与验收记录之间不存在未说明的主流程冲突。
- 已完成与未完成边界清楚。
- 会话记录、任务进度和发现已更新。
