# Runtime/User Review：漫画成稿真人体验

## 1. 结论

**FAIL：当前不适合面向普通创作者上线。**

几何编辑、自动保存、智能建议不直接覆盖、成稿预检、Revision、历史恢复、Publication 和只读长图底座成立；文字/气泡编辑会让可见内容变空且 Undo 不能完整恢复，构成用户可见 S0。

## 5. 盲读评价

- 从页首向下可以理解“雨夜警告—诡异末班车—点名—反抗—脱险—再会”的主线。
- 角色图像和雨夜气氛基本统一，中后段连续动作镜头有速度。
- 首段思考气泡为空，读者会直接判断为成稿错误。
- 多处气泡与图片之间的白区偏大，节奏更像自动排版样张而不是成熟条漫。
- 小 caption 在 390px 下接近舒适阅读下限。
- 已出版 Revision 1 是 11 个纯图片段落，不能替代带对白的完整漫画成稿。

## 6. 优先级

### P0

1. 统一画布 selection、属性面板和富文本编辑器的对象身份；切换对象必须重新绑定内容和 runs。
2. 让气泡类型、文字、方向、字体、SFX 和 appearance preset 全部以原子 Shared command 进入 Undo/Redo。
3. 预检增加“可见气泡/文字渲染为空”“编辑器值与 LayoutDocument 值不一致”的 fail-closed。
4. 补真实浏览器回归：气泡改型→改字→竖排→Undo×3；新增文字→输入 SFX→切对象→刷新→手机预览。

### P1

1. `1024～1260px` 保留手机预览和版本出版入口，可折叠进固定溢出菜单。
2. 手机预览弹窗失败时提供同页导航或明确错误反馈。
3. 智能重排只有在所有视觉资源 ready 且完整预览被实际浏览后才解锁应用。
4. 右侧属性应把当前对象属性置顶，画布尺寸和模板折叠。

### P2

1. 收紧段落留白，设置手机 caption 最小字号。
2. 丰富气泡外观和尾巴落点，减少模板感。
3. 统一“出版已完成 / 版面等待完成”等状态文案。
