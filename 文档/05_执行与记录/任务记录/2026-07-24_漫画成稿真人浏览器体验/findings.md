# 发现与决策

## 初始事实

- 漫画成稿技术闭环已通过 Shared、Web、Server 和 DB-only 浏览器自动化。
- 上轮运行素材为 `1×1 PNG`，只能证明接线和正式事实链，不能签收真实美术质量。
- 当前项目已有“杀令入棺”等真实角色、场景和候选图素材，可优先用于本轮人工体验。
- 浏览器操作必须直接使用页面，不使用测试脚本替代真人路径。

## 评分维度

| 维度 | 核心问题 |
| --- | --- |
| 界面体验 | 首屏是否清楚、主画布是否突出、信息密度是否可承受 |
| 交互 | 选择、拖动、调整、撤销、反馈是否符合直觉 |
| 功能完整度 | 是否能从现有素材完成编辑、预览、版本和出版 |
| 美观度 | 编辑器本身与最终漫画是否达到可展示水平 |
| 普通人适配度 | 不懂领域术语的人是否知道下一步、出错后是否会修 |

## 浏览器事实

- 首屏能看懂章节、保存状态、工具、画布和主要动作，深夜蓝黑视觉体系有专业工具感。
- `1280×720` 时中央画布约只有 260px 宽；`1440×900` 仍需在左段落、中央画布、右属性之间分配注意力。
- 对象属性位于固定的画布尺寸和模板之后，找气泡/文字设置通常需要滚动 2～3 屏。
- 画格拖动、裁切、图层显隐/锁定、多选、对齐、Undo/Redo 和自动保存均有清楚反馈。
- `1180px` 宽时隐藏“手机预览”和“版本与出版”，关键闭环没有替代入口；`980px` 只读提示清楚。
- 智能整章重排能在不覆盖当前稿的前提下生成并列候选，但“完整视觉预览”安全门只验证点击展开，不验证图片 ready 或浏览到底。
- 成稿预检能识别并阻断本轮制造的文字/气泡不一致，正式 Revision 和 Publication 没有被坏草稿覆盖。
- 已有正式长图自然尺寸 `1080×21120`，恢复 Revision 后 Working Copy 为 `v102`、11 个 `1080×1920` 段落。

## S0：文字/气泡状态同步与 Undo

复现路径：

1. 选中已有思考气泡。
2. 将类型切换为喊叫。
3. 修改对白内容，再切换为竖排。
4. 画布中的气泡文字变空。
5. 点击 Undo，只恢复横排；气泡类型和文字修改没有进入可恢复历史。
6. 新增文字后，画布选中“输入文字”，富文本面板仍显示上一气泡内容。
7. 输入“轰——”并应用“冲击拟声”，属性面板有内容，画布对象仍为空。

影响：

- 用户操作的是错误或过期的富文本状态。
- 可见内容丢失，且无法靠统一 Undo 自救。
- 手机预览已真实出现空气泡。
- 按验收标尺属于 S0，交互、功能、美观和普通人适配维度均不得高于 4 分。

## S1

1. `1024～1260px` 之间关键出版入口隐藏，普通笔记本或侧栏场景无法闭环。
2. 点击“手机预览”在内置浏览器无新标签、无失败提示；直接访问正确 URL 才能阅读。
3. 智能重排的应用门禁没有证明完整视觉内容已加载或已浏览。
4. 属性面板过长，画布和对象属性上下文频繁丢失。
5. “出版 1 · 已完成”与“版面 v1 · 等待完成”同时出现，状态文案容易看反。

## 美术与阅读

- 优点：真人图片主体裁切总体可辨；雨夜氛围统一；中后段动作镜头连续；390px 下大多数对白可读。
- 问题：首段空气泡；部分段落上方和气泡间留白过大；气泡轮廓较模板化；caption 偏小；正式 Revision/Publication 是纯图片序列，没有冻结富文本草稿的完整叙事。
- 结论：可作为内部排版与出版链路验证样本，不能当面对普通读者的发布金样。
