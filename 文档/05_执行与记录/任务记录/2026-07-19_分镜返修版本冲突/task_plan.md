## 目标

查明并修复已有出图后确认新分镜的真实冲突来源，在不删除旧产物、不误判正确草稿的前提下允许安全返修。

## 非目标

- 不改变剧情结构 group 角色的既有兼容映射规则。
- 不在未设计稳定镜头匹配前自动复用旧候选图。
- 不删除旧分镜、候选图、布局或导出。

## 验收标准

1. 当前 Story ID/digest 与 pending 冻结来源一致时，确认不再误报 `UPSTREAM_SOURCE_STALE`。
2. 真正的 Story 来源已变化时仍必须阻止确认，并给出可理解的处理路径。
3. 已有候选图、布局或导出不会被删除；确认新分镜后旧产物变为历史，出图准备显示“需要更新”。
4. `milestoneStatus` 保持最远里程碑，不因返修倒退。
5. 确认前明确展示受影响产物数量；重新生成本身只创建待确认草稿。

## 推荐决策

| Decision | Rationale |
| --- | --- |
| 允许保存待确认新分镜 | 草稿不改变正式链，用户需要比较和放弃空间 |
| 有旧图时仍允许确认新分镜 | 返修是正常制作行为，不应因已有投入永久锁死上游 |
| 确认使用 pending 自带的冻结 source ID/digest | 这是任务创建时的权威来源，禁止前端从展示 DTO 重算摘要 |
| 新正式分镜生效后通过 Freshness 让下游需更新 | 保留历史且避免旧图冒充新结果 |
| 第一阶段整章失效，按镜复用后置 | 当前每次重生成都换 Shot ID，立即自动复用存在错配风险 |
