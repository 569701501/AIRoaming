## 1. 用途

本目录保存复杂任务的计划、进度、发现、Handoff 和验证证据。

复杂任务必须创建独立目录：

```text
YYYY-MM-DD_<任务短名>/
  task_plan.md
  progress.md
  findings.md
```

## 4. 何时创建任务记录

使用 `$deep-think` 或满足以下任一条件时创建：

- 涉及前后端或多模块。
- 涉及数据库、任务协议、素材路径。
- 需要多阶段实现。
- 需要验收证据。
- 用户明确要求深思熟虑。

普通聊天、小修、被推翻的探索性页面不创建正式任务记录。
