## 1. 目标

创建项目成功后，用户必须直接进入项目工作区第 1 步“剧本”，首屏布局为：

```text
左侧：公共对话框
右侧：剧本文档编辑器
顶部：返回项目列表 + 项目名称 + 6 步流程
```

本任务只对齐项目工作区首屏 UI 和基础交互，不接入真实 OpenCode 对话运行时。

## 5. 已做决策

| Decision | Rationale |
| --- | --- |
| 创建项目成功后直接进入项目工作区第 1 步“剧本” | 用户明确要求，且已写入当前事实源 |
| 项目工作区首屏为左对话框、右剧本文档编辑器 | 用户明确要求，也是当前 UI 信息架构 |
| 当前任务不接真实 OpenCode | 先对齐页面链路和布局，避免运行时接入掩盖 UI 问题 |
| 当前代码的“剧本面板”只能算 `ui_shell` | 还没有左对话框 + 右剧本文档编辑器 |

## 6. 退出标准

- 创建项目成功后，页面自动进入项目工作区第 1 步“剧本”。
- 项目工作区不显示全局左侧导航。
- 首屏明确呈现左侧“对话框”和右侧“剧本文档编辑器”。
- 剧本文档编辑器保留现有保存能力。
- 构建通过，页面经浏览器或截图验收。
