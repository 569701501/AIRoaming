## 已做决策

| Decision | Rationale |
| --- | --- |
| 采用 A+ 简化方案 | 先验证流程和 Prompt 质量，不提前增加正式 ChapterPlan |
| 两条路线在已确认 `ChapterScriptVersion` 汇合 | 下游剧情结构只需要确定的章节正文，不要求上游中间产物相同 |
| 页面展示字段保持不变 | 当前剧本页和剧情结构页已足够用户查看；新增信息留在上游对话、预览或内部项目产物 |
| 先定流程，再定阶段契约，最后写 Prompt | 避免提示词先行导致阶段职责与产物互相覆盖 |
| 拆章目录确认后一次创建全部待确认章节草稿 | 用户可自由切换查看任意章节，但不会因此把草稿直接写成正式章节 |
| 正式化按章确认，不提供整本批量确认 | 只有用户查看并点击该章“确认章节”后，该章才落入正式章节剧本；其他章继续保持草稿 |
| 导入路线 B5 的 V1 草稿只查看和确认 | 暂不提供手动修改或 AI 重新整理；不满意的导入章节保持待确认，后续修改能力另行设计。AI 创作路线仍按 A5 采用为 Working Copy 后编辑 |
| AI 创作完成本章后不提供“继续下一章” | 仅在已确认大纲存在下一章卡时把下一章加入章节下拉框并停留当前章；切换只改变当前章节和对话作用域，用户明确输入“生成当前章节”后，A4 才读取当前章章节卡和上一章已确认正文 |
