## 目标

基于 AI漫游当前已经罗列/实现的功能，重新对照市面上热门 AI 漫画、AI 生图、AI 故事板和视频创作平台，生成一份新的 HTML 报告页面。

## 非目标

- 不修改业务代码。
- 不替换上一版出图准备专项 HTML。
- 不把未经核验的营销说法当成事实。

## 阶段

| 阶段 | 状态 | 说明 |
| --- | --- | --- |
| 1. 事实源读取与任务留痕 | completed | 读取项目文档并建立任务记录 |
| 2. AI漫游功能清单梳理 | completed | 汇总项目库、剧本、剧情结构、角色库、分镜、出图准备、候选图、排版导出、素材包、任务/设置等能力 |
| 3. 市场热门平台调研 | completed | 联网核验热门平台当前能力和定位 |
| 4. 报告 HTML 生成 | completed | 新增可视化报告页面 |
| 5. 自检与记忆更新 | completed | 检查文件、关键词、来源链接、任务记录和长期记忆 |

## 验收标准

- 新增 HTML 报告位于 `文档/04_方案与决策/`。
- 报告必须覆盖 AI漫游完整主链路和关键辅助能力。
- 报告必须包含市场热门平台对照、能力矩阵、差距判断和产品优先级建议。
- 不覆盖已有 HTML 报告。
- 记录调研来源与自检结果。

## 当前深思熟虑角色边界

- Orchestrator：读取事实源、建任务目录、拆阶段。
- Worker：梳理清单、调研、生成报告。
- Scrutiny Review：检查报告是否回答用户新要求、是否引用来源、是否未覆盖旧文件。
- Runtime/User Review：本任务为静态 HTML 报告，不需要启动应用；用户可打开 HTML 做人工体验复核。
