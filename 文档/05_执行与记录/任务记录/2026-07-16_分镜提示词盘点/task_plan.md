# 分镜及后续提示词盘点任务计划

## 目标

在不改变当前页面字段和已确认上游流程的前提下，找齐分镜及后续阶段已有 Prompt / Skill 文档与生产实现，明确哪些结论仍有效，并确定下一阶段的合理施工顺序。

## 非目标

- 本轮不直接重写分镜 Prompt。
- 不新增页面字段、数据库字段、确认节点或公开 Skill。
- 不延伸到 G6 素材包或视频阶段。
- 不把旧设计文档未经核验直接当作当前事实源。

## 阶段

| 阶段 | 角色 | 状态 | 退出标准 |
| --- | --- | --- | --- |
| 文档与代码盘点 | Orchestrator | completed | 已找齐事实源、方案、实现和测试入口 |
| 契约一致性核对 | Worker | completed | 输入、输出、页面字段、触发和确认门已核清 |
| 下一步排序 | Worker | completed | 已确定分镜 S1-S3、场景参考图 S4、候选图 S5 |
| 静态复核 | Scrutiny Review | completed | 结论均有代码或文档证据，已标记历史文档的过期部分 |

## 验收标准

1. 明确当前分镜生成真实读取什么、输出什么、在哪里确认。
2. 明确已有文档中哪些是当前事实源、哪些是历史实现记录。
3. 明确分镜之后“出图准备、候选图”的 Prompt 边界。
4. 给出一个用户可逐阶段确认的下一步顺序。

## 退出标准

形成一份可直接用于下一轮“分镜 Prompt 详细设计”的盘点结论，并同步会话与长期记忆。

## 最终结果

- 正式结论见 `文档/04_方案与决策/2026-07-16_分镜及后续提示词改造顺序.md`。
- 下一项正式任务为 S1：分镜生成契约与引用映射。
- 当前页面展示字段和分镜确认流程保持不变。
