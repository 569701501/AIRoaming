# 漫画成稿「简单调整」定位设计

## 1. 定位确认（用户 2026-08-03 明确）

- 目标用户：**普通用户**（非专业漫画家）。
- 核心流程：AI 自动排版 → 用户查看效果 → 不满意做**简单调整** → 导出。
- 简单调整范围（用户原话归纳）：
  1. 气泡挡住图片关键部位 → 挪位置；
  2. 对白内容修改；
  3. 字体大小、颜色修改；
  4. 拖拽元素位置。
- AI 排版硬要求：**每个镜头对白必须准确**（不遗漏、不错绑、不改写、不遮挡关键部位）。

## 2. 与现状的差距分析

### 2.1 保留（核心体验，已是产品级）

| 能力 | 说明 |
| --- | --- |
| 首次自动排版 `layout_compose` | 唯一 AI 入口，无参数、无模式选择 |
| 拖拽实时预览 + 松手提交 | 拖拽全程 DOM 跟随，吸附参考线 |
| 双击就地改字（text/balloon） | 普通用户最直觉的改字入口 |
| Delete + 确认删除 | 含画格内镜头"回到未放置"提示 |
| 有限本地撤销（50 步，无 redo） | 满足"改错了能退" |
| 导出预检 + 文字差异确认 | blocked / review 两段，系统错误不能强行导出 |
| 对白 binding + tombstone + 双 preflight | 对白准确性的数据保障 |

### 2.2 需要上浮到「选中工具条」的常用动作

- 字号 + / 字号 -
- 文字颜色（简单色板）
- 粗体开关
- 删除、复制
- 撤销

目标：**90% 的调整不打开任何面板**。文字类元素选中即出现这组动作；图片/画格选中给出位置相关动作。

### 2.3 应隐藏/移除的专业遗留（收进「更多/高级」或直接退役）

| 能力 | 处置建议 | 理由 |
| --- | --- | --- |
| 裁切工具手势（crop tool） | 隐藏 | 普通用户不裁图；图片放错位置靠拖动，不靠裁切 |
| 气泡尾巴 5 字段（rootRatio/targetX/targetY/baseWidth） | 保留「尾巴开关」，数值隐藏 | 只拖尾巴端点，不填数字 |
| 精确几何 X/Y/宽/高/旋转/透明 | 隐藏 | 数字输入不是普通用户语言 |
| 富文本混排（段内加粗/变色/多段样式） | 保留简单改字，混排收高级 | 就地编辑按首段样式重建已兼容 |
| 阅读顺序编辑 | 隐藏 | 自动排版已生成，普通用户不手调 |
| 画格模板抽屉 | 隐藏 | 自动排版产物为准 |
| 图层 Tab | 隐藏 | 普通用户无图层概念 |
| SFX 预设、文字 semantic | 隐藏 | 专业术语 |
| 来源替换条（换图条） | 收「更多」 | 偶尔换镜头，不作为主交互 |
| 画布尺寸/段高设置抽屉 | 保留但默认收起 | 首次自动排版已按版式生成 |

## 3. 自动排版对白准确性（第一优先级不变量）

- 现有保障：formal dialogue binding 一对一、tombstone 不复活、导出 preflight 硬阻断（DIALOGUE_* 系列 issue）、文字差异原文 vs 当前确认。
- 缺口：
  1. **遮挡**：无 visual analysis（fallback/未配置）时，气泡可能压住人脸/主体/关键物品——MEMORY 2026-07-23 记录真实项目 19 气泡 7 个与画格相交。需硬门：无视觉证据时对白/旁白主体外置或侧挂文字带；有证据时 face/body/focal protected 重叠拒绝候选。
  2. **准确性的用户可感知验证**：导出前把「每镜头对白是否就位」以普通用户能懂的方式呈现（如逐镜头对白核对卡），而非内部 issue code。
- 建议落地：自动排版完成后，若存在遮挡风险，在画布顶部横幅提示"本稿部分对白可能遮挡画面，可拖动调整"，并把有风险的气泡轻微高亮。

## 4. 后续设计任务（候选，待用户排期）

1. **选中工具条扩充**：文字/气泡元素加字号、颜色、粗体；目标是零面板完成 90% 调整。
2. **专业能力收纳**：按 2.3 表逐项隐藏/退役，契约测试与 e2e 同步（testid 迁移策略沿用 07-30 教训：保留 testid 但挪位置，减少断言改动）。
3. **遮挡硬门**：自动排版端，无视觉证据时禁止对白主体进入画格；有证据时 protected 重叠拒绝（对接 MEMORY 07-23 已知缺口）。
4. **对白核对卡**：导出前或成稿页提供逐镜头对白就位核对，普通用户可读懂。
5. **用户修改回流（远期）**：项目级「排版偏好账本」记录 override 统计，下次自动排版优先尊重（见 design_review.md §6.2）。

## 5. 与现有 ADR 的关系

- 本定位是对 ADR-0022「基础编辑」的进一步收缩：**明确普通用户只做四种简单调整，专业能力退场**。
- 若按 2.3 全量执行，需新增 ADR（或修订 ADR-0023）记录「专业能力收纳」范围与退役清单。
- 自动排版「首次一次、AI 不二次介入」口径不变。
