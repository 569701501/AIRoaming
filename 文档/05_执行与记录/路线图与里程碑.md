## 1. 当前阶段

当前处于 M1：章节剧本到分镜阶段。项目库优先、项目工作区和 7 步主流程已经成为当前产品口径；代码仍有部分旧 6 步 workflow 需要迁移。

## 2. 阶段总览

| 阶段 | 名称 | 状态 | 核心交付 |
| --- | --- | --- | --- |
| M0 | 文档与契约成型 | completed | 文档体系、产品范围、架构、数据模型、任务协议 |
| M0.1 | 产品页面链路收口 | completed | 核心用户流程、功能清单、当前 UI 信息架构、AI 入口同步 |

## 5. M1 章节剧本到分镜

### 目标

用户能从当前章节剧本得到可编辑分镜。

### 建议任务

- [x] 初始化应用工程。
- [ ] 建立 Project/Chapter/Character/StoryVersion/Shot 数据模型。
- [x] 建立项目 workflow 契约和基础流程状态；需要从旧 6 步迁移到包含 `project_characters` 的 7 步流程。
- [x] 实现项目创建。
- [x] 实现项目级过渡故事输入和保存。
- [x] 实现章节列表和当前章节保存。
- [x] 实现完成本章并创建下一章草稿；需要按新口径补齐 `进入项目角色库` / `继续下一章` 后续选择。
- [ ] 实现项目角色库数据、角色定稿图确认和剧情结构前置门槛。
- [x] 实现 `story_parse` 任务占位或真实调用。
- [ ] 实现结构化剧情查看和编辑。
- [ ] 实现 `shot_generate` 任务占位或真实调用。
- [ ] 实现分镜列表和分镜详情编辑。

### 验收

- [ ] 输入当前章节剧本后能保存为 `ChapterScriptVersion` 或等价章节草稿。
- [ ] 能生成结构化剧情 JSON。
- [ ] 能生成至少 8 条分镜。
- [ ] 分镜字段可编辑并保存。
- [ ] 功能完成记录已写。

## 6. M2 分镜到漫画图候选

### 目标

用户能为分镜生成多个漫画图候选并锁定结果。

### 建议任务

- [ ] 建立 SceneLocation 模型，并让候选图读取已确认项目角色库。
- [ ] 建立 Asset/Candidate/GenerationTask 模型。
- [ ] 实现场景模板编辑和角色参考图注入。
- [ ] 实现分镜提示词生成。
- [ ] 实现图片生成任务。
- [ ] 实现候选图列表。
- [ ] 实现选择、锁定、废弃和重生成。

### 验收

- [ ] 每个分镜能生成多个候选。
- [ ] 候选能追溯到任务输入。
- [ ] 一个分镜只能锁定一个候选。
- [ ] 锁定状态能被排版模块读取。
