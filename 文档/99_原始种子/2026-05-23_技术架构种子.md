> 该文档保留项目最初的技术架构种子。当前有效技术事实源见 `文档/02_架构与契约/`。

## 1. 架构概览
**前端**：
- 技术栈：Vue 3 + Pinia + Tailwind CSS + shadcn/reka-ui
- 负责 UI 工作台、素材面板、分镜/漫画/轻漫剧预览
- 可选桌面端：Electron/Tauri 打包

**后端**：
- 技术栈：Node.js + NestJS + Prisma + SQLite/PostgreSQL
- 负责 API 接口、任务调度、数据持久化
- 任务队列可用 BullMQ 或本地异步队列

**AI 生成任务**：
- 分镜生成、漫画图生成、视频序列生成
- 可调用云端 API 或本地模型
- 支持多候选、失败重试、异步任务

**素材管理**：
- 文件路径统一：/workspace/**
- 支持版本管理、多候选管理和导出归档

**视频与音频处理**：
- 视频：FFmpeg 或本地序列帧合成
- TTS/BGM：ElevenLabs 或本地 TTS

## 2. 模块划分
| 层级 | 模块 | 职责 |
| --- | --- | --- |
| 前端 | 页面组件 | 分镜工作台、漫画图生成界面、轻漫剧预览、素材管理 |
| 前端 | 状态管理 | 管理项目、分镜、角色、场景、生成任务状态 |
| 后端 | API 接口 | 提供 REST/GraphQL API，处理前端请求 |
| 后端 | 任务队列 | 异步执行分镜生成、漫画图生成、视频生成 |
| 后端 | 数据库 | 存储项目、角色、场景、分镜、素材、版本信息 |
| AI 层 | 生成模块 | 图片生成、视频序列生成、TTS/BGM合成 |
| 文件系统 | 素材路径 | 统一管理素材，保证任务输出与前端显示一致 |

## 3. 技术设计原则
- **模块化**：前后端、任务队列、生成模块独立，可单独迭代
- **异步任务**：所有生成任务支持队列、重试、多候选
- **统一路径与契约**：所有素材文件、数据库字段、API 都有明确约束
- **可扩展性**：可支持未来多人协作、云端扩容或桌面端部署
- **MVP 优先**：核心功能先行，复杂视频生成、多人协作、商业化功能后续扩展
