## 1. 项目概述
- **项目名称**：AI漫游
- **目标**：内部工具，快速将故事创意转化为分镜、漫画图和轻漫剧素材
- **用户群体**：创意团队、漫画作者、轻漫剧制作组
- **核心原则**：
  - 流程自动化 + 人工可控
  - 生成素材可复用
  - 支持多版本、多候选输出

## 2. 核心功能模块
| 模块 | 描述 | 输入 | 输出 | 优先级 |
| --- | --- | --- | --- | --- |
| 故事输入与整理 | 将文本剧情整理成结构化信息 | 剧本文字 | JSON 剧情结构 | P0 |
| 分镜生成 | 根据剧情生成镜头信息 | JSON 剧情结构 | 分镜数组 JSON | P0 |
| 漫画图生成 | 按分镜和角色模板生成漫画图候选 | 分镜 + 角色模板 + 风格 | 候选图片数组 | P0 |
| 漫画排版 | 将候选漫画图排版成完整漫画页面 | 漫画图 + 分镜 | PNG / PDF 漫画页面 | P0.5 |
| 轻漫剧生成 | 将漫画图序列合成基础视频 | 漫画图序列 + TTS + BGM | MP4 视频 | P0.5 |
| 素材管理与导出 | 管理生成的漫画、视频和音频素材 | 漫画图、视频、音频 | 素材包 | P0 |

## 3. 核心流程
```
故事输入 -> 剧情整理 -> 分镜生成 -> 候选漫画图生成 -> 候选图选择
-> 漫画排版 -> 漫画导出 -> 轻漫剧生成 -> TTS/字幕/BGM -> MP4导出 -> 素材包归档
```

## 4. 异步任务
- 每个生成模块可作为独立异步任务
- 支持多候选、多版本
- 前端实时接收生成进度

## 5. 数据模型示例
- **Project**：{id, name, version, status}
- **Character**：{id, name, appearance, templateId}
- **Scene**：{id, name, backgroundImage}
- **Shot (分镜)**：{id, shotNumber, characters, scene, action, camera}

## 6. MVP 功能
- 分镜生成 + 人工编辑
- 漫画图生成 + 候选图选择
- 漫画排版导出（PNG/PDF）
- 轻漫剧基础 MP4 导出 + TTS/字幕
- 素材管理与归档
