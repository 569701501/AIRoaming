# G5 成稿编辑器与确定性导出验收清单

## 1. 状态

本清单已随 G5 方案获用户确认，但所有功能项均未执行、未通过。`accepted` 只代表接受实施方案，不代表以下 checkbox 可以勾选。

## 2. 验收原则

- 使用临时 SQLite、临时 workspace、固定本地图片/字体 fixture；禁止改真实用户项目。
- 测试不调用真实模型、网络字体或外部图片 URL，不需要任何 provider key。
- 同一 LayoutDocument 必须贯穿 Shared、Web preview、Server renderer 和 manifest；不得为测试准备另一套“简化导出 JSON”。
- 旧“复制候选原图”必须作为错误语义被替换，不能通过降低断言继续冒充 PNG 合成。
- golden 更新必须说明 renderer/font/policy 变化并人工查看 diff；禁止无条件 overwrite snapshot。
- 任何未执行验证在 Handoff 中写明，不得口头推断通过。

## 24. 真实用户路径复核

Runtime/User Reviewer 必须亲自完成并记录截图/产物：

### 路径 A：分页漫画

```text
进入已有 layout step
→ 选择默认竖页
→ 自动四格
→ 调整画格/裁切/图层
→ 添加横排气泡和竖排拟声字
→ autosave/reload
→ 保存版本
→ 预检
→ 导出 PNG+PDF
→ 打开所有文件并核对 manifest
```

### 路径 B：竖向条漫

```text
初始化 1080 宽
→ 20 段连续编辑/重排/改高
→ 手机预览/切片线
→ 保存版本
→ 导出 slices + 条件长图
→ 顺序拼回像素验证
```

### 路径 C：返修

```text
A 已有 Revision/Publication
→ 候选阶段 replace B
→ 旧成品历史仍可开
→ 画布显示 stale
→ 单张 preserve crop + 批量 reset crop 预览
→ source 再变化导致旧 preview 失效
→ 重做并 commit
→ 新 Revision/Publication current
```

### 路径 D：故障

```text
编辑中多标签冲突
→ 下载 recovery
→ 明确选择版本
→ 导出中重启 Server/worker
→ task 恢复或安全失败
→ 旧 worker 迟到不切 current
```

### 路径 E：手机和 AI

```text
手机打开已保存草稿/版本
→ 无写请求
→ 桌面打开 AI drawer
→ 建议 preview/discard
→ 新建议 apply/Undo
→ AI 无法保存版本或导出
```
