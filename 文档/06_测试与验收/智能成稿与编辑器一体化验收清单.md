# 智能成稿与编辑器一体化验收清单

## 1. 验收目标与范围

本清单要证明：用户在所有镜头已有当前定稿图的前提下，不配置排版参数即可得到包含画格、裁切、对白、气泡、旁白和阅读顺序的完整可编辑成稿；用户后续手调和局部智能优化互不破坏，最终仍通过现有确定性 renderer 生成真实 publication。

范围内：

- LayoutDocumentV2 与 V1 兼容。
- 智能成稿规则模式、完整视觉分析模式、多候选评分与自动修复。
- 首次 `layout_compose`、整章/局部预览、人工保护和统一编辑工作台。
- 阅读预览、来源更新和一次预览并导出。

范围外：

- 绘画、滤镜、inpaint、复杂印刷、多尾气泡、任意画格、G6 ZIP。

### 4.7 M6 视觉分析与局部智能调整状态（2026-07-23）

- OpenCode 结构化运行时支持受限图片附件；视觉分析服务会复核 DB ready Asset、storageKey、真实路径、字节数、SHA-256、尺寸和 MIME，再缩放为最大边 1536px 的 JPEG。
- Provider 只能返回主体/脸部、关键区域、文字安全区和视觉中心。角色映射、Asset 身份、稳定 subject ID、warning 与 analysis digest 由本地 adapter 权威补齐；原始响应、密钥、路径和图片字节不进入任务输出。
- 每个 Shot 可独立使用 `vision` 或回退；非法角色映射、结构失败、超时/失败和无配置均不阻断完整成稿。与 `assetId + assetDigest` 完全一致的历史 vision 分析可安全复用。
- page/strip canvas、选中 element、scene shot scope 均有稳定扩展规则；局部命令只允许 geometry/crop/balloon style/tail，保护或锁定字段逐项跳过。
- 同一工作台开放“智能调整”，默认选中对象，否则当前页/段；可切当前场景和四种调整意图。所有结果先显示当前/新排法，放弃不改稿，应用进入一次 Undo。
- 选中对象存在人工 protection 时显示“允许智能再次调整”；只清除该对象和嵌套画格图片的 protection，不解除显式锁定。
- 验证：Shared 36 files/218 tests、Server 129 files/763 tests、类型检查、Server/Web production build 全部通过；数据库集成包含 scoped Pending/apply，条漫/页漫浏览器路径 2/2 通过。
- 本轮使用本地假结构化服务验证 provider 附件与严格输出，没有发起付费外部视觉调用。具体模型对真实漫画的审美和气泡改进质量仍为独立 `not_run`，不能由接线测试替代。

## 13. 视觉质量统计方法

每个固定样例分别对自动生成画格和自动绑定气泡记录：

| 字段 | 值 |
| --- | --- |
| `layout_ok` | 无需调整画格位置/尺寸 |
| `crop_ok` | 无需调整裁切 |
| `balloon_geometry_ok` | 无需移动/缩放气泡 |
| `balloon_type_ok` | 气泡类型正确 |
| `reading_order_ok` | 阅读顺序正确 |
| `subject_occlusion_ok` | 无关键人脸/动作遮挡 |
| `text_fit_ok` | 无溢出且字号可读 |
| `source_fidelity_ok` | 对白/旁白不遗漏、不改写、不重复 |
| `tail_ok` | 尾巴开关、目标人物、路径与相邻对象无需调整 |
| `shape_safe_ok` | 文字位于对应气泡形状的安全内区 |
| `page_reading_order` | 不看工程编号也能自然读完整页/整段 |
| `page_rhythm` | 停顿、推进、爆发和留白符合剧情 |

普通读者视觉研究统一遵循 [漫画成稿普通读者视觉验收标准](./漫画成稿普通读者视觉验收标准.md)，标准编号为 `AIR-QA-COMIC-FINAL-001-v1`。画格、自动绑定气泡、完整页/段按普通和困难样例分别统计：普通样例目标直接可用率均为 ≥90%，困难样例均为 ≥80%；内容、裁切、阅读顺序、主体遮挡、文字可读性、原文一致性和说话者/尾巴等严重可见错误目标为 0。2026-07-23 用户实际复核认为重复草图无法支撑可靠的专业节奏评分，并授权在保留“部分气泡外观不够自然”的已知问题下继续正式接线。因此 A/B 保留为可选内部研究，不再阻塞 M4；若实际开展，仍必须由两位不同真人独立完成并运行 `pnpm smart-layout:m3:review:validate`，不得把空表或自动结果写成真人通过。旧版合成测量图 HTML/CSV 只保留为工程几何证据。
