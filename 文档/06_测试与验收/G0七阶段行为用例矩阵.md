# G0 七阶段行为用例矩阵

## 1. 使用方式

本矩阵是 G0 以及后续能力切片的测试索引，不是要求在 G0 一次写完所有测试。当前开发波次只启用到 G5；G6/G7 用例保留为后置长期索引。

| 标记 | 执行规则 |
| --- | --- |
| `green_now` | G0 按垂直切片实现，进入默认测试 |
| `migration_witness` | G0 临时锁旧系统的重启/读取语义；G1 有等价 DB 测试后替换 |
| `covered` | 已有测试覆盖，不重复写同义用例 |
| `record_only` | 当前已知错误，只留证据，不断言错误现状 |
| `red_on_slice:Gx` | 到 Gx 开始时写成 red 测试，然后最小实现到 green |
| `manual:G7` | 真实供应商或真实成品人工/受控验收，不进普通 CI |

所有自动化用例必须满足：

- 使用原创 fixture。
- 使用临时 workspace。
- 不读取真实 provider key。
- 断言公开输出、状态、文件或错误，不断言私有实现调用次数。
- 用稳定关系断言随机 ID 和时间，不 snapshot 整个易漂移对象。

用途：验证 preflight 阻塞。

## 14. G0 每条测试的断言模板

### 14.1 状态推进

```text
Given：公开 API 建立的 current 上游
When：用户完成/确认/锁定动作
Then：
  - 返回的章节状态正确
  - workflow.currentStepKey 正确
  - 前序 step=done，当前 step=active，后序 step=waiting
  - current 事实存在且来源关系正确
  - 未确认/pending 不被当成 current
```

### 14.2 门禁失败

```text
Given：缺少一个明确前置
When：调用下游写动作
Then：
  - 返回非成功和稳定业务错误码
  - 章节状态不变
  - current 指针不变
  - 正式对象/Asset/文件数量不增加
```

### 14.3 重启 witness

```text
Given：通过公开 Service 完成 checkpoint
When：关闭 Nest context，并在相同临时根新建 context
Then：
  - 公开 WorkbenchSnapshot 的语义字段一致
  - 不比较 volatile 时间和绝对路径
  - 当前旧文件存在只作为迁移证据
  - G1 后用 DB-only 等价用例接替
```
