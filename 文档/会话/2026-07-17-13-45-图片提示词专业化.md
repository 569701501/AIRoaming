# web_search

- 初步来源包括 OpenAI 官方图像生成指南、xAI 官方图像文档、火山引擎 Seedream 官方提示词指南、Midjourney 官方 Character/Omni Reference 文档、StoryDiffusion 官方仓库与论文项目页、ComfyUI 官方 Area Composition 示例。
- 初步共同结论：专业图像生成不是堆砌“神词”，而是明确主体、动作、环境、构图、光色、参考图角色、必须保持项和禁止项；多人物一致性与位置控制还依赖参考图分工、区域/布局控制及能力边界，不能只靠长 Prompt。
- 重要链接：
  - https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide
  - https://developers.openai.com/api/docs/guides/image-generation
  - https://www.volcengine.com/docs/82379/1829186
  - https://docs.x.ai/developers/model-capabilities/images/generation
  - https://docs.midjourney.com/hc/en-us/articles/32162917505293-Character-Reference
  - https://github.com/HVision-NKU/StoryDiffusion
  - https://comfyanonymous.github.io/ComfyUI_examples/area_composition/
- 已完成来源扩展与代码级核对：
  - https://github.com/tencent-ailab/IP-Adapter
  - https://github.com/instantX-research/InstantID
  - https://github.com/jbilcke-hf/ai-comic-factory
- 完整调研结论：没有可直接导入的万能漫画 Prompt；应采用稳定内容顺序、逐图职责、保持/允许变化、按人数拆镜头合同、Provider 分别编译和固定连续性评测。
- 参数边界：Doubao 水印、目标比例、Grok 三图上限和单图编辑策略不能靠 Prompt 文案替代。

# approach

- 漫画静态图与漫剧关键帧/视频提示词分开设计。
- 保持现有页面展示字段不变，通过内部 Prompt 编译层吸收专业方法。
- 不直接复制某一套网上 Prompt；提取可验证的方法，并按 OpenAI、Doubao、Grok 分别适配。
- 待重写范围分为：角色预览、角色定稿、场景参考、漫画单格共享合同、五类漫画镜头模块、参考图角色清单、三个 Provider Profile；漫剧关键帧/视频作为独立 Prompt 包，不与漫画静态图混用。
- R2 已结束，正式依据为 `文档/04_方案与决策/2026-07-17_图片Prompt专业化调研与V2设计依据.md`。下一阶段只编写 V2 和离线样例，不调用付费图片服务。
- R3 已完成：默认参考图模板升级 V2，候选图新增按人物数量与动作关系的镜头合同，三家 Provider 使用不同 V2 编译，V1 保留作 A/B。Doubao 关闭水印并保持 3:2 / 2:3 候选尺寸；Grok 单参考图降级仍是显式残留风险。
- V2 正式说明：`文档/04_方案与决策/2026-07-17_图片Prompt专业V2模板与编译规则.md`。
- 离线结果：定向 28/28、DB/候选集成 40/40、Server 全量 120 files / 720 tests，Shared build、Server typecheck/build 全部通过；未调用付费图片服务。
