# finding

- 用户希望参考 AuroraPlatformWeb，在 AI漫游项目内建立 `opencodeAI` 体系，后续每个流程都能逐步添加对应 agent、skill 和 tool。
- AuroraPlatformWeb 的源码事实源位于 `apps/server/opencodeAI`，包含 `agents/*.md`、`skills/**/SKILL.md`、`tools/*.js`、`AGENTS.md.tpl` 和 `opencode.json`。
- Aurora 的 agent 文件负责角色、模式、权限和可用 skill 列表；skill 文件用 frontmatter 描述名称和触发场景，正文写阶段能力边界；tool 文件通过 `@opencode-ai/plugin` 转发到后端受控回调。
- AI漫游已有文档结论：OpenCode 只作为对话运行时，不能直接写本地项目文件；剧本阶段需要独立 agent/skill；用户提供剧本整理需要导入前分析/校验。
- AIRoaming 当前还没有 `apps/server/opencodeAI` 源码资产目录，`OpenCodeRuntimeService` 也尚未从项目内模板同步 agents/skills/tools。
