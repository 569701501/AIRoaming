# web_search

2026-07-09 追加搜索 GitHub / 开源提示词实践，主题为“漫画平台哪些提示词可以借鉴外部热门 prompt”。

关键结论：

- 生图类提示词最值得借鉴外部结构：候选图、角色参考图、场景参考图可吸收 Stable Diffusion / ComfyUI / Fooocus 风格 preset 的 prompt + negative_prompt 组织方式。
- 角色一致性提示词可借鉴 character reference sheet / turnaround sheet：正面、侧面、背面、服装细节、色板、白底、同一角色一致性。
- 剧情结构、灵感、大纲、章节写作和分镜只能借鉴方法论，如 Story Spine、Hero's Journey、因果推进、场景目的、镜头语言；不能照搬外部模板。
- 项目事实源、工具调用、阶段边界、写入协议不宜借鉴外部内容，只能参考提示词工程和评测方法。

参考来源：

- `f/prompts.chat`：通用 prompt 集合，适合观察角色设定和输出口径组织方式。
- `dair-ai/Prompt-Engineering-Guide`：提示词工程方法。
- `FurkanGozukara/Stable-Diffusion`、`Chan-0312/ComfyUI-Prompt-Preview`：生图 prompt、style preset 和 negative prompt 组织方式。
- `JGonzalez249/automatic-comic-book`：漫画生图中角色一致性依赖可识别特征和负面提示词。
- `new-sankaku/manga-editor-desu`：漫画制作工具流程参考。
- `jackterror/writers-room-story-engine`、`yingpengma/Awesome-Story-Generation`：故事结构和写作方法论参考。
- `promptfoo/promptfoo`：提示词回归测试、模型对比和红队测试。
