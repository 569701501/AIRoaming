# goal

# approach

- 使用 `$deep-think` 建立正式任务目录并逐阶段施工。
- 先建立固定夹具和 Prompt 部件，再改角色/场景/候选图，最后回推分镜。
- Prompt 领域规格保持 provider-neutral；真正发送给 provider 的字符串通过显式 profile 编译。
- 不整段复制外部 Prompt，不使用第三方 IP/艺术家名作为默认模板。
