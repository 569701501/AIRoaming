# finding

- `apps/server/opencodeAI/skills/` 当前只有 5 个剧本 Skill，没有分镜或图片 Skill。
- 分镜和图片生产 Prompt 当前分别散落在 `dialogue-prompt.util.ts`、`reference-prompt.util.ts`、`candidate-generation-spec.ts` 与 `image-prompt-profile.util.ts`。
- `OpenCodeRuntimeService` 启动 OpenCode 时没有把 `apps/server/opencodeAI` 配置为运行目录，也没有复制或显式加载其中的 Skill；现有剧本 Skill 与后端动态 Prompt 同样存在重复事实源。
- 旧方案曾以“Skill 资产尚未接入生产运行时”为由，暂时把生产 Prompt 放在服务端；该临时实现不符合用户要求的长期提示词事实源边界。

# goal

明确分镜和生成图片提示词的正确归属，纠正为 `apps/server/opencodeAI/skills/` 下的可运行 Skill 事实源，并避免只移动文件却导致生产运行失效。

# approach

- Skill 保存稳定的角色、方法、输入输出、禁止事项和质量契约。
- 后端只负责注入项目动态上下文、调用运行时、校验输出、版本写入及图片 provider 适配。
- 迁移必须同时完成 Skill 资产与运行时加载接线，不能保留后端和 Skill 两份可编辑 Prompt。
