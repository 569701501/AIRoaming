# approach

- 在 Shared 内使用无 Node 依赖的纯 TypeScript SHA-256 和 RFC 8785 风格 canonical JSON。
- Codec 接受 JSON 文本或未知对象，文本使用重复键检测 parser；对象路径使用 exact-key validator。
- Freshness Resolver 只依赖显式输入结构，不读取 Prisma、文件系统或时间（`generatedAt` 由调用者传入）。
