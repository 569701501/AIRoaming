# finding

- 用户指出“清除剧本”不应清除所有剧本，而应只作用于当前打开章节。
- 当前代码与文档中的 `清空剧本 / resetProjectScript` 是项目级语义：`POST /api/projects/{projectId}/script/reset` 会删除整个 `chapters/` 目录，并重建空白 `chapter-001`。
- 剧本页按钮当前文案为“清空剧本”，确认弹窗明确写着“删除当前项目下所有章节草稿”，前端调用 `workbench.resetProjectScript()`。
- 章节模型已明确 `Chapter` 是项目内一等工作单元；剧本编辑器读取 `WorkbenchSnapshot.currentChapter`，因此编辑器里的“清空”应默认作用于当前打开章节。
- 若当前章节已经完成，清空正文后仍保持 `script_done` 会造成空正文仍可进入剧情结构；合理行为是将该章节退回 `draft`，解除当前剧本版本和结构化版本引用。

# web_search

# goal

把剧本编辑器的清空动作从“清空项目剧本/删除所有章节”改为“清空当前打开章节正文”。其他章节必须保留，当前章节保留标题、顺序和章节身份。

# approach

- 文档先收口术语：用户可见按钮语义是“清空当前章节”，项目级整本重置只作为后端维护/整本替换能力，不再由编辑器按钮触发。
- 新增章节级清空 API：按 `projectId + chapterId` 清空当前章节 `sourceText`。
- 清空当前章节时：保留章节 ID、标题、顺序和其他章节；清空 `sourceText/summary/lastScriptRevision`，将 `status` 退回 `draft`，清掉 `currentScriptVersionId/currentStoryVersionId/completedAt`。
- 前端按钮、确认弹窗、store 和 API 调用全部改为章节级清空，并继续复用章节级局部合并。

# result

已将剧本编辑器清空动作改为章节级“清空本章”。新增 `POST /api/projects/{projectId}/chapters/{chapterId}/script/clear` 和 `ClearChapterScriptResponse`；后端只清空目标章节正文，保留其他章节，并将目标章节退回 `draft`、清除当前版本/结构引用、删除该章节 `script.versions/` 与 `script.revisions/`。前端按钮文案和确认弹窗已改为“清空当前章节”，store 调用章节级 API 并继续局部合并结果。

项目级 `POST /api/projects/{projectId}/script/reset` 保留为整本替换或错误导入维护能力，不再作为编辑器普通按钮。

验证通过：`corepack pnpm --filter @airoaming/shared build`、`corepack pnpm --filter @airoaming/shared typecheck`、`corepack pnpm --filter @airoaming/server typecheck`、`corepack pnpm --filter @airoaming/web typecheck`、`corepack pnpm --filter @airoaming/server build`、`corepack pnpm --filter @airoaming/web build`、`git diff --check`。另用临时 workspace 服务级脚本验证：清空第 2 章后，第 1 章保留，章节总数不变，第 2 章正文为空且状态退回 `draft`。
