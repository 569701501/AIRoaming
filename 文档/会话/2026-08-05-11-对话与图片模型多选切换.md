# 会话记忆：对话与图片模型多选切换

## finding

- 对话模型契约已支持逐消息指定 model（SendDialogueMessageRequest.model、DialogueMessageItem.model）。
- 前端 workbench-store.selectedDialogueModel 只在 loadRuntimeModels()（启动）时取一次 default，之后无 UI 可改 → 这是"换不了模型"的根因。
- GET /api/ai-runtime/models 已返回全量已注册模型（items+defaultModel），可直接复用做选择器。
- 设置页原「AI 密钥」是单一对话槽位；图片生成已是 4 槽位 + activeImageProvider 切换。
- updateAIKeySettings 中 providerChanged 且未传 apiKey 会自动清 key（settings.service.ts），跨 provider 切换需注意。
- 切 provider（带 baseUrl）会触发 OpenCode serve 重启（ensureConfiguredProvider），有数秒延迟。
- G1 credential_metadata trigger：owner 白名单 text→opencode、image→image_secret_store/environment；凭证轮换/清除/删除需 Outbox 或不可变约束。
- DB 模式 providerConfig 行按 providerId 唯一；managed model 在 DB 模式 id 稳定为 model_<providerId>，文件模式用 uuid。
- 全量 pnpm test 并行时偶发集成测试资源竞争失败（cutover/document-library/backup），单独复跑全过，与具体改动无关。

对话模型/图片生成模型多选与随时切换：选中即用、切换持久化、不丢凭证。M1 模型管理已完成；M2 运行时衔接待用户确认。
