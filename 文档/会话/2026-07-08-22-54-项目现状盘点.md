# finding

- 项目定位：AI漫游 / 绘界漫画是内部 AI 漫画制作工作台，主线是从章节剧本推进到剧情结构、分镜、出图准备、候选图、排版导出和素材包；轻漫剧属于后续 P0.5。
- 工程形态：pnpm workspace，三包为 `apps/web`、`apps/server`、`packages/shared`。前端 Vue 3 + Pinia + Vite；后端 NestJS；共享契约集中在 `packages/shared`。
- 后端模块已按边界拆分：`ProjectsModule` 下有 `ProjectRepository`、`ProjectStore`、`ChapterScriptService`、`StoryStructureService`、`StoryboardService`、`ImagePreflightService`、`CharacterReferenceService`、`ImageProviderService`；`DialogueModule` 下有剧本、剧情结构、分镜三个对话子 service。
- 当前 UI 已实现项目库、项目工作区、剧本、项目角色库、剧情结构、分镜工作台、出图准备；候选图工作台、排版导出、素材包在 `ProjectWorkbenchView.vue` 中仍走占位面板。
- `ProjectsController` API 覆盖项目、章节、角色、素材文件、剧情结构、分镜、出图准备；未看到候选图、排版导出、素材包的同等业务 API。
- `TasksService` 当前仍是进程内任务 Map，普通 create 会跑 mock task；角色参考图等受控任务可走 `createControlled` 由业务 worker 推进。
- workspace 中存在一个本地样例项目和本地设置文件；设置文件未展开，避免泄露本地密钥。
- 2026-07-08 继续任务时执行 `git fetch --prune origin` 后发现远端 `main` 新增 `4d1dd30 chore(web): 允许 exe.dev 域名访问 dev server`，仅修改 `apps/web/vite.config.ts`；已通过 `git pull --ff-only` 安全快进到该提交。
- 2026-07-08 已启动本地后端 `http://localhost:4310/api` 和前端 `http://localhost:5173/`。
- 候选图工作台第一版已实现：`/projects/:projectId/candidates` 显示真实工作区、按章节正式分镜展示镜头、可为单镜头创建 `image_generate` 任务并展示任务状态；未完成分镜或未确认出图准备时显示阻塞态。
- 本阶段未实现 Candidate 持久化、真实候选图资产落库、候选选择/锁定、排版导出入口。
