# finding

- F2 已在现有 G1 SQLite schema 上实现持久化任务仓储，没有新增 migration、字段或表。
- `PersistentTaskRepository` 已覆盖 runtime task 的 create、source projection seal、idempotency replay、claim/lease、heartbeat、finish、retry、cancel 和 expired-lease recovery。
- `TaskConcurrencySlot` 按 `concurrencyKey + slotNo` 维护全局槽位池；任务创建只补齐缺少的槽位，不能按任务重复建槽。
- DB 模式的 Tasks API 已投影到持久化仓储；file 模式仍保留原有内存任务行为。
- startup recovery service 会在 DB 模式模块初始化时收敛已过期 running task。
- 新增 `PersistentTaskWorkerService`：claim、15 秒 heartbeat、provider handler、严格 V2 输出、completion transaction；已覆盖四类 G2 任务。
- Story/Storyboard repository 新增 `applyTaskResultInTransaction`，会在 active pending + rowVersion + source gate 成功时更新 document/projection，过期任务只保存 `historical` 输出。
- Task detail API 返回 attempt 历史；主进程 DB mode 默认启动 worker，可用 `AIROAMING_TASK_WORKER_ENABLED=false` 关闭。
- repository create 对四类 G2 task 已校验 strict input、routing target、source types 和 generation spec；`PersistentG2TaskCreateGuardService` 统一执行创建时 NewWorkGate 和 current source projection 重建。
