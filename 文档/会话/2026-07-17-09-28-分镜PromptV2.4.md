# finding

- 当前生产基线为分镜 Prompt V2.3；它已经解决正式台词来源、对白负载和状态边界问题。
- 独立 P6 评测证明，V2.3 的主要残留不是 beatId 缺失，而是 `summary/outcome` 中的触发、身份、关系、状态结果或非对白声音没有进入实际镜头字段。
- 当前 Storyboard Schema 没有独立音效或屏幕文字字段，V2.4 必须使用现有 `coreAction`、`comic.panelDescription/dialogue/caption`、`motion.visualDescription/voiceLines` 承载，不扩字段。

# web_search

- 本轮不新增网络搜索；继续使用已完成的外部对标方案与本项目真实模型证据。

# goal

评估分镜 Prompt V2.4：在 V2.3 前置对白分配和状态边界之前增加 Beat 事实拆解与承载分配，完成相同两项目的真实文本 A/B 和重复语义评测；只有不破坏对白、时长、双轨与确认边界时才采用，否则恢复 V2.3。

# approach

- Prompt 内部顺序改为：Beat 事实账本 → 正式对白选择 → 对白分段 → 状态边界 → 共享 Shot → 双轨事实承载 → 逐 Beat 反查。
- 不让模型输出事实账本、评分或诊断字段。
- 非对白声音和屏幕文字不得伪造成 `voiceLines`；必须在现有画面/说明字段中明确，正式角色台词仍逐字来自候选。
- 真实 A/B 若退化则回滚到 V2.3，不因已写代码而强行采用。
