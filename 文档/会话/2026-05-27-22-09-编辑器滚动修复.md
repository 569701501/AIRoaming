# finding

- 剧本编辑器使用 `ProjectWorkbenchView -> ScriptDocumentEditor -> MarkdownTextEditor -> CodeMirror` 的多层 flex 高度链路。
- `ScriptDocumentEditor.vue` 的 `.editor-content` 缺少 `min-height: 0` 和 `overflow: hidden`，会让子级内容撑开而不是把高度约束交给 CodeMirror。
- `MarkdownTextEditor.vue` 的根容器没有显式隐藏外层溢出，CodeMirror `.cm-scroller` 也没有在组件内声明滚动接管，导致长文本时滚动边界不稳定。

# web_search


# goal

修复剧本文档编辑器长文本无法滚动的问题，保持工作台整体布局不被编辑器内容撑开。

# approach

- 补齐工作台中列、编辑器内容区、CodeMirror 根节点的 `min-height: 0` / `overflow` / `flex` 契约。
- 让 `.cm-scroller` 作为文本编辑区内部滚动层。
- 用类型检查、diff 检查和页面截图验证长文本可在编辑器内部滚动。
