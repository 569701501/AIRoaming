# finding

- 项目是 AI 漫画创作工作台（前端品牌"绘界漫画"），主链路 7 步：剧本 → 剧情结构 → 分镜工作台 → 出图准备 → 候选图工作台 → 排版导出 → 素材包。
- 前端 Vue 3 + Pinia + 自定义 CSS（`styles.css` 深色紫青渐变主题 + `styles-premium.css`），页面集中在 `apps/web/src/components/{projects,workbench,settings,layout}`。
- **用户反馈 V1 设计稿（扁平灰系）"太不好看，还没现在的好看"**：用户认可现有视觉语言（深紫夜色 #0b1020、紫色渐变辉光按钮、玻璃感面板、绿色状态丸），不要推翻重做。
- 已用 Playwright 截图现有 9 个页面确认真实臃肿点：DB Working Copy 开发状态条（结构/分镜/出图准备）、对话内内部 ID（thread=/message=/tool=）、英文技能名（script-outline-drafting）、候选图页三段解释文案、项目卡片封面占位与状态丸重叠、卡片摘要显示原始 markdown 井号。
- 修正方向：**保留现有视觉气质，只精修**——删内部术语/ID、压缩解释文案、统一状态语言、提升排版层级；V2 稿在 prototypes/ui-redesign-v2/index.html（剧本工作区，雨夜末班车真实内容）。
- 本地开发环境长期在跑：web :5173、server :4310，可直接截图对比。
