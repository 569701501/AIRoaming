# finding

- 当前 AI漫游全局导航包含 `项目库 / 素材库 / 任务队列 / 设置`，但 `设置` 只是 `AppSidebar.vue` 中的 planned 按钮，没有路由和页面。
- 当前前端路由只有 `/projects` 与项目工作区路由；`AppShell.vue` 在非项目路由时固定展示 `ProjectLibraryView`，需要增加 settings 路由分支。
- 当前 OpenCode 模型链路已有 `GET /api/ai-runtime/models`，后端默认模型来自 `OpenCodeRuntimeService.defaultModel`，当前兜底为 `self/gpt-5.5`。
- AuroraPlatformWeb 的 SettingsPage 采用左侧 tab 分区，包含 `AI 密钥` 与 `外观设置`；AI 密钥通过后端 credential API 保存，前端只展示指纹和状态；主题通过 Pinia theme store 写入 localStorage 并给 `documentElement` 加 `dark` class。
- 已实现 AI漫游本地 `settings` 模块：`GET/PATCH /api/settings` 保存到 `workspace/settings/app-settings.json`，响应不回传完整 API Key。
- OpenCodeRuntimeService 当前会读取 settings 默认 `providerId/modelId`；如果 settings 中存在 API Key，会在调用 OpenCode 前通过 `/auth/{providerID}` 同步给 OpenCode。

# goal

实现首页设置模块的两个功能：

- 设置页新增 `AI 密钥`，参考 AuroraPlatformWeb 的 provider credential 形态，但适配 AI漫游本地单用户应用。
- 设置页新增 `外观设置`，可切换外观并保存，刷新后保留。
- 不能把完整 API Key 暴露给前端持久状态；前端只展示掩码/指纹。

# approach

- 新增后端 `settings` 模块，把全局设置保存到 `workspace/settings/app-settings.json`。
- AI 密钥采用本地 workspace 文件持久化，API 返回时隐藏原文，只返回 `configured/keyPreview/updatedAt`。
- 外观设置采用 `theme` 字段，前端加载设置后应用到 `document.documentElement`，并提供页面内切换。
- 页面形态参考 Aurora：左侧设置分组，右侧内容面板；本阶段只做 `AI 密钥` 和 `外观设置`，不迁移账户、账单、团队和沙盒运行时。
