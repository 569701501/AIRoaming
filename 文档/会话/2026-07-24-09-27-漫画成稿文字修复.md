# finding

- 上轮真实浏览器验收已稳定复现：切换气泡类型、编辑文字、切换竖排后画布文字变空，Undo 只恢复部分状态。
- 新增文字时，画布选中对象与富文本面板仍指向上一对象；输入 SFX 后画布为空。
- 根因 1：浏览器全选替换会删除 `.editor-paragraph` 包装，旧解析器只读取该包装，因而把肉眼可见文字提交成空串。
- 根因 2：富文本组件未按 `element.id` 重建，IME/composition 状态会从旧气泡泄漏到新文字对象。
- 根因 3：每个输入事件独立入历史，连续键入一次 Undo 只撤一个字；现改为同一聚焦编辑会话合并历史。
- 独立复核根因 4：contenteditable 原先被全局快捷键处理器提前排除，Cmd/Ctrl+Z 不会调用 Session history；现已由 DB-only E2E 证明修复。
- 独立复核根因 5：章节 A 的保存响应原先可在切换到章节 B 后无条件写回共享 Session；现以 `projectId + chapterId + loadGeneration` 隔离保存结果，并允许显式保存等待既有 autosave。
- 独立复核根因 6：只读取标准 `.editor-paragraph` 会漏掉 Safari/Firefox 可能生成的无 class 根段落；现按根 `childNodes` 顺序读取标准段落、未知块和根文本，并在结构漂移后重建。
- 真实 DB E2E 已通过：根级整段替换、IME、对象切换、连续输入一次撤销/重做、普通 Enter、未知根段落，以及气泡 `thought → shout → 改字 → 竖排 → Undo×3 → Redo×3`。
