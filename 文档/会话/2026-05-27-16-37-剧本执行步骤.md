# goal

使用 `$grill-with-docs` 为剧本双来源与 AI 受控编辑功能拆出可逐步执行的开发步骤；先校准术语和执行顺序，再按用户确认一步步推进。用户要求基于“附件上传/输入框粘贴已有剧本，不新增导入按钮”的澄清，先写一版计划步骤供审阅。

# approach

先用现有文档和代码确认已具备的底座与缺口，再把功能拆成小阶段。需要用户决策的问题一次只问一个。术语调整为“用户提供剧本整理”：附件上传和输入框粘贴是输入方式，`import_script_to_chapters` 是后端/AI 处理动作，不是 UI 主按钮。

计划草案按“共享契约 -> 对话作用域 -> 附件/粘贴输入 -> AI 整理写章节 -> 前端刷新 -> 灵感生成 -> 章节内 AI 编辑 -> 追溯回退”的顺序拆分。
