# web_search

- 主题：漫画分镜与漫剧/动画镜头差异。
- 关键结论：漫画分镜是读者控制节奏的静态画格系统，重点是页面/条漫阅读顺序、panel layout、对白气泡、旁白、画格大小和信息呈现；动画/漫剧镜头是时间轴系统，重点是镜头持续时间、运镜、声音/配音、字幕和画面类型。
- 关键结论：motion comic/漫剧通常把漫画画格扩展为视频镜头，并加入声音、配音、音乐、有限动画或镜头运动；因此漫画和漫剧可以共享同一个镜头核心，但必须保留不同表达字段。
- 关键结论：不能把“漫画一格 = 漫剧一镜”作为永久规则。M1 可以默认一对一，后续要允许一格拆多镜或多格合一段。
- 来源：Clip Studio Paint 漫画创作说明、Too Corporation 漫画 storyboard 说明、Adobe animatic 说明、Toon Boom Storyboard Pro timing/camera 文档、Motion comic 定义、小镜故事板漫剧分镜字段文章。

# goal

明确分镜工作台的产品链路、数据边界、页面形态和确认保存规则，后续实现需要能形成章节级闭环。

# approach

先按 `$grill-with-docs` 对齐术语和关键决策：分镜工作台可复用剧情结构的阶段模式，但必须明确 `StoryBeat -> Shot[]` 的下游转换关系，不能把剧情结构字段简单换皮。

已确认：分镜 AI 生成结果也采用「待确认预览 -> 用户确认 -> 写入 `storyboard.json` / `Shot[]` -> 章节状态推进到 `storyboard_done`」。未确认分镜不能触发候选图生成。

已确认：分镜工作台同一次生成中产出漫画画格字段和基础漫剧镜头字段；正式模型是同一个 `Shot` 核心下分 `comic` / `motion` 两组表达字段。M1 一个 `Shot` 默认带一组 `comic` 和一组 `motion`，但契约不能把漫画一格和漫剧一镜永久写死。完整轻漫剧成片、TTS、字幕和视频导出仍后置。
