## 1. 用途

本文档定义工作台前端应如何组织视图、面板状态、左侧对话与中央功能面板之间的交互。

## 2. 核心视图类型

```ts
type WorkbenchPanelKey =
  | "project_story"
  | "story_structure"
  | "storyboard"
  | "image_candidates"
  | "layout_export"
  | "asset_package";
```

| Key | 中文 | 当前状态 | 主要数据 |
| --- | --- | --- | --- |
| `project_story` | 项目与故事 | current | `Project`, `StoryVersion.sourceText` |
| `story_structure` | 剧情结构 | current/next | `StoryVersion.structureJson` |
| `storyboard` | 分镜 | next | `Shot[]` |
| `image_candidates` | 候选图 | next | `Candidate[]`, `Asset[]` |
| `layout_export` | 排版导出 | next | `LayoutPage`, `PanelPlacement` |
| `asset_package` | 素材包 | next | `Asset[]`, `manifest` |

## 3. 三栏布局契约

```text
WorkbenchShell
  ├─ CommandPane
  ├─ WorkbenchSurface
  └─ ContextRail
```

| 区域 | 组件建议 | 状态来源 | 说明 |
| --- | --- | --- | --- |
| `CommandPane` | `ProjectContext`, `AiCommandStream`, `CommandComposer` | store + message state | 负责指令，不负责完整编辑 |
| `WorkbenchSurface` | `ProjectStoryPanel`, `StoryStructurePanel`, `StoryboardPanel`, `CandidatePanel`, `LayoutPanel`, `AssetPackagePanel` | `WorkbenchSnapshot` | 负责功能主体 |
| `ContextRail` | `TaskQueue`, `ObjectInspector`, `NextStepAdvisor` | tasks + selected object | 负责辅助判断 |

## 4. 面板状态

```ts
type PanelStatus = "locked" | "ready" | "active" | "needs_input" | "done";
```

| 状态 | 含义 | UI 行为 |
| --- | --- | --- |
| `locked` | 上游未完成，不能操作 | 禁用主操作，说明原因 |
| `needs_input` | 缺少必要输入 | 展示输入缺口 |
| `ready` | 可开始 | 展示主操作 |
| `active` | 当前正在处理 | 展示任务进度 |
| `done` | 当前阶段已完成 | 展示结果和下一步 |

## 5. 面板前置条件

| 面板 | 前置条件 | 未满足时 |
| --- | --- | --- |
| 项目与故事 | 无 | 展示创建项目 |
| 剧情结构 | 已有项目和故事原文 | 提示补故事 |
| 分镜 | 已有结构化剧情或剧情节拍 | 提示先结构化 |
| 候选图 | 至少一个 `ready_for_image` 分镜 | 提示先确认分镜 |
| 排版导出 | 至少一个锁定候选 | 提示先锁定候选图 |
| 素材包 | 至少有可归档资产 | 提示先生成或导出产物 |

## 6. 对话命令路由

对话输入应路由到面板和任务，不应只追加聊天消息。

```ts
type CommandIntent =
  | "create_project"
  | "update_story"
  | "parse_story"
  | "generate_shots"
  | "edit_shot"
  | "generate_candidates"
  | "lock_candidate"
  | "create_layout"
  | "export_package";
```

| Intent | 切换面板 | 任务类型 |
| --- | --- | --- |
| `create_project` | `project_story` | 无或 project create |
| `update_story` | `project_story` | 无 |
| `parse_story` | `story_structure` | `story_parse` |
| `generate_shots` | `storyboard` | `shot_generate` |
| `edit_shot` | `storyboard` | 无或 `shot_rewrite` |
| `generate_candidates` | `image_candidates` | `image_generate` |
| `lock_candidate` | `image_candidates` | 无 |
| `create_layout` | `layout_export` | `layout_generate` |
| `export_package` | `asset_package` | `asset_package_export` |

## 7. WorkbenchSnapshot 扩展方向

当前 `WorkbenchSnapshot` 已包含：

```ts
project
stages
story
shots
candidates
assets
aiNotes
```

后续为了支撑功能面板，应补充：

| 字段 | 说明 |
| --- | --- |
| `storyStructure` | 摘要、角色、场景、节拍结构 |
| `selectedShotId` | 当前选中分镜 |
| `selectedCandidateId` | 当前选中候选 |
| `layoutPages` | 页面排版列表 |
| `packageManifest` | 素材包预览 |
| `panelReadiness` | 每个面板的前置条件状态 |

## 8. 右侧 ContextRail 模式

```ts
type ContextRailMode = "tasks" | "inspector" | "advisor";
```

| 模式 | 用途 |
| --- | --- |
| `tasks` | 展示生成任务队列、进度、错误 |
| `inspector` | 展示当前选中故事/节拍/分镜/候选/页面详情 |
| `advisor` | 展示下一步建议、缺失项和风险 |

规则：

- 宽屏可同时展示任务和建议。
- 中等屏幕可用 Tab 切换。
- 移动端应把 ContextRail 放到 WorkbenchSurface 下方。

## 9. 前端组件拆分建议

```text
apps/web/src/components/workbench/
  WorkbenchShell.vue
  CommandPane.vue
  WorkbenchSurface.vue
  ContextRail.vue
  panels/
    ProjectStoryPanel.vue
    StoryStructurePanel.vue
    StoryboardPanel.vue
    ImageCandidatePanel.vue
    LayoutExportPanel.vue
    AssetPackagePanel.vue
```

## 10. 验收标准

- 中央区域不再只是输出展示，而是根据 `WorkbenchPanelKey` 显示功能面板。
- 左侧输入指令后，能切换到对应面板。
- 每个面板至少有前置条件、主操作、结果区、下一步。
- 右侧能解释当前任务或当前选中对象。
- 未实现面板必须显示 `next` 或 `locked`，不能伪装为完成。
