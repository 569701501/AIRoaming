## 1. 用途

本文档用于解决“文档功能范围”和“参考效果图功能密度”不对齐的问题。

参考效果图只能作为视觉语言和布局启发，不能直接决定当前产品功能。前端展示必须以本文档的功能取舍为准。

具体工作台功能面板以 `文档/01_愿景与产品/工作台功能模型.md` 为准；前端视图与交互以 `文档/02_架构与契约/工作台视图与交互契约.md` 为准。

## 2. 当前产品功能主线

AI漫游当前要做的是故事到漫画产物的内部生产链路：

```text
创建项目
  -> 输入故事
  -> 结构化剧情
  -> 生成/编辑分镜
  -> 生成漫画图候选
  -> 选择并锁定候选
  -> 漫画排版与导出
  -> 素材包归档
```

## 3. UI 展示层级

| 层级 | 含义 | 当前前端处理 |
| --- | --- | --- |
| `current` | 当前必须出现并围绕它组织页面 | 显示为主路径 |
| `next` | MVP 后续阶段要做，但当前未实现 | 可作为阶段卡或禁用提示 |
| `later` | P1/P2 或后置能力 | 当前隐藏，不进入主界面 |
| `exclude` | 明确不属于当前产品或当前阶段 | 不展示 |

## 5. 参考效果图功能取舍

| 参考图节点 | 是否出现在当前前端 | 取舍 | 原因 |
| --- | --- | --- | --- |
| 左侧品牌导航 | 是，但收敛 | `current` | 有利于表达生产模块，但只保留 MVP 主线 |
| 工作台 | 是 | `current` | 当前主入口 |
| 项目 | 是 | `current` | 已有项目列表和创建 |
| 角色库 | 暂不独立展示 | `next` | 文档有角色模板，但当前未实现独立管理 |
| 剧本 | 是，作为故事/剧本 | `current` | 故事输入是 M1 |
| 分镜 | 是 | `next` | M1 后续核心 |
| 漫画生成 | 是 | `next` | M2 核心 |
| 页面排版 | 是 | `next` | M3 核心 |
| 素材库 | 是，作为素材包/素材 | `next` | MVP 需要归档，但当前未实现完整库 |
| 设置 | 否 | `later` | 非主路径 |
| 升级计划 | 否 | `exclude` | 商业化不进入当前项目 |
| 全局搜索 | 否 | `later` | 当前没有索引和搜索需求 |
| 通知铃铛 | 否 | `later` | 无事件系统和用户通知 |
| 用户/团队菜单 | 否 | `later` | 多用户后置 |
| 生成队列 | 是 | `current` | 生成任务中心是基础设施 |
| 团队协作 | 否 | `later` | MVP 非目标 |
| 系统提示 | 改为下一步建议 | `current` | 保留对生产链路有帮助的 AI 建议 |
| 近期项目卡片 | 是 | `current` | 项目打开入口 |
| 数据指标卡 | 否 | `later` | 无真实统计数据 |
| 漫画页面编辑器 | 否，后续页面 | `next/later` | M3 前不作为主界面 |
| 属性/图层/标注 | 否 | `later` | 复杂编辑器后置 |
| 版本历史 | 否 | `later` | 当前无版本系统 |
| 导出设置 DPI/出血 | 否 | `later` | 复杂导出设置后置 |

## 6. 当前前端应展示的信息架构

```text
AIRoamingStudio
  ├─ 左侧窄导航
  │    ├─ 工作台 current
  │    ├─ 项目 current
  │    ├─ 故事 current
  │    ├─ 分镜 next
  │    ├─ 候选图 next
  │    ├─ 排版导出 next
  │    └─ 素材包 next
  ├─ 左侧对话区
  │    ├─ 项目列表
  │    ├─ 创建项目
  │    ├─ 对话消息
  │    └─ 指令输入
  ├─ 中央输出区
  │    ├─ 当前项目和主动作
  │    ├─ MVP 阶段条
  │    ├─ 输出 Tab：总览/故事/分镜/候选/导出
  │    └─ 最近项目或当前产物
  └─ 右侧生产栏
       ├─ 生成任务队列
       └─ 下一步建议
```

注意：左侧对话区不是工作台主体。中央输出区应升级为功能工作面板，详见 `工作台功能模型.md`。

## 7. 当前前端不应展示

| 不展示节点 | 说明 |
| --- | --- |
| 搜索框和快捷键 | 没有真实搜索和命令面板 |
| 通知铃铛 | 没有通知系统 |
| 用户头像/团队菜单 | 单机内部工具阶段不需要 |
| 团队协作面板 | 多人协作是 MVP 非目标 |
| 升级计划 | 商业化不进入当前产品 |
| 指标大盘 | 当前无真实统计 |
| 完整页面编辑器属性面板 | M3 前不展示 |
| 版本历史 | 当前无版本系统 |

## 8. 前端验收标准

布局调整完成后，应满足：

- 用户一眼能看出当前产品主线是“故事到漫画产物”。
- 不出现参考图中与当前文档不匹配的商业化、团队协作和复杂编辑器功能。
- 未实现但属于 MVP 后续的功能，只能作为阶段节点或禁用/占位出现。
- 当前可用功能必须能追溯到文档中的 `current`。
- 后续功能必须能追溯到文档中的 `next`。
