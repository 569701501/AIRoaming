## 1. 功能摘要

将前端从“项目库页面 / 项目工作台页面”切换模型，重构为始终打开的创作工作台壳：左侧作品栏、中间创作画布、右侧上下文检查器、底部任务 Dock。

## 2. 修改文件

| 文件 | 说明 |
| --- | --- |
| `apps/web/src/App.vue` | 重写为固定工作台壳 |
| `apps/web/src/styles.css` | 重写工作台布局和画布样式 |
| `文档/05_执行与记录/任务记录/2026-05-23_工作台壳重构/` | 新增任务三件套 |

## 3. 当前交互模型

```text
AI漫游工作台
  左侧作品栏：新建作品、最近作品
  中间创作画布：创建作品 / 总览 / 故事 / 分镜 / 素材 / 导出
  右侧检查器：上下文动作、项目状态、工作提示
  底部任务 Dock：生成任务队列
```
