## 1. 功能摘要

将应用入口从直接进入 demo 工作台修正为项目库。用户现在先创建项目，项目创建成功后进入该项目工作台。

## 2. 修改文件

| 文件 | 说明 |
| --- | --- |
| `packages/shared/src/dto.ts` | 新增项目列表和创建项目 DTO |
| `apps/server/src/projects/projects.service.ts` | 新增内存项目管理与按 projectId 生成 workbench |
| `apps/server/src/projects/projects.controller.ts` | 新增项目列表、创建、项目工作台接口 |
| `apps/web/src/services/api.ts` | 新增项目 API client |
| `apps/web/src/stores/workbench-store.ts` | 新增项目库、创建项目、打开项目、返回项目库状态 |
| `apps/web/src/App.vue` | 修正入口流程为项目库 -> 创建项目 -> 工作台 |
| `apps/web/src/styles.css` | 新增项目库和创建表单样式 |

## 4. 已知风险

- 项目数据暂时是内存存储。
- 尚未引入 Vue Router。
- 创建项目后故事只进入 snapshot，尚未写入 Prisma。
