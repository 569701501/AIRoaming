## 1. 功能摘要

将 AI漫游前端从简单状态页升级为参考 AuroraPlatformWeb 的创作工作台：左侧导航、顶部任务入口、工作台 tabs、工作流、故事、分镜、素材、导出和 AI 协作侧栏。

## 2. 影响范围

| 范围 | 影响 |
| --- | --- |
| shared 契约 | 新增 `WorkbenchSnapshot` 及工作台子对象 DTO |
| server | 新增 `projects` module 和 `GET /api/projects/local-demo/workbench` |
| web | 重写 `App.vue` 和 `styles.css`，升级为多面板创作工作台 |
| 文档 | 新增深思熟虑任务记录和完成记录 |

- 当前 workbench 数据为 demo snapshot，后续应迁移为 Prisma 项目数据。

## 6. 已知风险

- 这次增强的是产品工作台形态，不是完整 Aurora 级后端能力。
- 工作台数据仍是 demo snapshot，没有接 Prisma。
- 任务中心仍是 mock 任务，没有 SSE。
- 素材缩略图是 CSS 视觉占位，还没有真实图片文件。
