## 参考图拆解

| 特征 | 可迁移到 AI漫游的做法 |
| --- | --- |
| 白底与浅灰边界 | 页面保持轻、干净、可长期工作 |
| 紫色品牌和主按钮 | 用紫蓝作为主动作色，提高产品识别度 |
| 左侧图标导航 | 承载工作台、项目、角色、剧本、分镜、漫画生成等模块入口 |
| 顶部搜索和用户区 | 形成完整创作软件外壳 |
| 中央输出工作区 | 右侧内容不再只是状态列表，而是可操作的产物区 |
| 右侧队列与提示 | 生成队列、协作/提示应靠近输出区 |
| 漫画缩略图与面板感 | 用视觉占位表达漫画生成语境 |

## 本轮设计原则

- 不做落地页。
- 不把说明文案当作主要界面。
- 保留真实工作路径：创建作品、打开作品、查看输出、触发任务。
- 视觉上接近参考图，但不照抄品牌、头像或具体图片素材。

## 风险

- 当前缺少真实漫画图资产，视觉图块只能先用样式化占位表示。
- 参考图是完整产品原型，本项目目前仍处于 MVP 壳阶段，不能把未接入能力做成已完成状态。
