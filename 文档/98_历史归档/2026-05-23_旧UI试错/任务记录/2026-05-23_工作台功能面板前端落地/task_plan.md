## 1. 目标

把当前前端从“左侧对话 + 中央输出页签”推进为“左侧命令入口 + 中央六个功能面板 + 右侧辅助上下文”的工作台骨架。

## 2. 非目标

- 不接入真实图片生成、排版导出或素材打包服务。
- 不新增数据库表或后端持久化协议。
- 不引入搜索、通知、团队协作、升级计划等当前 MVP 外功能。

## 3. 阶段计划

| 阶段 | 状态 | 说明 |
| --- | --- | --- |
| 事实源复核 | complete | 已读取文档入口、写作规则、深思熟虑契约、工作台功能模型、视图契约和现有前端代码。 |
| 前端改造 | complete | 已将 `App.vue` 的输出页签替换为功能面板状态、操作入口、结果区和锁定说明。 |
| 文档留痕 | complete | 已记录改动、验证结果、Handoff 与完成记录。 |
| 验证验收 | complete | 已执行构建、类型检查、本地页面检查和截图证据。 |

## 4. 决策

| 决策 | 说明 |
| --- | --- |
| 中央区使用六面板 | 与 `WorkbenchPanelKey` 保持一致。 |
| 左侧对话只做命令路由 | 输入指令后切换面板或创建任务，不把聊天本身当功能。 |
| 未实现功能显示 `next/locked` | 防止把视觉占位误认为已完成。 |
| 后端暂不扩展 | 当前目标是前端产品骨架，不改变数据模型和 API。 |

## 5. 退出标准

- 中央区页签与 `工作台视图与交互契约.md` 的六个面板一致。
- 每个面板至少呈现前置条件、主操作、结果区、下一步或锁定原因。
- 左侧输入指令能切换到对应面板或触发当前可用任务。
- 右侧能展示任务、当前对象检查和下一步建议。
- 通过 `corepack pnpm build` 和 `corepack pnpm typecheck`。
- 任务记录、完成记录和验证证据齐全。
