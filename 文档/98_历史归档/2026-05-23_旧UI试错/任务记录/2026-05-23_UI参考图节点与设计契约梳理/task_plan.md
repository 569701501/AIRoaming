- 本次不复制参考图的品牌、头像、具体图片素材。

| 问题 | 处理方式 |
| --- | --- |
| 参考图中很多能力尚未实现 | 使用 `implemented/ui_shell/planned/deferred/not_in_mvp` 标记 |
