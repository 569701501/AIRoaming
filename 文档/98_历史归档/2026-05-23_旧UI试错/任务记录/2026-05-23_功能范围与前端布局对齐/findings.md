## 发现

- 文档中的当前主线是 AI 内容生产链路，不是完整 SaaS 协作平台。
- 参考图适合借鉴视觉风格，但里面的功能密度超过当前 MVP。
- 当前前端包含搜索、通知、用户区、团队协作、升级卡、指标卡等节点，容易误导后续实现方向。

## 决策

| Decision | Rationale |
| --- | --- |
| 先建功能范围与 UI 对齐矩阵 | 明确哪些功能现在做、哪些只是后续 |
| 前端只展示 P0/P0.5 主线 | 避免从第一版就像完整后台 |
| 超范围能力从界面移除而不是只禁用 | 当前阶段减少噪音，保护主路径 |
| 保留参考图视觉语言 | 白底、紫色主动作、轻卡片可保留 |

## 当前要收敛掉的节点

| 节点 | 原因 |
| --- | --- |
| 全局搜索/命令面板 | 文档未定义当前功能 |
| 通知和用户菜单 | 多用户/事件系统后置 |
| 团队协作和邀请成员 | MVP 非目标 |
| 升级计划 | 商业化后置 |
| 指标大盘 | 当前没有真实统计数据 |
| 完整页面编辑器入口 | M3 前不作为主界面 |

## 最终取舍

| 类别 | 保留 | 移除/隐藏 |
| --- | --- | --- |
| 导航 | 工作台、项目、故事、分镜、候选图、排版导出、素材包 | 角色库独立入口、设置 |
| 顶部栏 | 当前项目、M1 阶段提示 | 搜索、通知、用户团队 |
| 左侧区 | 项目列表、创建项目、AI 对话、指令输入 | 升级计划 |
| 中央区 | MVP 主线、阶段卡、输出 Tab、项目卡 | 指标大盘、完整页面编辑器 |
| 右侧区 | 生成队列、下一步建议 | 团队协作、邀请成员 |
