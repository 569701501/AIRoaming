## 目标

根据 AI漫游已有产品文档梳理当前应该做的功能范围，对照参考效果图中的超范围功能，更新文档并收敛前端布局。

## 非目标

- 不新增后端能力。
- 不把参考图中的搜索、通知、团队协作、升级、版本历史、完整页面编辑器等能力纳入当前实现。
- 不改变 MVP 主线。

## 阶段

| 阶段 | 状态 | 结果 |
| --- | --- | --- |
| 文档范围梳理 | completed | 已读取产品总览、MVP、核心用户流程、UI 节点和 UI 契约 |
| 功能取舍矩阵 | completed | 新增功能范围与 UI 对齐矩阵 |
| 文档同步 | completed | 更新 UI 节点、UI 契约、核心用户流程 |
| 前端收敛 | completed | 移除超范围 UI，保留 MVP 主线 |
| 验证留痕 | completed | build/typecheck/页面访问/截图/完成记录 |

## 已确认事实

| 来源 | 结论 |
| --- | --- |
| `产品总览.md` | 当前主线是故事、结构化、分镜、候选、锁定、排版导出、素材归档 |
| `MVP范围与路线图.md` | P0 是项目、故事、剧情结构化、分镜、图片候选、素材管理 |
| `核心用户流程.md` | 不包含全局搜索、通知、团队协作、升级、商业化 |
| 参考效果图 | 包含大量完整产品 UI 节点，不能全部进入当前前端 |
