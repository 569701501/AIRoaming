## 目标

重新梳理 AI漫游工作台的功能模型，明确左侧对话只是命令入口，中央和右侧必须承载真实可操作的功能工作面板。

## 非目标

- 本次不直接改代码。
- 本次不新增后端 API。
- 本次不扩大 MVP 范围。

## 核心判断

| 判断 | 说明 |
| --- | --- |
| 当前不是聊天产品 | 对话只是发起任务、解释结果、做下一步建议 |
| 中央区必须是功能工作面板 | 故事结构、分镜、候选图、排版导出都要成为可编辑表面 |
| 右侧区不是团队栏 | 右侧应是任务队列、对象检查器、AI 建议 |
| 前端下一轮应按功能面板改 | 不是继续美化聊天，而是补工作区 |
