# ADR-0016 G5 画布与确定性渲染技术路线

## 1. 决策状态

已采纳。依据无排期连续 Handoff：候选通过全部 E0 硬门、许可证可接受且不需要新付费或系统权限时，可直接定版并继续 G5-M2。

## 2. 背景与问题

G5 既要高自由画布、DOM IME/Undo，也要从同一 `LayoutDocument` 生成确定性的 PNG、PDF 和条漫切片。只比较拖拽体验会把工作预览与正式 renderer 分成两套语义，因此 E0 同时实现了：

- A：Konva 交互 adapter + DOM 富文本输入 + 独立 HTML RenderScene + 固定 Chromium。
- B：SVG-native adapter + 显式 glyph 定位 + resvg PNG + Chromium PDF 对照。

两条路线均覆盖页漫、横竖排、四类气泡、自由图片、crop/flip/rotation、IME/Undo、字体隔离、PDF 与条漫；B 的原生栅格调用另以子进程隔离，避免 native abort 终止总任务。

## 3. 决策

生产主路线采用候选 A：

1. Web 交互层使用 `konva@10.3.0`，只负责命中、选择、变换、手势与临时视觉反馈。
2. 富文本输入使用 IME 安全的 DOM overlay；持久事实仍是严格 `RichTextDocument`，不保存 HTML、DOM、Konva node 或 stage JSON。
3. Shared/Renderer 从 `LayoutDocument + RenderPlan + AssetManifest` 构建独立 HTML/SVG `RenderScene`；正式输出不得截图编辑器工作区。
4. Server 使用与 `@playwright/test@1.61.1` 绑定的 Chromium 149.0.7827.55，等待受控字体与图片 ready 后输出 PNG；PDF 使用同一 RenderScene 的 print 语义。
5. 条漫在同一完整 RenderScene 上按 `maxSliceHeightPx=8192` 滚动/clip 输出，不重新定位内容；切片 overlap/gap 固定为 0。
6. 字体预检使用受控 FontAsset 字节与 cmap；E0 锁定 Inter Regular 和 Noto Sans CJK SC Regular 的字节摘要。缺字体、缺 glyph 或摘要不符必须失败，不允许系统字体兜底。
7. Grapheme policy 由 G5-M2 固定为版本化 Shared 实现，不依赖客户端宿主 `Intl.Segmenter`；E0 原型中的 `Intl.Segmenter` 只作为原型实现，不进入生产事实源。

### 3.1 固定身份

| 项 | 固定值 |
| --- | --- |
| interaction adapter | `konva@10.3.0` |
| browser driver | `@playwright/test@1.61.1` |
| E0 Chromium | `149.0.7827.55` |
| renderer policy | `layout_render_policy_v1` |
| geometry policy | `layout_geometry_v1` |
| text policy | `layout_text_v1`；grapheme 子版本由 M2 固定 |
| balloon policy | `balloon_shape_v1` |
| Inter fixture | `sha256:27ae72daf88c7431896929273087c99910d019ae82dc0af7d86505c0f5ef5dbf` |
| Noto CJK E0 | `sha256:2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b` |

任何 Konva、Chromium、字体、text/geometry/balloon policy 升级都必须重跑 M0 corpus、E0/正式 golden、横竖排语义、PDF 和切片测试；像素或换行发生变化时必须升级 `rendererVersion`。

## 4. 选择依据

候选 A 最终 15 个门全部通过：

- 4 画格、自由图、crop/flip/rotation、层级、四类气泡 round-trip 通过。
- 中日文 IME composition 期间 0 条脏命令；一次 Undo 回输入前；100 条混合命令 Undo/Redo digest 回起点/终点。
- 工作预览与正式 scene 文字语义一致；11 个元素最大几何差 `0.001`，低于 `0.5`。
- `1800×2400` PNG 连续三次和固定黄金图 sha 相同。
- 单页 PDF 连续三次规范化 sha 相同；40 页 PDF 的 MediaBox 均为 `1350×1800pt`，字体为嵌入 Type0/Type3。
- 5 个条漫切片高度为 `8192/8192/8192/8192/5632`；拼接像素摘要与 20 个原始段落摘要完全相同。
- 20 canvases/200 elements：frame p95=`19.9ms`，pointerup command=`0.2ms`。
- 渲染期间外网请求为 0；缺字体明确失败；Inter/Noto cmap 均确认 `😀` 缺 glyph，预检拦截而不是系统字体降级。

候选 B 的页面 PNG、语义和 PDF 可通过，但 `@resvg/resvg-js@2.6.2` 在首个 `1080×8192` 切片发生 native abort；子进程隔离能保住总报告，却不能满足正式输出硬门，因此不选为首版 renderer。

## 5. 许可证与部署

| 依赖/字体 | E0 版本 | 许可 | 决议 |
| --- | --- | --- | --- |
| Konva | 10.3.0 | MIT | 可进入 Web 生产依赖 |
| Playwright | 1.61.1 | Apache-2.0 | 可用于 renderer 管理；binary 不提交仓库 |
| Inter | 固定 WOFF2 | OFL-1.1 | 可嵌入；M5 建 FontAsset metadata |
| Noto Sans CJK SC | 固定 OTF | OFL-1.1 | 可嵌入；M5 建 FontAsset metadata |
| fontkit | 2.0.4 | MIT | E0 cmap 审计通过；生产是否保留由 M5 按包体决定 |
| resvg | 2.6.2 | MPL-2.0 | 仅保留失败对照证据，不进入首版主 renderer |

Chromium binary 由固定 Playwright runtime 获取，不写入 git。若未来将 browser binary 随发行包再分发，发布前仍需按目标发行方式复核上游 notices；这不影响当前本地 G5 实施，也不引入付费或新系统权限。

## 6. 被否决的备选

| 备选 | 否决原因 |
| --- | --- |
| SVG + resvg 为主 renderer | 8192 高切片触发 native abort，未通过正式输出硬门 |
| 浏览器 Canvas + Server Canvas/Skia 双实现 | 两套文字测量/换行语义，E0 未证明一致 |
| 保存 Konva JSON | 把 adapter 私有状态变成领域事实，违反严格 LayoutDocument 契约 |
| 截图编辑器工作区 | 会带入选择框、viewport/dpr、调试 UI 与客户端状态，无法确定性出版 |

## 7. 影响与后续约束

- M2：建立严格 codec/normalization/digest/limits、固定 Unicode 17.0 grapheme policy、命令 reducer/inverse/batch 与 geometry/crop/reading order。
- M3～M5：Konva/DOM 只通过 adapter 消费 Shared state；autosave 只保存规范 LayoutDocument；受控字体通过 Asset/Outbox provision。
- M7：正式 renderer 必须进独立 worker phase，固定 browser/font/policy identity，并保留 crash/retry/output verifier。
- E0 原型保留为 `PROTOTYPE/ARCHIVED EVIDENCE`，不得复制进生产页面；生产代码只吸收已记录的接口与门禁。
