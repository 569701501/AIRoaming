## 1. 决策状态

已采纳。

## 2. 背景与问题

现有产品文档已经规定角色图生成/定稿发生在剧情结构页，出图准备只负责检查和放行；但当前实现对 `chapter/minor/extra` 角色使用正式分镜 `appearanceCount > 1` 决定是否需要四视图。待确认分镜不进入正式 `snapshot.shots`，导致剧情结构页先隐藏定稿按钮，确认分镜后才出现，用户随后在出图准备被迫返回上游。

同一规则还忽略 `entityType`，把群体和非人生物重复出镜错误解释为需要人物四视图，并让同一群体的文字别名形成重复 Character。

## 3. 决策

视觉素材要求在剧情结构确认时由 `level + entityType` 唯一确定；分镜只能引用该结构已登记的视觉主体；出图准备只验证正式分镜引用的主体是否满足这份既定要求，不生成、不修复、不临时升级要求。

### 3.1 不变量

- `剧情结构页显示的素材要求 == 分镜允许引用的视觉主体 == 出图准备检查的素材要求`。
- 出图准备缺项必须阻断候选图，但不得提供生成或修复动作。
- `appearanceCount` 不再决定素材类型。
- 用户不新增一个视觉元素确认阶段，现有页面字段和七阶段流程保持不变。
- 图片任务必须由已有用户动作触发；本决策实施和验收不得调用付费图片 Provider。

### 3.2 首版分类矩阵

| entityType | level | required kind |
| --- | --- | --- |
| human | lead / recurring / chapter | final_reference |
| human | minor / extra | preview_front |
| creature | 任意 | preview_front |
| group | 任意 | preview_front |
| voice | 任意 | none |

### 3.3 适用范围

- 剧情结构确认后的角色预览任务。
- 剧情结构页角色图/定稿按钮。
- 分镜角色引用解析。
- file 兼容预检与 DB-only PreflightRevision。
- 角色参考图 Prompt 模板选择。

### 3.4 非目标

- 不在本轮引入 `prop/object/location/style` 通用 Elements 数据模型。
- 不新增角色等级、StoryStructure 字段、数据库 migration 或新页面。
- 不要求所有素材完成后才能生成分镜草稿；但结构外主体不能确认进入正式分镜。

## 4. 被否决的备选

| 备选 | 优点 | 否决原因 |
| --- | --- | --- |
| 出图准备发现缺项后就地生成 | 操作看似集中 | 让门禁变成补救站，掩盖上游要求晚到问题 |
| 确认分镜后按出镜次数升级角色 | 看似贴近镜头 | 形成循环依赖和回头路，按钮无法提前展示 |
| 所有主体统一要求人物四视图 | 规则简单 | 群体、怪物、装置语义错误且浪费费用 |
| 立即建设完整 Elements 平台 | 长期完整 | 当前回滚成本过高，超出本次根因修复 |

## 5. 影响与后果

| 影响面 | 变化 |
| --- | --- |
| 产品与用户流程 | 七阶段不变；剧情结构页提前显示正确动作；出图准备仍纯检查 |
| 数据模型 | 无 migration；沿用 level/entityType 和 preview/final/none |
| API / 任务协议 | 请求字段不变；服务端按共享规则拒绝不适用的 final 请求 |
| 文件与 Asset | 现有 Asset 类型不变；creature/group 的 preview 作为首版视觉参考 |
| 前端 / 后端模块 | 共用 shared policy；预检 v2；分镜引用收紧 |
| 测试与验收 | 增加分类矩阵、别名、越界引用、策略失效和页面路径回归 |

## 6. 兼容、迁移与切换

- 旧 `preflight-source-v1` 文档继续兼容读取，但生产状态不再视为当前策略，用户需重新确认出图准备。
- 新预检写 `preflight-source-v2`，来源摘要包含 entityType 和要求规则影响。
- 已有 Character/Asset 不迁移；符合新规则的 final 仍可满足 preview 要求。
- 已存在的 group 别名不自动删除；页面素材投影即时去重，新结构或旧结构再次确认时保守归并到同一 Character。

## 7. 风险与回滚

| 风险 | 影响 | 预防或检测 | 回滚方式 |
| --- | --- | --- | --- |
| group 归一过度 | 不同群体被合并 | 只对固定中文群体后缀生效并做固定样例测试 | 关闭 group identity key，原 Character 不删除 |
| preview 对复杂 creature 不够 | 后续一致性不足 | 记录为类型化非人物 reference 的后续扩展点 | 后续新增专门 reference kind，不回写旧资产 |
| v1 预检变 stale | 用户需重确认 | UI 显示来源需更新，数据不删除 | 恢复生产策略接受 v1，但不推荐 |
