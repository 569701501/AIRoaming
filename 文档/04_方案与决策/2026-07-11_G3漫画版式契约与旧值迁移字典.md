# G3 漫画版式契约与旧值迁移字典

## 1. 用途

本文是 G3 实施时可直接复制到代码、migration、fixture 和验收用例的精确字典。它不重新讨论是否要在创建项目时选择；该产品决策已经由 ADR-0009 采纳。

优先级：

```text
ADR-0009 产品决策
  -> 本契约字典
    -> G3 主方案
      -> 具体实现与测试
```

若实现与本文冲突，必须先修改文档并复核，不能在代码里另造默认值或兼容别名。

## 2. 术语字典

| 中文 | 代码名 | 精确定义 |
| --- | --- | --- |
| 漫画版式 | `ComicFormat` | 项目级、创建后不可变的阅读容器；只有条漫/分页 |
| 竖向条漫 | `vertical_scroll` | 连续纵向滚动阅读容器 |
| 分页漫画 | `paged_comic` | 固定页序阅读容器，不包含页面横竖和尺寸 |
| 页面规格 | `PageProfile` | G5 定义的页面宽高、方向、出血等，可在分页容器内变化 |
| 布局模板 | `LayoutPreset` | G5 定义的画格初始布局，例如四格，可替换 |
| 发布规格 | `ExportProfile` | 平台/渠道的切片、格式、压缩、PDF 等版本化设置 |
| canonical 值 | canonical value | 正式运行时与 Project 表允许保存的两种值 |
| legacy alias | legacy alias | 只存在于旧 workspace/旧文档中的 `page_horizontal/four_panel` |
| strict parser | `parseRequiredComicFormat` | 正式请求入口，只接受 canonical 值 |
| legacy mapper | `mapLegacyComicFormat` | maintenance importer 专用，不参与 runtime 请求 |

禁止同义混用：

- 用户字段只能叫“漫画版式”，不叫“漫画分格”“漫画格式”“项目类型”。
- `ProjectType` 不等于 `ComicFormat`。
- `paged_comic` 不等于 `page_horizontal`。
- `four_panel` 不属于 Project `ComicFormat`。

## 3. Shared 领域定义

### 3.1 类型

```ts
export const COMIC_FORMATS = ["vertical_scroll", "paged_comic"] as const;

export type ComicFormat = (typeof COMIC_FORMATS)[number];

export interface ComicFormatDefinition {
  value: ComicFormat;
  label: "竖向条漫" | "分页漫画";
  description: string;
}
```

### 3.2 唯一定义目录

```ts
export const COMIC_FORMAT_DEFINITIONS = {
  vertical_scroll: {
    value: "vertical_scroll",
    label: "竖向条漫",
    description: "用于手机连续滚动阅读；后续排版将使用条漫画布。",
  },
  paged_comic: {
    value: "paged_comic",
    label: "分页漫画",
    description: "用于固定页面阅读；页面方向和尺寸在排版阶段设置。",
  },
} as const satisfies Record<ComicFormat, ComicFormatDefinition>;
```

### 3.3 predicate

```ts
export function isComicFormat(value: unknown): value is ComicFormat {
  return typeof value === "string"
    && (COMIC_FORMATS as readonly string[]).includes(value);
}
```

禁止：

```ts
// 禁止：会掩盖请求错误和数据损坏
return isComicFormat(value) ? value : "vertical_scroll";
```

### 3.4 label 读取

```ts
export function getComicFormatDefinition(value: ComicFormat): ComicFormatDefinition {
  return COMIC_FORMAT_DEFINITIONS[value];
}
```

不提供 fallback label。违反类型的数据必须在边界处拒绝，不能在展示层伪装成竖向条漫。

## 4. DTO 契约

### 4.1 Create

```ts
export interface CreateProjectRequest {
  name: string;
  type: ProjectType;
  comicFormat: ComicFormat;
  storyTitle?: string;
  genreTags?: string[];
  artStyle?: ArtStyle;
  description?: string;
  sourceText?: string;
}
```

不允许：

```ts
comicFormat?: ComicFormat;
comicFormat: ComicFormat | "";
comicFormat: string;
```

空字符串只属于前端表单内部状态，不属于 HTTP DTO。

### 4.2 Update

```ts
export interface UpdateProjectDraftRequest {
  name?: string;
  storyTitle?: string;
  genreTags?: string[];
  artStyle?: ArtStyle;
  description?: string;
  sourceText?: string;
}
```

`comicFormat` 不得以 `readonly` 或 deprecated 可选字段继续存在；必须完全删除，才能让新客户端在编译期报错。

### 4.3 Output

以下输出都必须继续包含 canonical `comicFormat: ComicFormat`：

- `ProjectListItem`
- `WorkbenchSnapshot.project`
- 需要项目来源的 Preflight DTO
- 新 runtime GenerationTask input/source snapshot
- 新 LayoutDocument/Export manifest（由 G5/G6 定义）

输出不允许为空、legacy alias 或 UI label。

## 5. 前端表单契约

### 5.1 内部状态

```ts
interface CreateProjectFormState {
  name: string;
  type: "comic";
  comicFormat: "" | ComicFormat;
}
```

初始值与每次 reopen：

```json
{
  "name": "",
  "type": "comic",
  "comicFormat": ""
}
```

### 5.2 选项

| 顺序 | value | label | disabled |
| --- | --- | --- | --- |
| 0 | `""` | 请选择漫画版式 | 是 |
| 1 | `vertical_scroll` | 竖向条漫 | 否 |
| 2 | `paged_comic` | 分页漫画 | 否 |

顺序不表示推荐。不能在任一选项旁增加“推荐”“默认”或自动预选。

### 5.3 提交条件

```ts
const canSubmit = computed(() => (
  form.name.trim().length > 0
  && isComicFormat(form.comicFormat)
));
```

提交 payload 必须从表单重新构造，不使用 `...form` 直接透传。`canSubmit` 是 UI 状态，不会替 TypeScript 在另一个函数中完成类型收窄，因此 submit 仍需读取局部值并再次执行 predicate：

```ts
const comicFormat = form.comicFormat;
if (!isComicFormat(comicFormat) || form.name.trim().length === 0) {
  return;
}

emit("create", {
  name: form.name.trim(),
  type: "comic",
  comicFormat,
});
```

禁止用 `as ComicFormat` 绕过空值。

### 5.4 UI 错误映射

```text
COMIC_FORMAT_REQUIRED  -> 请选择漫画版式
COMIC_FORMAT_INVALID   -> 漫画版式无效，请重新选择
COMIC_FORMAT_IMMUTABLE -> 漫画版式创建后不可直接修改
```

创建失败不 reset；关闭并重新打开才 reset。

## 6. Runtime parser

### 6.1 输入分类

| raw | 结果 |
| --- | --- |
| property 不存在 | `COMIC_FORMAT_REQUIRED` |
| `undefined` | `COMIC_FORMAT_REQUIRED` |
| `null` | `COMIC_FORMAT_REQUIRED` |
| `""` / 纯空格 | `COMIC_FORMAT_REQUIRED` |
| `vertical_scroll` | 返回 canonical |
| `paged_comic` | 返回 canonical |
| `page_horizontal` | `COMIC_FORMAT_INVALID` |
| `four_panel` | `COMIC_FORMAT_INVALID` |
| 数字/布尔/数组/对象 | `COMIC_FORMAT_INVALID` |
| 其他字符串 | `COMIC_FORMAT_INVALID` |

### 6.2 伪代码

```ts
export function parseRequiredComicFormat(raw: unknown): ComicFormat {
  if (raw === undefined || raw === null) {
    throw new BadRequestException("COMIC_FORMAT_REQUIRED");
  }
  if (typeof raw === "string" && raw.trim().length === 0) {
    throw new BadRequestException("COMIC_FORMAT_REQUIRED");
  }
  if (!isComicFormat(raw)) {
    throw new BadRequestException("COMIC_FORMAT_INVALID");
  }
  return raw;
}
```

不 trim 合法枚举：`" paged_comic "` 是非法输入，不应被宽松接受。

### 6.3 Update forbidden-field guard

```ts
export function assertComicFormatAbsentOnUpdate(body: unknown): void {
  if (isRecord(body) && Object.prototype.hasOwnProperty.call(body, "comicFormat")) {
    throw new ConflictException("COMIC_FORMAT_IMMUTABLE");
  }
}
```

guard 必须在构造 Update command 前执行。以下都返回 409：

```jsonl
{ "comicFormat": "vertical_scroll" }
{ "comicFormat": "paged_comic" }
{ "comicFormat": null }
{ "comicFormat": "" }
```

## 8. 数据库契约

### 8.1 Prisma 目标

```prisma
enum ComicFormat {
  vertical_scroll
  paged_comic
}

model Project {
  id          String      @id
  comicFormat ComicFormat
  // 无 @default
}
```

Prisma enum 不等于 SQLite 硬约束；migration SQL 仍必须有 CHECK。

### 8.2 SQLite 合同

| 项目 | 期望 |
| --- | --- |
| `PRAGMA table_info('Project').notnull` | `comicFormat=1` |
| `PRAGMA table_info('Project').dflt_value` | null |
| `sqlite_master.sql` | 包含两值 CHECK |
| trigger | `project_comic_format_immutable` 存在 |
| 直接 insert 缺值 | NOT NULL 失败 |
| 直接 insert 非法值 | CHECK 失败 |
| 直接 update 不同值 | `COMIC_FORMAT_IMMUTABLE` 失败 |
| 直接 update 同值 | DB 层允许 no-op；HTTP 层仍拒绝字段 |

### 8.3 trigger SQL

```sql
CREATE TRIGGER project_comic_format_immutable
BEFORE UPDATE OF comicFormat ON Project
FOR EACH ROW
WHEN NEW.comicFormat IS NOT OLD.comicFormat
BEGIN
  SELECT RAISE(ABORT, 'COMIC_FORMAT_IMMUTABLE');
END;
```

### 8.4 事务不变量

创建成功：

```text
Project.comicFormat = request canonical value
Project.currentChapterId -> 同事务默认 Chapter
Project.rowVersion = initial value
```

创建失败：

```text
Project 不存在
Chapter 不存在
current pointer 不存在
Outbox 不存在
```

## 9. Legacy mapper

### 9.1 返回类型

```ts
export type LegacyComicFormatMapping =
  | {
      kind: "canonical";
      comicFormat: ComicFormat;
      originalValue: "vertical_scroll" | "paged_comic";
    }
  | {
      kind: "auto_mapped";
      comicFormat: "paged_comic";
      originalValue: "page_horizontal";
      reason: "LEGACY_PAGE_HORIZONTAL_TO_PAGED_COMIC";
    }
  | {
      kind: "decision_required";
      issueCode:
        | "COMIC_FORMAT_FOUR_PANEL_REQUIRES_CONTAINER"
        | "COMIC_FORMAT_MISSING"
        | "COMIC_FORMAT_INVALID_LEGACY_VALUE";
      originalValue: unknown;
      layoutPresetIntent: "four_panel" | null;
    };
```

### 9.2 映射伪代码

```ts
export function mapLegacyComicFormat(raw: unknown): LegacyComicFormatMapping {
  if (raw === "vertical_scroll" || raw === "paged_comic") {
    return { kind: "canonical", comicFormat: raw, originalValue: raw };
  }
  if (raw === "page_horizontal") {
    return {
      kind: "auto_mapped",
      comicFormat: "paged_comic",
      originalValue: raw,
      reason: "LEGACY_PAGE_HORIZONTAL_TO_PAGED_COMIC",
    };
  }
  if (raw === "four_panel") {
    return {
      kind: "decision_required",
      issueCode: "COMIC_FORMAT_FOUR_PANEL_REQUIRES_CONTAINER",
      originalValue: raw,
      layoutPresetIntent: "four_panel",
    };
  }
  if (raw === undefined || raw === null || raw === "") {
    return {
      kind: "decision_required",
      issueCode: "COMIC_FORMAT_MISSING",
      originalValue: raw,
      layoutPresetIntent: null,
    };
  }
  return {
    kind: "decision_required",
    issueCode: "COMIC_FORMAT_INVALID_LEGACY_VALUE",
    originalValue: raw,
    layoutPresetIntent: null,
  };
}
```

Importer 日志和报告不得原样输出巨大对象或敏感内容；非法非字符串只记录类型、安全截断值和 source digest。

## 10. MigrationIssue 与决议

### 10.1 issueKey

```text
project:{projectId}:comic-format
```

同一 MigrationRun 内唯一。

### 10.2 detailJson

```json
{
  "schemaVersion": 1,
  "projectId": "project-123",
  "sourceStorageKey": "projects/project-123/project.json",
  "originalValueKind": "string",
  "originalValuePreview": "four_panel",
  "sourceDigest": "sha256:...",
  "layoutPresetIntent": "four_panel",
  "allowedComicFormats": ["vertical_scroll", "paged_comic"]
}
```

### 10.3 resolutionJson

```json
{
  "decisionSchemaVersion": 1,
  "action": "set_comic_format",
  "chosenComicFormat": "paged_comic",
  "layoutPresetIntent": "four_panel"
}
```

无四格意图时字段为 null，不省略，便于 canonical digest。

### 10.4 校验

- `chosenComicFormat` 必须 canonical。
- `layoutPresetIntent` 只能 `four_panel/null`。
- 非 four_panel 原始值不能伪造 `layoutPresetIntent=four_panel`。
- resolution 不提供“use_default”“ignore”或“keep_legacy”。
- resolved issue 必须进入 `MigrationRun.decisionsDigest`。

### 10.5 状态

```text
open      -> audit/blocked run 的历史 issue，阻止该 run 进入 final import/activate
resolved  -> 带固定 decisionsDigest 的新 run 已验证决议，允许 importer 使用 chosenComicFormat
```

已完成 run 的 issue 和 resolution 不可覆盖；用户提交或改变决议都创建新 run，旧 open issue 继续作为历史证据。

| `sourceDigest` | 原 metadata 摘要 |
| `originalComicFormat` | 安全字符串或类型预览 |
| `mappingKind` | canonical/auto_mapped/decision_required |
| `targetComicFormat` | canonical 或 null |
| `layoutPresetIntent` | four_panel/null |

| `resolutionStatus` | not_needed/open/resolved |
| `importStatus` | pending/imported/blocked |

```text

autoMappedCount
decisionRequiredCount
unresolvedBlockerCount
importedCount
```

## 12. 历史文档值处理

### 12.1 Project

只写 canonical 值；旧 alias 不保留在 Project 行。

### 12.2 Preflight

迁移后的权威 Project 值是 canonical，但旧 Preflight 的原字段、source digest 和别名证据进入 migration/legacy provenance。若无法按 G2 当前 policy 重建完整 SourceSnapshot：

```text
freshness=stale
reasonCode=PREFLIGHT_SOURCE_UNRESOLVED
canStartNewCandidateTask=false
```

用户重新确认后生成新的 canonical PreflightRevision。

### 12.3 Layout

旧 `LayoutPage.format` 原样保存在 `legacy_chapter_layout_v1` 文档中；它是历史证据，不参与 Project CHECK。

### 12.4 GenerationTask

旧 task input/output 不改写摘要：

- `legacy_imported/legacy_stub` 保留旧 payload 或脱敏摘要证据。
- 新 runtime task input 只允许 canonical Project 值。
- 查询层不得把旧 task payload 反序列化成新 runtime command 后重放。

## 13. Prompt 与 default policy

### 13.1 Prompt hint

建议 Server 映射：

```ts
const COMIC_FORMAT_PROMPT_HINTS: Record<ComicFormat, string> = {
  vertical_scroll: "vertical scrolling webcomic reading format",
  paged_comic: "page-based comic reading format; page orientation is not implied",
};
```

该 hint 可以进入角色/场景风格上下文，但 Candidate 干净底图 prompt 仍遵守现有规则，不写“整页漫画、气泡、分格”。

### 13.2 临时候选尺寸策略

```ts
export const LEGACY_GENERATION_DEFAULT_POLICY_VERSION = "legacy_generation_default_v1";

export const LEGACY_GENERATION_DEFAULT_SIZE: Record<ComicFormat, {
  width: number;
  height: number;
}> = {
  vertical_scroll: { width: 1024, height: 1536 },
  paged_comic: { width: 1536, height: 1024 },
};
```

任务 input 必须保存最终 width/height 和 policyVersion。不要只保存 `comicFormat` 后在重放时用新代码重新推断旧尺寸。

### 13.3 Legacy Layout adapter

```ts
type LegacyLayoutPageFormat = "vertical_comic" | "page_horizontal" | "four_panel";

export function toLegacyLayoutPageFormat(format: ComicFormat): LegacyLayoutPageFormat {
  return format === "vertical_scroll" ? "vertical_comic" : "page_horizontal";
}
```

函数名、注释和调用点必须出现 `Legacy`；G5 完成后删除。禁止把它导出为通用 Shared 领域函数。

## 14. 读写不变量

### 14.1 Runtime

```text
Create input        canonical only
Project DB          canonical only
Project API output  canonical only
Update input        field forbidden
Preflight new       canonical only
Task new            canonical only
UI label            definition catalog
```

### 14.2 Migration

```text
Source snapshot     may contain legacy alias/missing/invalid
Mapper              explicit result, never default
Decision            required for ambiguity
Project insert      canonical only
Legacy evidence     preserves original value/digest
```

### 14.3 历史兼容

```text
Legacy LayoutPage   may retain old format
Legacy Task         may retain old payload/digest
Runtime replay      forbidden
New business write  canonical only
```

## 15. 禁止实现清单

- `input.comicFormat ?? "vertical_scroll"`
- `normalizeComicFormat` 在请求和迁移共用
- Create DTO 继续可选
- Update DTO 继续保留 readonly/deprecated 字段
- PATCH 同值静默成功
- 在 Controller 只写 interface、不做运行时检查
- SQLite 只有 Prisma enum、没有 CHECK
- 数据库允许管理员原地 UPDATE 版式
- UI 选项写“横版页漫”
- 把 `four_panel` 自动猜为分页漫画
- 将旧 task/layout payload 全局字符串替换为 `paged_comic`
- 在现有弹窗前再增加一步选择页
- 把 ProjectStoryPanel 的旧元信息表单重新接回第 1 步

## 16. 与阶段边界的对应

| 契约 | 实施阶段 |
| --- | --- |
| canonical enum/definition/predicate | G3-A |
| strict parser/Update guard | G3-B |
| CHECK/trigger | G3-B |
| 现有弹窗与只读标签 | G3-C |
| legacy mapper/decision/report | G3-D |
| G2 SourceSnapshot canonical 化 | G3-D 联调 |
| PageProfile/LayoutPreset | G5，不在 G3 |
| 复制为另一版式 | 后续独立能力 |
