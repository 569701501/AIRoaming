# ADR-0019 智能成稿与人工编辑一体化

## 1. 决策状态

已采纳。用户于 2026-07-22 明确确认本方向作为后续开发基线。

本文扩展 ADR-0011 和 ADR-0016：两份旧 ADR 的有限成稿容器、高自由对象编辑、确定性渲染和不可变出版边界继续有效；本文取代旧 G5 中“模板初稿为主、对白与气泡主要靠人工补齐、AI 仅作为弱建议入口”的产品路径。

## 2. 背景与问题

现有 G5 已经具备正式编辑器的技术底座，包括画格、候选图、裁切、富文本、四类气泡、Working Copy、Undo/Redo、来源返修、LayoutRevision、确定性渲染和出版导出。但当前首次排版仍是固定规则：条漫一镜一段，页漫最多四镜一页；不会根据场景、节奏和对白生成完整成稿，也不会自动创建对白气泡和旁白。

当前页面同时暴露草稿、版本、出版、历史、来源修复和大量属性，普通用户必须先理解编辑器和系统状态，才能获得一份可读漫画。用户明确要求：上手必须简单，首次进入就应得到布局、裁切、对白、气泡和旁白基本正确的完整成稿，同时保留正式编辑器供后续手调。

## 3. 决策

第 6 步采用“一套漫画成稿工作台、智能起稿与人工编辑连续协作”的产品模型：系统基于正式分镜和当前候选定稿零配置生成结构化可编辑成稿，结果直接进入正式编辑器；用户在同一工作台中手调或进行局部智能优化，随后阅读预览并导出。

### 3.1 不变量

1. 用户可见名称使用“漫画成稿”；内部步骤键 `layout_export`、路由 `/projects/:projectId/layout` 和正式任务 `layout_export` 保持不变。
2. 首次进入不要求选择画布尺寸、模板、页数、气泡样式或导出参数；项目已锁定的 `comicFormat` 和系统默认 Profile 决定初始容器。
3. 智能成稿输出必须是正式 `LayoutDocument` 对象：画格、图片、裁切、文字、气泡和阅读顺序均可继续编辑，禁止先生成扁平图片再伪装为编辑器内容。
4. 成稿阶段只放置正式分镜中的对白与旁白，可以重新断行，不得静默增删、改写或总结台词。
5. 完整编辑器是主工作区，不是隐藏的“高级模式”；阅读预览是同一文档的只读视图。
6. 智能调整必须有明确作用域，默认保护人工修改，完全尊重显式锁定；非首次初始化的智能结果先预览、后应用，并进入同一撤销栈。
7. 任何智能规划都必须绑定正式 StoryboardVersion、当前 CandidateLockSet、图片 Asset 摘要、字体与策略版本；来源变化后旧规划不得直接应用。
8. 正式导出继续只消费不可变 LayoutRevision，沿用现有确定性 RenderScene、publication、Asset 和 manifest 契约。
9. 即使视觉分析不可用，系统也必须通过保守安全布局生成内容完整、文字不溢出的基础成稿；视觉分析只能增强裁切、主体避让和气泡尾巴，不得成为打开编辑器的单点故障。

### 3.2 适用范围

- `vertical_scroll` 竖向条漫与 `paged_comic` 分页漫画。
- 当前章节全部正式 Shot 和当前 CandidateLockRevision。
- 初次整章成稿、整章换版、场景/页面/条漫段落重排和选区局部优化。
- 自动画格布局、非破坏裁切、对白/旁白归一化、气泡类型、气泡位置、尾巴、阅读顺序和基础版式风格。

### 3.3 非目标

- 不扩张为画笔、滤镜、像素修图、通用矢量工具或无限白板。
- 不允许智能成稿自动创建正式 LayoutRevision 或自动出版。
- 不在成稿阶段重新创作剧情或台词。
- 不让模型直接输出未经校验的任意像素坐标作为最终事实；模型只提供结构化视觉区域或建议，最终几何由受控规划器和质量门生成。
- 不要求首版支持印刷出血、跨页大图、复杂多尾气泡或任意多边形画格。

## 4. 被否决的备选

| 备选 | 优点 | 否决原因 |
| --- | --- | --- |
| 智能成稿完成后再进入独立高级编辑器 | 主流程看起来短 | 把编辑器降为补救入口，自动结果和手调状态容易分裂，用户已明确否决 |
| 继续固定一镜一段/四镜一页，只优化页面样式 | 实现简单 | 不理解场景、节奏和对白，无法满足“大部分内容无需调整” |
| 让多模态模型直接返回最终 LayoutDocument 像素坐标 | 开发原型快 | 难以稳定复现、校验和回归，容易漏台词、遮挡主体或产生越界几何 |
| 首次进入先让用户选择模板、尺寸和气泡样式 | 可控参数多 | 增加学习成本，把系统能推断的信息重新交给用户填写 |
| 手动修改后禁止再使用智能能力 | 保护实现简单 | 失去局部重排价值，不符合智能与编辑连续协作的目标 |

## 5. 影响与后果

### 正向后果

- 普通用户进入第 6 步即可获得可阅读的完整初稿，编辑器从“从零制作工具”变成“修正少量例外的工作台”。
- 自动布局和人工编辑共用同一份业务文档、版本链和 renderer，不建立第二套成稿事实源。
- 对白、气泡和阅读顺序可以通过固定语料和质量评分持续回归，而不是依赖人工主观判断。

### 代价与限制

- 需要新增叙事分组、对白归一化、视觉安全区、布局候选生成、评分和自动修复能力。
- 需要记录字段级人工保护意图；现有单一 `locked` 布尔值不足以表达“保留手调裁切但允许系统调整画格”。
- 需要新的真实视觉样例集和人工评分基线；只跑类型检查、单元测试或成功导出不能证明智能成稿质量。

| 影响面 | 变化 |
| --- | --- |
| 产品与用户流程 | 第 6 步目标名称改为“漫画成稿”；首次自动成稿，编辑/阅读预览/导出在同一工作台连续完成 |
| 数据模型 | `LayoutDocumentV2` 增加不影响渲染的 automation/protection 元数据；现有关系表继续承载 Working Copy 与 Revision |
| API / 任务协议 | 新增来源密封的 `layout_compose` 建议任务与整章/局部预览应用接口；正式 `layout_export` 不变 |
| 文件与 Asset | 不新增可变文件事实源；视觉分析和规划结果保存于任务输出及 LayoutDocument 元数据，正式成品路径不变 |
| 前端 / 后端模块 | 新增规划器、质量评分器、视觉分析适配器和统一工作台壳；复用现有画布、命令、保存、预检和 renderer |
| 测试与验收 | 新增内容覆盖、对白零改写、气泡可读性、主体遮挡、人工保护和视觉质量语料验收 |

## 6. 兼容、迁移与切换

- 旧 `LayoutDocumentV1` 必须继续可读；历史 Revision 不改写。V1 Working Copy 升级为 V2 时 composition/dialogue binding 为空，但既有 canvas、element 和 panel image 按适用字段生成 `explicit_preserve` 保护，因为系统无法证明它们没有被人工调整。
- 已存在的 Working Copy 不得被智能成稿静默覆盖。用户显式选择“生成智能成稿”后先得到整章差异预览，再决定是否应用。
- 没有 Working Copy 的章节首次进入时，前端自动创建来源密封的成稿任务；结果仍需由服务端在来源未变化、Working Copy 未被其他写入占用时原子应用。
- V2 不新增渲染元素类型，因此必须提供可见内容无损的 `V2 -> V1` 纯投影：仅剥离 automation/protection 元数据，保留所有画格、图片、文字与气泡。它只供 renderer/兼容读取和 golden 使用，不得覆盖写回 V2 Working Copy/Revision；功能开关关闭只停智能入口，不丢绑定与保护。
- 切换前必须先完成固定语料、V1/V2 codec 往返、现有 G5 renderer golden 和真实用户路径；不允许双写 V1/V2 两套 current 文档。

## 7. 风险与回滚

| 风险 | 影响 | 预防或检测 | 回滚方式 |
| --- | --- | --- | --- |
| 自动排版质量波动 | 用户仍需大量手调 | 多候选评分、固定语料、截图人工复核和 80% 无需移动指标 | 关闭智能首次入口，保留编辑器和 V2 兼容读；不把降级投影写回覆盖 V2 |
| 对白重复或遗漏 | 成稿内容错误 | 结构化对白优先、稳定 lineId、覆盖账本和 100% 对白映射门禁 | 阻止应用该规划，回到原 Working Copy，不生成 Revision |
| 智能重排覆盖手调 | 用户失去信任 | 字段级 protection、显式 lock、作用域预览、同一 Undo 栈 | 丢弃 PendingEditorCommandSet 或撤销整批命令 |
| 视觉分析错误 | 裁切人物或气泡遮脸 | 置信度门槛、保守 fallback、主体遮挡评分和预检 | 忽略该分析，重跑规则模式；不删除原图 |
| 来源在生成期间变化 | 应用过期布局 | task source projection、apply 时二次 CAS/freshness 校验 | 标记任务 historical/expired，重新生成 |
| 长条画布性能下降 | 编辑卡顿 | 段落虚拟化、缩略预览、局部重排与性能门 | 关闭高成本分析层，不回退业务文档 |

## 8. 验证标准

- [ ] 首次进入无需配置即可生成包含全部镜头、对白、旁白和气泡的结构化成稿。
- [ ] 固定测试集中镜头、对白和旁白覆盖率为 100%，无重复、无静默改写。
- [ ] 文字无溢出且不低于项目规定的最小可读字号；气泡阅读顺序可验证。
- [ ] 完整模式下，普通测试章节的画格/裁切直接可用率与自动绑定气泡无需改类型/移动/缩放率均至少 80%。
- [ ] 用户修改裁切、文字或气泡后，局部智能重排不覆盖受保护字段；锁定对象完全不变。
- [ ] 初始任务、局部预览、并发冲突、来源更新、重启恢复和重复提交均有合同或集成证据。
- [ ] 同一 LayoutDocument 的编辑预览、阅读预览和正式 publication 保持现有确定性渲染一致性。
- [ ] Runtime/User Review 使用真实条漫与页漫章节完成，并保存截图、任务、Revision 和导出物证据。
