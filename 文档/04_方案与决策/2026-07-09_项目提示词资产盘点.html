按优先级看

高优先级 候选图最终 Prompt 过薄

后端候选图最终只取 positivePrompt / promptDraft / panelDescription / coreAction，再拼一个 Avoid。前端已有更完整的 prompt 预览，但后端并未完全复用。后续优化出图质量时应优先统一。

高优先级 角色定稿图 Prompt 已有硬约束，但缺少可调参数

角色图明确拒绝真人、3D 和多角色，方向正确；但缺少姿态、线稿风格、光影、画布比例、参考图权重等可配置层。

中优先级 剧情结构和分镜 Prompt 偏“协议强”，偏“创作弱”

JSON 结构、字段枚举和边界很清楚，但缺少优秀漫画分镜常见的节奏、镜头推进、情绪峰值、读者视线引导等创作评分维度。

中优先级 剧本 Prompt 多处重复边界

动态 prompt、AGENTS、agent、skills 都声明了剧本边界，能稳住行为，但后续维护要防止一处改了另一处过期。

后续对标优化建议

批次 建议先改哪类 原因 需要调研的市场提示词方向
第 1 批 候选图最终 Prompt + 角色参考图 Prompt 直接决定用户能不能看到好图，也是 Grok/豆包/OpenAI provider 的共同收益点。 漫画 panel prompt、character sheet prompt、consistent character、negative prompt、reference image prompt。
第 2 批 分镜 Prompt 分镜质量决定候选图 prompt 的上限；现在更像字段转换器，还不是强漫画导演。 storyboard prompt、manga panel composition、shot breakdown、cinematic manga pacing。
第 3 批 灵感 / 大纲 / 章节剧本 Prompt 已有边界很稳，适合在不破坏格式的前提下增强商业类型、开篇钩子和章节爽点。 webtoon story prompt、short drama hook、manhwa plot outline、episode cliffhanger。
第 4 批 工具描述和 Agent/Skill 去重 主要影响模型何时调用工具和长期维护成本，属于稳定性优化。 function calling tool description best practices、agent instruction hierarchy。
