# ADR-0023 漫画成稿编辑器极简画布与有限本地撤销

## 状态

已采纳（2026-07-30 用户逐项确认 D1~D8)。

## 背景

ADR-0022 把漫画成稿收缩为「首次自动排版 → 人工手调 → 一次导出」基础版。2026-07-26 体验评估确认数据链路已是产品级，但手动调整环节是短板：右侧常驻属性面板平铺近 10 个内部概念区块、拖拽无实时预览（盲拖）、画布上不能改文字、没有任何撤销手段、且编辑器使用第三套私有蓝色主题（`--le-accent:#4f8cff`)。

## 决策

只改编辑器 UI/交互层，不改 LayoutDocument 协议、自动排版与导出后端：

1. **布局**：三栏改画布优先。左侧页面导航 + 镜头素材默认收起为浮层；右侧常驻属性面板移除，页面设置 / 画格模板收进「画布设置」抽屉；详细设置收进按需打开的「属性」浮层。
2. **浮动上下文工具条**：选中元素就近浮出核心动作（画格=裁切/复制/锁定/删除；气泡=类型/尾巴/复制/锁定/删除；多选=对齐/分布/删除）,「更多」打开属性浮层。对齐 / 分布不再常驻工具条。
3. **画布直接操纵**：拖拽 / 缩放 / 旋转全程实时预览（Konva dragmove 同步视觉投影，松手才提交正式命令）；双击文字 / 气泡就地编辑纯文本（按首段样式重建段落，复用正式替换文档命令）;Delete 删除保留。
4. **有限本地撤销**：恢复撤销能力，但以最克制形式——内存快照栈（上限 50 步、仅当前会话、服务端重载即清空、无 redo、不进入任何协议、不复用已退役的 `LayoutCommandHistoryV1`)。这是对 ADR-0022「无 Undo」口径的**有限修订**:ADR-0022 反对的是与智能调整配套的一次性 AI 撤销，而非人工编辑的本地撤销。
5. **主题**：废弃私有蓝色主题，选中态 / 强调色统一为项目紫色（`#8b5cf6`)，完成态沿用薄荷绿，背景并入全局 `#0a0d14`。

## 明确不做

- 不激活 full/scoped reflow、Pending 命令、版本历史 UI、导出历史 UI。
- 不做 redo、不持久化撤销栈、不把撤销暴露给任何 API / 协议。
- 不改导出对话框流程（预检阻断 → 文字确认 → 下载）。

## 影响

- 前端：`LayoutExportWorkspace.vue` 拆出 `LayoutExportDialog.vue`、`LayoutCanvasSettingsDrawer.vue`;`LayoutKonvaInteractionLayer.vue` 增加预览变换与双击事件；`layout-editor-session.ts` 增加本地撤销栈。
- 测试：e2e m4/m5/m6/m7/m8/smart-compose 操作路径改为「先展开对应浮层再操作」;契约测试锁定新形态（本地撤销存在、无 redo、无 AI 抽屉）。
- 文档：本 ADR 取代 ADR-0022 中「无 Undo」的表述，其余基础版口径不变。
