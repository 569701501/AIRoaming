# ADR-0009 项目创建时锁定漫画版式

## 1. 状态

已采纳，尚未实现。

2026-07-11 实施细节已获用户确认：复用现有创建项目按钮、弹窗、API 调用和成功跳转，只在现有弹窗补字段；不新增入口或向导。普通 PATCH 只要出现 `comicFormat` 就拒绝，数据库使用 canonical CHECK 和不可变 trigger；三份 G3 开发级文档均已采纳但尚未实现。

## 2. 背景

现有项目已有 `comicFormat`，但创建弹窗只填写项目名称，后端缺失值默认 `vertical_scroll`，用户进入工作台后还能修改。现有枚举还把 `vertical_scroll/page_horizontal/four_panel` 并列，混合了两种分类轴：

- 条漫/页漫描述最终阅读容器。
- 四格描述容器内部的格子模板。

漫画版式会影响所有章节、画布、候选图默认画幅、发布预览和导出。如果在项目创建后任意改变，既有布局、字体、导出和验收契约都可能失效。

## 3. 决策

### 3.1 创建项目时必选

在现有“创建项目”弹窗中，项目名称下方增加“漫画版式”下拉框：

- 默认值为空。
- 用户未选择时不能创建。
- 服务端对缺失和非法值执行强校验，不提供静默默认。

### 3.2 正式术语

- 用户可见字段：`漫画版式`。
- 领域对象：`ComicFormat` / `comicFormat`。
- `漫画分格` 保留给画布里的三格、四格、自由分格和格子调整。
- `ProjectType` 继续表达漫画/轻漫剧等媒介类型，不与 D1 混用。

### 3.3 顶层版式只有两类

```text
vertical_scroll  竖向条漫
paged_comic      分页漫画
```

- `page_horizontal` 迁移为 `paged_comic`，页面横竖方向由页面设置表达。
- `four_panel` 迁移为 `LayoutPreset.four_panel`，不再属于项目级版式。
- 印刷、PDF、平台切片尺寸属于可版本化 `ExportProfile`，不新增项目版式。

### 3.4 创建后不可直接修改

普通项目更新接口不提供 `comicFormat` 写入口。UI 只读展示，服务端拒绝旧客户端修改，数据库字段非空且无默认值。

未来若用户确实需要改变版式，采用“复制为另一版式”的显式转换任务，创建新的 `Project.id`；不在原项目上直接 UPDATE。

### 3.5 旧数据不静默猜测

- `vertical_scroll` 原值保留。
- `page_horizontal` 映射为 `paged_comic`。
- `four_panel` 或缺失/非法值进入一次性人工确认报告；保留四格模板意图，但不自动猜测条漫或页漫。

## 4. 被否决的备选

### 4.1 否决：继续默认竖向条漫

用户可能无意识建立错误项目身份；同时违背“创建后不可修改”的高成本约束。

### 4.2 否决：字段名使用“漫画分格”

该词已稳定表达画格和格子布局，若用作条漫/页漫字段，会与后续三格、四格和自由分格产生概念冲突。

### 4.3 否决：四格继续与条漫、页漫并列

四格可存在于条漫或固定页，是布局模板而不是阅读容器。

### 4.4 否决：创建后原地切换版式

原地切换会让历史画布、导出和发布规格失去可复现性，且回滚成本高。

## 5. 影响范围

- 产品：创建项目从一个必填字段增加为两个；工作台只读展示版式。
- 共享契约：`CreateProjectRequest.comicFormat` 必填；更新 DTO 移除该字段。
- 后端：创建严格解析；普通更新拒绝修改。
- 数据库：`Project.comicFormat` 非空、无默认；旧值迁移。
- 画布：四格进入布局模板；页面方向与尺寸独立建模。
- 候选图：项目版式只提供默认画幅，未来允许镜头/画格级目标比例覆盖。
- 导出：平台规则进入 `ExportProfile`，不改变项目身份。

## 6. 风险与回滚

| 风险 | 应对 |
| --- | --- |
| 用户选错后无法修改 | 创建入口明确提示；后续提供复制转换，不修改原项目 |
| 枚举更名破坏旧数据 | 幂等迁移、异常报告、正式切换前审计 |
| 两类版式无法覆盖特殊平台 | 在版式内部扩展页面设置和 ExportProfile，不扩张顶层枚举 |

若开发前撤销本 ADR，只需恢复旧方案文档；一旦新项目按不可变版式创建，回滚必须保留已存值和兼容读取，不能重新给所有项目套默认值。

## 7. 验证标准

- 创建弹窗默认空且必选。
- API 缺失或非法版式返回错误。
- 创建后 UI、DTO、服务和数据库均不能直接修改。
- 竖向条漫、分页漫画各能创建一个项目并在重启后保持值。
- 四格只出现在布局模板中。
- 当前 workspace 项目迁移报告无未处理异常。
