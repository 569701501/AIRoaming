##第 1 章：雨夜点名

###一、基础方向

类型：都市怪谈 / 心理惊悚 / 超自然
主题：被错误点名的活人，如何在收容规则里争回自己的姓名
风格：暗黑写实、雨夜压迫、低语式惊悚
漫画形式：竖向条漫
目标篇幅：单章短篇（完整起承转合）

###二、本章方向

一句话梗概：雨夜末班站，林夏被广播点名上一辆无司机空车，发现座位按死亡时间编号后，她抓住点名漏洞证明自己不该被带走，跌回站台，只余广播极轻的一顿。

本章目标：完成「被点名上车 → 识破收容规则 → 证明不该被带走并回到站台」的单章闭环，让读者看清空车规则、林夏压力与最终选择结果。

核心冲突：林夏只想到家，却被系统点名为漏网死者；反抗会触发车厢清点，服从会被送去从未去过的终点，失败则姓名与存在被抹去。

情绪走向：疲惫戒备 → 被点名的僵直恐惧 → 车内规则压迫下的无助 → 抓住矛盾后的拼死自证 → 落地后的虚脱与未散余悸

###三、剧本亮点

关键转折：她从「不敢动、只求别被点到」转为抓住编号/点名矛盾主动自证；因此空车的收容逻辑被卡死，车门在终点前反常开启，她被放回站台而非被抹除。

结尾钩子：人已安全站在雨里，值班员撑伞确认她还在；主威胁解除，只余广播在空荡线路尽头极轻地停顿半拍，像记得这个名字，却不再宣读。
